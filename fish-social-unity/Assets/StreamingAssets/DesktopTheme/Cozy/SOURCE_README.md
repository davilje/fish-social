## 组合规范

- 图标、按钮背景、文字相互独立。PNG 内没有功能文字，支持实时排版与本地化。
- 图标画布为 256×256，实际图案包围框按绘制图集逐项裁切，不把相邻图案简单按等分格裁入。锚点默认 0.5 / 0.5。
- `reference-*` 不作为空按钮底板使用，避免将背包雕刻重复叠加。
- `plate-*` 可用于常规图片按钮；拉伸前检查四边约 100px 的九宫格边界。该边界是建议起点，不是 Unity 已导入验证的成品 Prefab。
- 默认与悬停底板包含柔和阴影，不应再叠加额外外投影。按下时改用 `plate-pressed`，或使用原参考纹理并关闭外投影。
- UI 文字不作为 PNG 切图；列表、弹窗、背包格和进度条由统一组件动态布局，避免静态截图的不可交互与拉伸问题。
- 网页用原参考纹理与 CSS 实现同一按钮状态，图标 / 插画使用本目录 PNG，不使用 SVG。`styles.css` 为素材库独立预览所需样式，由切图脚本同步生成。

## 来源与复现

雕刻图集、无文字按钮底板和世界地图由图像生成工具按已批准方向派生，不保证逐像素复制原图；原批准图、裁片保留用于比对。角色 / 鱼 / 河畔场景沿用当前项目资产。

项目根目录的 `slice-ui-assets.cjs` 使用 Sharp 做切图、尺寸统一和头像裁切，不用脚本重新绘制雕刻图案。执行 `node slice-ui-assets.cjs` 可从保留源图重建切图清单与预览样式。

网页入口为相邻目录的 `../game-ui/index.html`。角色帧动画仍引用 `../animation-studio/`，本素材库不重复打包整套钓鱼动画。社交、排行榜和购物是本地演示，不是正式联网服务。
