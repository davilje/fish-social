# Unity 最终版 UI 切图

本目录采用最终确认的“底色加深、轻微下移、外投影消失”按钮方案，不使用此前的内凹槽候选。

- `icons/`：24 张独立、透明、可可棕雕刻图标，统一 256×256；Unity Image 使用白色 tint。
- `buttons/plate-*.png`：三态空白底板，512×512；九宫格边界为 100/100/100/100 起点。
- `buttons/reference-*.png`：含原背包图案的参考裁片，不用于空按钮底板。
- `textures/`：纸纹及三态填充纹理。
- `scenes/`：湖泊和世界地图插画；真实鱼塘点位/条件由现有工程目录决定。
- `characters/`、`fish/`：沿用已整理的橘猫和蓝鱼插画，不是完整运行时动画库。
- `sources/`：最终批准图及两张派生图集，用于设计比对和复现。
- `manifest.json`：40 张切图的路径/尺寸/透明信息；另保留 3 张源图，共 43 张 PNG。
- `index.html`：离线素材查看/单张下载工具；不是 Unity 游戏页面或实际联机结果。
- `design-tokens.json`：配色、按钮状态和布局意图；已改为本目录内可解析的相对路径。
- `SOURCE_README.md`：原网页素材库的来源说明，仅作为来源记录，其旧工程相对路径不用于 Unity。

Unity 接入说明位于仓库 `docs/archive/2026-10-26/superseded/design/ui/2026-10-13-cozy-unity-port.md`。编辑器菜单 `Fish Social → Cozy UI → 检查最终版素材` 可检查资源完整性。

底板阴影已烘焙进 PNG，不重复叠加 Unity Shadow。按下时换用 `plate-pressed` 并仅下移视觉内容 3 个参考像素，根节点/点击区域不移动。图标和文字分别渲染，文字不烘焙进切图。

派生图集/底板/地图不是逐像素复制批准图，批准源图与参考裁片保留供比对。图片导入及视觉效果仍需使用目标 Unity 版本在运行界面中验收。
