`motion.json` version 3 retains three cloud depths, but each cloud entry now lists independent cropped sprites. The 30 scenes contain 332 sprites: 207 static slanted clouds, 38 large horizontal clouds, and 87 smaller horizontal clouds. Existing layer PNGs remain available as exact static prefab artwork. The sprite split preserves every painted pixel; no artwork is regenerated or recolored.

Runtime validation accepts zero velocity, and versions 1/2 remain supported. The fixed celestial layer remains stationary.

The maximum foliage displacement is 7.2 source pixels, evaluated at 24 FPS when the scene is visible. Water remains a separate art layer; the existing Overlay water effects are independent.

The approved 2172 x 724 panoramas supply the visible tree, architecture, shore, water and celestial pixels.
