## 场景行为

当前鱼塘 ID＋真实玩家身份决定是否在钓鱼场景，不依赖是否正在抛竿；包括入塘后空闲、坐下、等待、钓鱼和塘内菜单。默认 pond ID 不会误开环境声；短暂断线仍在塘内时保持音乐禁用。

`DesktopAudioService.UpdateContext` 直接同步场景状态，Unity 与 WPF Overlay 都通过同一个 Unity 播放器：

- 入塘暂停音乐并置其输出为0；音乐异步解码完成、调整音乐音量均不能绕过场景限制。
- 全部 UI 语义 cue（点击、打开、关闭、切换、滑杆试听、成功／错误）静默消耗事件；额外在声源请求入口阻挡 UI，进入场景时清空已经播放及待替换的按钮音。
- 保留动作水声、咬钩提示和猫叫，原有四个短声部不变；环境声独立循环、流式解码。退出鱼塘恢复原音乐／按钮行为，保存的音乐和音效音量不变。
- 自然环境声以2秒平滑淡入／淡出；跟随既有音效音量，设为0立即停止，恢复时淡入。音乐音量不影响环境声。
- 全部窗口隐藏时环境声淡出，Unity隐藏而原生Overlay可见则正常播放。稳定循环不额外请求高帧率，只有过渡／关键提示沿用既有后台渲染租约。

## 环境声

新增 `Audio/ambience/pond_shore.wav`：48秒，44.1kHz、PCM16、原始立体声。采用ceich93的CC0河岸实录 [Water_Lapping_River.wav](https://freesound.org/people/ceich93/sounds/318064/)，轻水波拍岸和自然近水细节。对连续56秒片段轻滤低频风噪和高频毛刺，用8秒交叉过渡生成循环；未添加音乐、合成噪声、人声、鸟叫或硬压限。

[资源清单](../../../fish-social-unity/Assets/StreamingAssets/Audio/ambience-manifest.json)／[来源及资产验证](2026-10-30-pond-ambience-assets.json)。音频SHA256：`89127aa0c8235f7913fa5c6c0f25f4fd731ccb2ca1b20085a8666604db633289`。运行时增益0.65×音效音量，淡入淡出2秒；参数由独立manifest配置。

原47条音乐／音效WAV和cue-config哈希保持不变；此次新增独立环境声清单，完整资产校验现覆盖48条WAV，不改写历史采用记录。

## 验证

- **Unity EditMode 34/34通过**：[测试摘要](pond-asmr-2026-10-30/tests.json)／[原始XML](pond-asmr-2026-10-30/editmode.xml)。覆盖场景静音、原生与Unity按钮拦截、预加载竞态、全局音量保留、环境声淡入淡出／隐藏／静音，以及原有事件与四短声部仲裁。真实UnityWebRequest解码48条WAV通过，音乐和环境声使用流式选项，短音缓存仍3,383,056字节（<4MiB）。
- **资源和满音量混音检查通过**：[测量JSON](2026-10-30-pond-asmr-verification.json)。环境声4×真峰0.259992，循环首尾PCM差0，相邻变化小于录音内部普通波动；钓鱼场景满音量最坏组合上界 **−3.06184dBTP**（2钓鱼＋1猫叫＋环境声，不含已禁用的BGM／UI）。
- **可重建**：固定源SHA及许可证据校验通过，重复生成音频、清单和meta哈希一致。现有47条采用音频与cue配置校验通过。
- 更新22I规格、提示词与主计划说明，设计日期保留2026-10-24，完成日期2026-10-30；执行package.json中`planning:master-xlsx`对应的两个Python生成器，同步计划表和看板。其他功能的代码或状态未另作修改。

本次为macOS Unity编辑器验证，未生成Windows安装包，也未进行Windows耳机／扬声器听感或画声延迟实测。数值检查不代替人工听感判断。

## 复现

```sh
python tools/audio/build_pond_ambience.py --sources <cache>
python tools/audio/verify_desktop_audio.py
python tools/audio/verify_pond_ambience.py
```

Unity编辑器选择 `FishSocial.Tests.Editor.DesktopAudioTests` 运行EditMode测试；也可使用 `-batchmode -runTests -testPlatform EditMode -testFilter FishSocial.Tests.Editor.DesktopAudioTests`。当前正式资源位于 `fish-social-unity/Assets/StreamingAssets/Audio/`，由既有构建流程包含进游戏。
