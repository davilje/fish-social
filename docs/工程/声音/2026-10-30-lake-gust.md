## 风带动树叶

1. 入场或恢复后，先等待6–12秒。
2. 风声平滑渐起，持续6–10秒；2–4秒后加入叶响。
3. 风先退，叶声留一段尾音；叶响总长6–9秒，整阵有2秒起音／3秒收尾包络。
4. 整阵结束后安静20–38秒，再随机出现下一阵。水声继续铺底。

风叶各自非循环，随机片段起点限制在录音有效范围。单轨音量归零取消它本阵已排或在播的声音，恢复不补播旧阵。切塘、离塘、全部隐藏、总静音或组件禁用取消旧阵，重新允许播放时从新的入场等待开始。水声切换使用两条固定声源交叉淡化；三档试听快速切换不会增加声源。Unity 共9条固定声源：音乐1、水声2、风1、叶1、原短音4。

环境包络在音频线程按 DSP 时间计算，风叶使用定时播放和停止；环境过渡与安静间隔都不申请持续高帧率。音效总音量和原三轨保存音量继续生效。

## 预览

右侧可选择鱼塘，自动带出对应湖面；也可比较「平静湖面」「轻晃水面」「原河岸水声」。水声只保留一种，切换时柔和衔接。「自动环境」按正式间隔播放；「立即听风起叶响」可立即听完整一阵；风／叶各有单次试听及独立音量。首次加载不自动播放。

## 复现

```sh
python tools/audio/build_pond_ambience.py --sources <shore-cache>
python tools/audio/build_pond_wind_leaves.py --sources <leaf-cache>
python tools/audio/build_lake_gust_ambience.py --sources <lake-wind-cache>
python tools/audio/verify_desktop_audio.py
python tools/audio/verify_pond_ambience.py
```

配置源为`tools/audio/pond_scene_config.py`，组装后的`ambience-manifest.json`为version3，含水面档位、21塘映射及风叶间隔。两个旧生成命令只刷新原河岸／叶声资源，保留新版场景配置，不会重新引入已停用风声。
