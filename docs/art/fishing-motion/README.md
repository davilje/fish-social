# 钓鱼动作对照 · 22D / 22F

打开 `index.html`，可直接通过 `file://` 查看。左侧为原时间表，右侧为新的运动采样及按阶段循环。

- 十种现有角色共用道具运动数据，各自的身体、头、手素材保持原样。
- 覆盖 14 种动作：入座、挂饵、抛竿、等待、咬钩、发力、咬钩接发力、收杆、空军、展示收获、两种复位、打窝、离席。不增加 PNG，不修改单段总时长。
- 入座、离席、挂饵、收获和复位采用绕脚底的整体微转；头、身体、双手保持相对位置，手持鱼不单独移动。身体姿势形变仍来自原绘制帧。
- 等待新增浮标轻摆；发力末帧接回循环起点。静态 `idle`、`ready` 不额外动画。
- 咬钩鱼顶部至少下沉到水面下 64 个原画坐标单位；撒料阶段增加渐进下落。可调整水面高度对照旧落点。
- 打窝可设置持续秒数或点击「结束打窝」，结束后收手并恢复准备。
- `source-rig.json` 保留原工作台的轨迹坐标；`preview-data.js` 与正式 `motion-samples.json` 同源生成。
- `browser-verification.json`、六张 comparison 截图为本轮 Web 检查结果；不是 Windows 原生截图。

完整接入、复跑和限制见 [交付说明](../../engineering/animation-interaction/2026-10-24-overlay-motion-22df.md)。
