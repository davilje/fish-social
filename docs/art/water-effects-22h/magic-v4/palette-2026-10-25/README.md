正式WPF、Unity及Web采用同一套预热时缓存的调色映射，覆盖8水花＋8波纹＋2水滴：深蓝(27,82,114)、浅青白(181,240,245)、奶白(255,247,224)。按原图绿通道125到210归一，0.32分段线性插值，保留原稿明暗与alpha；纹理像素轮廓不变。每张只处理一次，不逐帧扫描像素。较亮的水体和泡沫形成主辨识，深蓝暗部保留层次。

预览默认使用用户参考图，并保留浅水／深水切换；纹理对照同步显示游戏实际配色。参考图上等待波纹、抛竿和鱼出水截图位于上一目录 `production-reference-FX02.png`、`production-reference-FX01.png`、`production-reference-FX05.png`。
