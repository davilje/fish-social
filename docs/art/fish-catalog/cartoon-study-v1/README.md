此目录保留已确认的六种风格样稿。用户确认后，正式 50 种鱼图已按此方向统一；对照页旧版来自 `../realistic-v1/` 归档。

- 样稿：鲫鱼、锦鲤、鳜鱼、带鱼、中华鲟、黄鳝。
- 独立透明 PNG：`assets/<speciesId>.png`。
- 新旧对照：`index.html`，支持深色、白色背景和小图辨识切换。
