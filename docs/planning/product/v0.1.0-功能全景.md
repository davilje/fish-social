## 1. 产品概述

Fish Social（钓鱼社交）是一款休闲社交挂机钓鱼游戏。玩家在世界地图上选择鱼塘区域进入场景，与其他玩家（及机器人）同塘挂机钓鱼，钓获鱼种入背包后可出售换金币、分享到动态墙，并通过好友系统私聊互动。

**产品定位**：多人在线鱼塘挂机钓鱼 + 轻量社交（动态墙、好友、私聊）+ 鱼塘生态模拟。

### 1.1 版本演进

| 版本 | 内容 |
|------|------|
| **v1** | 世界地图、二维鱼塘、实时同步、鱼塘聊天、背包、每日 8 小时钓鱼限制 |
| **v2** | 好友、动态墙、关注流、分享隐私、卖鱼换金币 |
| **v2.1** | 机器人系统（自动进塘、钓鱼、分享、发好友申请） |
| **v2.2** | 登录页、个人信息、8 格收藏品展示 |

### 1.2 辅助工具

根目录 `preview.html`：无需安装依赖的浏览器预览工具，含功能概览、架构说明、本地钓鱼模拟器、服务在线检测与一键跳转。

- **鱼塘**：连接超时 4 秒后进入演示模式，本地模拟钓鱼、聊天、上钩（`rollFishCatch` 随机生成，非生态实体鱼）
- **社交 / 卖鱼**：需服务端在线，否则 API 失败

## 3. 用户角色与权限

### 3.1 角色类型

| 角色 | 标识 | 行为 |
|------|------|------|
| **普通玩家** | `p_{timestamp}_{random}` | 完整游戏与社交 |
| **钓鱼机器人** | `bot-{uuid}` | 自动进塘、钓鱼、分享、发好友申请；被真人挤占时驱逐 |
| **管理员** | 持有 `ADMIN_SECRET` | 查看生态、重置生态、清理用户、查看错误日志 |

### 3.2 认证模型

- **无密码、无 OAuth**：客户端生成 `playerId`，输入昵称（≤12 字）即登录
- 会话字段：`playerId`、`nickname`、`avatarUrl`、`loggedIn`
- 未登录访问受保护页面 → 重定向 `/login`
- **服务端无会话校验**：REST API 仅凭 `playerId` 操作（信任客户端模式）

### 3.3 权限规则

| 操作 | 限制 |
|------|------|
| 加入鱼塘 | 每塘最多 20 人；满员时驱逐机器人 |
| 钓鱼 | 每人每天最多 8 小时（跨会话累计，SQLite 持久化） |
| 鱼塘聊天 | 须先 `join_pond`；消息最长 200 字 |
| 私聊 | **仅好友**可发；消息最长 300 字 |
| 动态可见性 | `public`（所有人）/ `friends`（仅好友，在关注流中过滤） |
| 收藏品 | 只能展示自己背包中存在的鱼 |
| 管理员 API | 请求头 `X-Admin-Key` 或 query `key` |

### 3.4 机器人特殊规则

- 向机器人发好友申请 → **自动同意**（`autoAccepted: true`）
- 机器人主动发好友申请：每分钟 15% 概率，4 分钟冷却
- 真人进塘满员或占机器人钓点 → 驱逐机器人并广播 `pond_user_left`

### 5.3 鱼塘场景与挂机钓鱼（v1 核心）

**场景尺寸**：400×440（斜 45° 正交视角）  
**钓位**：每塘 20 个，均匀分布在池塘外缘圆环（半径 rx=158, ry=128）

#### 5.3.1 视觉组件

| 组件 | 功能 |
|------|------|
| `PondScene` | 等距水面 + 钓位码头 + 角色（圆圈头像 + 昵称 + 钓鱼动画） |
| `PondSocialPanel` | 在线钓友横向 chips（头像+昵称，可开资料弹窗）+ 鱼塘聊天 |
| `ChatPanel` | 鱼塘聊天（可嵌入 `PondSocialPanel`）；系统公告以 📢 样式展示 |
| 底栏 | 今日剩余时长、生态信息、开始/收起鱼竿按钮 |

#### 5.3.2 钓鱼完整流程

```
加入鱼塘(join_pond) → 选择/自动分配钓点 → 开始钓鱼(start_fishing)
→ 每5秒检测上钩 → 咬钩成功(fish_bite) / 失败(fish_miss)
→ CatchFishModal 5秒倒计时 → 确认获得(accept_catch) → 入背包
→ 史诗及以上 → 鱼塘公告 + 自动发动态(含纪念照)
```

#### 5.3.3 核心数值

| 参数 | 值 | 代码位置 |
|------|-----|----------|
| 上钩检测间隔 | 5 秒 | `shared/constants.ts` |
| 基础咬钩概率 | 14%（× 钓点权重 / 0.17） | `shared/constants.ts` |
| 咬钩后成功率 | 70% | `shared/constants.ts` |
| 失败原因 | 空军 `empty`（50%）/ 脱钩 `escaped`（50%） | `server/src/index.ts` |
| 弹窗自动关闭 | 5 秒 | `shared/constants.ts` |
| 每日钓鱼上限 | 8 小时 | `shared/constants.ts` |
| 每塘人数上限 | 20 人 | `shared/constants.ts` |
| 聊天历史保留 | 100 条 | `shared/constants.ts` |
| 同时 pending 鱼获 | 每用户仅 1 条 | `server/src/inventory.ts` |

#### 5.3.4 钓点选择逻辑（客户端）

开始钓鱼时自动选择：

1. 空闲钓点
2. 若无空闲，选择被机器人占用的钓点（服务端驱逐该机器人）

真人不可抢占真人已占钓点。

#### 5.3.5 鱼获来源（服务端）

- 从鱼塘**生态实体鱼**（`pond_fish` 表）按钓点权重选取（`pickFishForBite`）
- 品质由**实际尺寸**推算（`deriveQualityFromSize`），非独立随机
- 领取时从 `pond_fish` 删除；若已被他人钓走则失败（「这条鱼已被他人钓走」）
- 待领取状态存内存 `pendingByUser`

#### 5.3.6 高品质公告

- 品质 ≥ **紫色（史诗）** 触发鱼塘系统公告
- 文案：`{昵称}钓到了【{品质名}】的{鱼种名}！`
- 同时 `autoShareEpicCatch` 发布动态（可见性取玩家默认分享设置）

#### 5.3.7 用户颜色

8 种循环分配：`#E57373`、`#64B5F6`、`#81C784`、`#FFB74D`、`#BA68C8`、`#4DD0E1`、`#F06292`、`#A1887F`

### 5.4 鱼塘生态系统

每 30 秒 `tickAllPonds()`，广播 `pond_ecology_updated`。

#### 5.4.1 各塘库存配置

| 鱼塘 | 常见鱼种 | 稀有鱼种 | 初始/最小/最大种群 | 稀有产出率 |
|------|----------|----------|-------------------|------------|
| 静心湖 | 鲫鱼、鲤鱼、罗非、河鲈 | 桂鱼、鳟鱼 | 48 / 12 / 80 | 10% |
| 云雾塘 | 鳟鱼、鲱鱼、鳕鱼、河鲈 | 三文鱼、狗鱼 | 42 / 10 / 70 | 12% |
| 夕阳湾 | 金枪鱼、鲭鱼、鲷鱼、三文鱼 | 旗鱼、鲟鱼 | 36 / 8 / 60 | 14% |
| 竹林池 | 锦鲤、鲤鱼、鲫鱼、鲶鱼 | 黑鲈、鳗鱼 | 45 / 10 / 75 | 11% |

#### 5.4.2 生态机制

| 机制 | 规则 |
|------|------|
| **成长** | 每 tick 按小时折算，增量 = `typicalMinM × 0.012 × hours`；上限 = `min(50m, typicalMaxM × 3.2)` |
| **繁衍** | 每 tick 8% 概率；同种两条鱼繁殖，子代 `generation+1` |
| **枯竭** | 鱼群被钓至 0 → 进入枯竭状态，**15 分钟**后恢复并播种至 `minPopulation` |
| **钓点权重** | 每 5 分钟刷新，每钓点权重 **0.06~0.34** 随机；影响上钩概率 |
| **选鱼算法** | `权重 = (0.5 + 尺寸加成) × 钓点亲和 × 钓点权重` 加权随机 |

**生态 UI 展示**（鱼塘底栏）：

- 正常：`鱼群 {count}/{maxPopulation} · 常见{鱼种列表}`
- 枯竭：`鱼塘恢复中 · 剩余倒计时`

### 5.7 社交系统（v2）

**页面**：`/social`，5 个 Tab

#### Tab 1：动态墙

- `GET /api/posts/wall` — 仅 `visibility=public`
- `PostCard`：头像、昵称、时间、纪念照（史诗+）、鱼获文案、品质、可见性标签
- 点击用户 → `UserProfileModal`

#### Tab 2：关注（好友动态流）

- `GET /api/posts/friends/:playerId`
- 包含：自己的帖子、公开帖、好友的 `friends` 可见帖
- 最多保留 **500** 条（服务端 trim）
- **注意**：Tab 名「关注」，实际逻辑是好友动态流（非单向关注）

#### Tab 3：好友

- **搜索**：昵称或 playerId 模糊匹配，最多 20 条
- **发申请**：`POST /api/friends/request`
- **待处理申请**：同意 / 拒绝
- **好友列表**：头像昵称，可跳转私聊或查看资料
- **实时通知**：Socket `friend_request` 事件刷新列表

#### Tab 4：私聊

- 会话列表：`GET /api/dm/conversations/:playerId`（最后消息、未读数）
- 打开会话：`GET /api/dm/:playerId/:friendPlayerId`（同时标记已读）
- 发送：`POST /api/dm`；对方在线时 Socket `dm_message` 推送
- 气泡：自己右对齐蓝色，对方左对齐灰色
- 私信总量上限 **1000** 条（全局 trim）

#### Tab 5：设置

- 默认分享可见性：`public` / `friends`
- 显示自己的 playerId
- 入口：Debug / 管理员工具 → `/admin`

#### 动态发布方式

1. 背包手动分享
2. 钓到史诗+鱼自动分享（含纪念照）
3. 机器人随机分享（45% 概率，非史诗；史诗必公告+发帖）

#### 钓鱼纪念照

- 史诗及以上动态自动附带 `photoUrl`
- 根据玩家默认头像映射到 `/image/fishing_photos/cat_fishing_{id}.png`（6 种与默认头像一一对应）
- 自定义 Base64 头像则按 `playerId` 哈希稳定分配

### 5.9 机器人系统（v2.1）

| 参数 | 值 |
|------|-----|
| 生成检测 | 每 45 秒，40% 概率 |
| 每塘上限 | 6 个 |
| 停留时间 | 1~3 小时随机 |
| 开始钓鱼概率 | 每 tick 28%（idle 时） |
| 停止钓鱼概率 | 每 tick 3%（**收竿后保留原钓位**） |
| 分享概率 | 45%（非史诗） |
| 好友申请 | 15% 概率/分钟，4 分钟冷却 |

**昵称池**（15 个）：湖边小王、静默钓手、晨雾渔人、夕阳老张、竹林隐者、微风钓客、江湖渔翁、浅水阿杰、远投高手、夜钓达人、悠闲钓妹、湖心居士、云雾行者、甩竿少年、静待鱼儿

**让位机制**：

- 真人进塘满员 → 循环驱逐机器人直至有空位
- 所有钓点被占且仍有机器人 → 继续驱逐
- 真人占机器人钓点 → 驱逐该机器人
- 驱逐时广播 `pond_user_left`

## 8. 数据模型

### 8.1 SQLite 表

**players**：`player_id`(PK)、`nickname`、`coins`(默认0)、`share_visibility`、`avatar_url`、`bio`、`showcase_fish_ids`(JSON 8格)、`created_at`

**inventory**：`id`(PK)、`player_id`(FK)、`species_id`、`quality`、`size_m`、`caught_at`

**daily_fishing**：`user_id` + `date_key`(复合PK)、`ms`

**pond_fish**：`id`(PK)、`pond_id`、`species_id`、`quality`、`size_m`、`born_at`、`generation`

**pond_state**：`pond_id`(PK)、`depleted_until`、`last_weight_refresh`

**spot_bite_weights**：`pond_id` + `spot_id`(复合PK)、`weight`

**social_posts**：`id`(PK)、`player_id`、`nickname`、`author_avatar_url`、`fish_json`、`text`、`photo_url`、`visibility`、`created_at`

**friend_links**：`player_id` + `friend_id`(复合PK)、`since`（双向各存一行）

**friend_requests**：`id`(PK)、`from/to_player_id`、`from/to_nickname`、`status`、`created_at`

**dm_messages** / **dm_read_cursor**：私信消息与已读游标

### 8.2 内存模型

- `sessions`：socketId → { userId, playerId, pondId, nickname }
- `pondUsers`：pondId → Map<userId, PondUser>
- `pondChats`：pondId → ChatMessage[]（最多 100 条）
- `pendingByUser`：userId → PendingFishCatch
- `botMeta`：userId → { playerId, pondId, leaveAt }
- `playerSockets`：playerId → socketId
- `errorLogs`：最多 200 条

## 9. 核心业务流程

### 9.1 新用户完整旅程

```
打开 App → /login 输入昵称+头像 → 注册 playerId
→ 世界地图选区域 → 进入鱼塘(WebSocket join_pond)
→ 点击「开始钓鱼」→ 等待上钩弹窗 → 获得鱼入背包
→ 史诗鱼自动公告+动态 → 打开社交中心查看
→ 背包卖鱼得金币 / 手动分享 → 搜索好友 → 私聊
→ 个人页设置收藏品展示
```

### 9.2 钓鱼竞争流程

```
多玩家同塘 → 钓点占用互斥（真人不可抢真人钓点）
→ 鱼从 pond_fish 实体移除 → 同一条鱼 pending 只能被一人领取
→ 鱼群枯竭 → 15分钟恢复 → 继续可钓
```

### 9.3 好友社交流程

```
搜索 ID/昵称 → 发申请 → 对方收到 Socket 通知
→ 同意 → 双向 friend_links → 可私聊、可见 friends 动态
→ 向机器人申请 → 自动同意
```

### 9.4 管理员运维流程

```
社交设置页进入 /admin → 输入密钥 → 查看生态/日志
→ 必要时重置生态或清理测试用户数据
```

## 11. 游戏机制汇总

| 机制 | 说明 |
|------|------|
| 挂机钓鱼 | 开始钓鱼后被动等待随机上钩，无 QTE |
| 资源竞争 | 鱼塘鱼实体有限，钓完进入 15 分钟恢复 CD |
| 生态循环 | 成长 → 繁衍 → 被钓走 → 枯竭 → 恢复播种 |
| 钓点 meta | 权重每 5 分钟刷新，鼓励换点 |
| 每日体力 | 8 小时钓鱼上限 |
| 品质成长 | 鱼越大品质越高（尺寸驱动） |
| 社交激励 | 史诗鱼全塘公告 + 纪念照动态 |
| 经济循环 | 卖鱼 → 金币（**暂无消耗闭环**） |
| NPC 填充 | 机器人维持鱼塘人气与动态活跃度 |

## 12. 已知限制与策划注意点

1. **无账号安全**：任何人知道 `playerId` 即可调用 API 操作该账号
2. **金币无消费**：经济系统半成品
3. **他人主页**：不展示金币；无独立 `/profile/[playerId]` 页面（仍为弹窗）。世界地图点头像直进 `/profile` 编辑；鱼塘/社交点头像开弹窗
4. **聊天/在线状态不持久**：重启服务端清空鱼塘聊天与在线用户
5. **图片资源**：`image/` 目录需单独准备（默认头像、纪念照）
6. **iOS / 原生端头像上传**：仅 Web 支持自定义上传，移动端仅默认头像
7. **admin 路由**未在 `_layout.tsx` 显式注册，但 Expo Router 文件路由仍可达 `/admin`；世界地图顶栏 ⚙ Debug 为一级入口，社交设置内保留备用链接
8. **未集成**：OAuth、支付、推送通知（FCM/APNs）、分析、CDN、云数据库、反作弊

**v0.1.1 已修复（见 [BUG修复-四项体验问题](../specs/BUG修复-四项体验问题.md)）**：好友弹窗关闭闪屏、同鱼双 pending、头像弹窗不统一、管理入口过深。
