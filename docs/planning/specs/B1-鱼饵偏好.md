# B1 — 鱼饵鱼种偏好

## 元信息

| 字段 | 内容 |

## 1. 目标

让不同鱼饵对不同 diet（草食 / 杂食 / 肉食）鱼种产生差异化加成，增加钓鱼策略深度：
- 玩家选饵不再是「买最贵的」，而是「为目标鱼选饵」
- 高价 live 饵对草食鱼性价比反而不如便宜的 corn

## 2. 范围

### In-Scope

- 鱼饵配置扩展 `affinityByDiet` 字段
- `FishSpecies.diet` 落配置数据（A0 已加字段）
- 服务端 `baitBiteBonus` 计算改单参→双参（baitId + speciesId）
- 商店 UI 增强：显示饵的偏好标签
- A2 Debug 面板显示玩家当前装备饵的差异化效果

### Out-of-Scope

- 渔具偏好（不做）
- 饵对脱钩率的影响（不做）

## 3. 数据模型

### 3.1 鱼饵配置扩展

```ts
interface Bait {
  id: string;
  name: string;
  price: number;
  globalBonus: number;
  affinityByDiet?: Partial<Record<FishDiet, number>>;
  consumed: boolean;
}

type FishDiet = 'herbivore' | 'omnivore' | 'carnivore';
```

### 3.2 数值定稿

| 鱼饵 | globalBonus | affinityByDiet | 草食总加成 | 杂食总加成 | 肉食总加成 |
|---|---|---|---|---|---|
| basic | 0 | — | 0 | 0 | 0 |
| corn | +0.02 | herbivore +0.06, omnivore +0.02 | **+0.08** | +0.04 | +0.02 |
| pellet | +0.05 | all +0.03 | +0.08 | +0.08 | +0.08 |
| live | +0.04 | carnivore +0.14, omnivore +0.04 | +0.04 | +0.08 | **+0.18** |

**设计意图**：
- corn 定位「草食鱼专用高性价比饵」
- pellet 定位「万金油」中档饵，无策略负担
- live 定位「肉食鱼/大鱼专用高投入饵」，草食鱼吃它反而不划算

### 3.3 FishSpecies.diet 落数据

| diet | 示例鱼种 |
|---|---|
| herbivore | crucian, carp, tilapia, grass carp |
| omnivore | perch, herring, mackerel |
| carnivore | bass, trout, mandarin, tuna, salmon, pike, marlin, sturgeon |

**兼容性**：无 `diet` 字段的历史配置默认按 `omnivore` 处理，不报错。

## 4. 计算公式

```
baitBiteBonus(baitId, speciesId) =
  bait.globalBonus +
  (bait.affinityByDiet?.[species.diet] ?? 0)
```

服务端 tick 计算：

```
w_i = (fish.biteWeight ?? species.biteWeight)
    + spotBite
    + baitBiteBonus(player.equippedBait, fish.speciesId)   // 变化点
```

## 5. UI 增强

### 5.1 商店鱼饵条目

每条鱼饵条目下方新增偏好标签：

```
🌽 玉米粒            50 金币
   基础 +0.02
   [ 草食鱼偏好 +0.06 ] [ 杂食鱼 +0.02 ]
```

点击标签可展开完整加成说明与代表鱼种列表。

### 5.2 图鉴（如已有）

鱼种详情页显示 `diet` 与「推荐鱼饵」。若图鉴未做（属 C5），本项跳过。

### 5.3 A2 Debug 面板增强

`fishContributions` 中 `effectiveWeight` 现受 diet 影响。前端展示当前查询玩家已装备的饵类型，供策划断言差异化生效：

```
[钓点 A] 当前查询：玩家 alice 装备 live
  ┌──────────┬──────┬────────┬───────┐
  │ 鱼种     │ diet │ effWt  │ 占比  │
  ├──────────┼──────┼────────┼───────┤
  │ tuna     │ carn │ 0.324  │ 32%   │
  │ carp     │ herb │ 0.184  │ 18%   │
  └──────────┴──────┴────────┴───────┘
```

## 7. 验收标准

- [ ] 装备 corn 时，草食鱼 `effectiveWeight` 增量 = 0.08（globalBonus 0.02 + affinity 0.06），肉食鱼仅 0.02
- [ ] 装备 live 时，肉食鱼 `effectiveWeight` 增量 = 0.18，草食鱼仅 0.04
- [ ] 装备 pellet 时，所有鱼 `effectiveWeight` 增量均为 0.08
- [ ] Debug 面板同一鱼在 corn / pellet / live 三种饵下 `effectiveWeight` 差异符合表格
- [ ] 商店偏好标签正确显示
- [ ] 无 `diet` 字段的历史配置默认按 `omnivore` 处理，不报错
- [ ] 一次咬钩全流程（含加成）与手算结果误差 < 0.001

## 8. 风险

| 风险 | 缓解 |
|---|---|
| 玩家不理解 diet 归类 | UI 明确「玉米 · 草食鱼偏好」文案；图鉴（若做）标注鱼种食性 |
| B0 上线后玩家形成「买最贵」习惯，B1 上线时反弹 | 商店首页 banner 提示「新玩法：饵有偏好」+ 一次性引导；给存量玩家发一份免费 corn 试用 |
| 数值失衡导致 corn 一饵通吃草食 | corn 仅对 herbivore 有偏好，omnivore 加成较小；肉食鱼几乎无效 |
