## 1. 背景与目标

### 1.1 背景

09D 规定默认用 **状态 icon + 上钩圆环**，短文案可选。实现却用了头顶文字徽章（「钓鱼中」「上钩」）。圆环直径 56 放在高 18px 的行里，看起来像浮在头顶，而不是套在 64×64 猫身上。

### 1.2 目标

- **常驻 UI 不再出现相位中文**（钓鱼中/上钩/收杆等）。
- 钓鱼中、上钩用 **16～20px 小图标**。
- 上钩进度圆环 **套在猫身外圈**（直径约 72～80，线宽 2～3），进度仍为 `(hookDeadlineMs - now) / total`。
- 时长只在 09B 悬停浮窗（本局 / 收杆剩余）。

### 1.3 非目标

- 不改 `fishingPhase` / Pipe 字段。
- 不把时长搬回头顶。
- idle / seated / 未钓：无 icon、无圆环（与 09D 一致）。
- 不改 `server/` / `shared/` / `mobile/`。

---

## 2. 用户与场景

| 角色 | 场景 | 期望结果 |
|------|------|----------|
| 玩家 | 等鱼 | 猫上方或肩角一枚「钓鱼中」小图标；无「钓鱼中」三字 |
| 玩家 | 上钩 | 小图标（可选咬钩）+ 猫身外圈进度环从满收到空 |
| 玩家 | 坐下未开钓 | 只有昵称 + 猫，无 icon/环 |
| 玩家 | 悬停猫身 ≥300ms | 仍仅时长（09B），不含相位字重复 |

布局：

```text
        [昵称]
     [16–20px icon]     ← 仅 fishing / hooked 等需展示的相位
        [ 圆环套猫 ]
        [ 64×64 猫 ]
```

## 3. 功能范围

| # | 功能点 | 优先级 | 说明 |
|---|--------|--------|------|
| 1 | 去掉头顶字徽章 | P0 | 隐藏/删除 `_statusBadge` 相位文案 |
| 2 | 状态 icon | P0 | 资源见下；缺图可用极简矢量占位 |
| 3 | 圆环改挂猫身 | P0 | 与 `_body` 同心，不要放在 18px 矮行 |
| 4 | 悬停 | P0 | 09B 热区仍为猫身 64×64；文案仍仅时长 |

### 3.2 图标路径

```text
desktop-overlay/OverlayResources/status/fishing.png
desktop-overlay/OverlayResources/status/hooked.png
```

也可放在 `hud/`。构建拷到 exe 旁。圆环程序绘制，不出序列帧。

相位 → icon：`waiting`/`fishing` 等「竿在水里」→ `fishing.png`；`hooked` → `hooked.png`（可与环同时）。`cast`/`reel` 若需 icon 用同一套目录加文件，P1。

- [x] 等鱼/上钩时头顶无「钓鱼中」「上钩」等相位字
- [x] 对应相位显示 16～20px 小图标
- [x] 上钩圆环套在猫身外、进度随 `hookDeadlineMs` 变化；idle/坐下无环
- [x] 悬停仍仅时长；热区仍为 64×64 猫身
- [x] 缺 icon 不崩
- [x] 不改 `mobile/`、`server/`、`shared/`
