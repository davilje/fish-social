## 问题

Windows Development Build 点击右上角关闭后，`FishSocialDesktop.exe` 被
`Application.wantsToQuit` 拦截并隐藏到托盘，进程继续驻留。重复启动会产生
多个后台实例，用户误以为程序已经关闭。

## 修复范围

- 右上角关闭按钮直接结束 Unity 进程。
- 托盘菜单仍可显式执行“隐藏窗口”。
- 托盘“退出游戏”继续执行正常退出流程并清理托盘线程。
- 增加单实例互斥锁，阻止重复启动多个桌面端进程。
- 不结束 Unity Editor、Unity Hub 或 Node.js 开发进程。

## 验收标准

- [x] 关闭 EXE 后 `FishSocialDesktop.exe` 消失。
- [x] 对应 `UnityCrashHandler64.exe` 随主进程退出。
- [x] 托盘显式隐藏仍可保留后台运行。
- [x] 托盘“退出游戏”可以完全退出。
- [x] 重复启动不会创建第二个桌面端实例。
- [x] 退出时托盘图标和托盘线程被清理。
