## 1. 背景与目标

### 1.1 背景

现网 20 种为中外混合（金枪、旗鱼、三文鱼、鳕鱼等），20 塘为 fantasy 名（静心湖等），种池由 `STOCK_TEMPLATES` 四模板轮转，**与中国垂钓认知不符**。用户定稿：全面替换为本土鱼种，塘名改为知名钓场/水域，并按现实分布分区出鱼。

### 1.2 目标

- 鱼种扩充至 **50 种**：中国常见为主体 + 少量稀有/巨物；**全面替换**旧 ID（外来主叙事种删除）。
- **塘名改为真实钓场**；`pondId` **不变**（避免进度/社交断链）。
- **每个塘可出哪些种** 仅由 `pond_fish_pool` 记录（权威）；`ponds.bioRegion` / `waterType` / `realWorldRef` 作策划标注与地图文案。
- **不设** `fish_species_habitat` 表（曾用 bioRegion 间接生成池；已废弃，改直接维护 pool）。
- 种稀有度决定 **品质上限**（`qualityMin` 恒为 gray=1；`qualityMax` 随 `rarityTier`）；与 POOL-01 塘分级品质权重求交。
- `typicalMinM` / `typicalMaxM`：**仅图鉴展示**；出生体长跟品质 `sizeCapM`。
- 尺寸上限仍按品质；咬钩/脱钩**公式不变**（POOL-01）。

### 1.3 非目标

- 新增第 21 塘、改 tile 场景几何。
- 改卖价 / XP 公式形状（新种走既有 `catchGroup` 系数即可）。
- 保护动物玩法争议：中华鲟/达氏鲟仅作 **稀有图鉴向巨物**，不鼓励商业化文案。
- Mobile 图鉴全量对齐。
- 恢复或依赖 `fish_species_habitat` sheet。

### 3.3 生物区枚举（标注用）

`east_plain_lake` · `yangtze_mid` · `southwest_plateau` · `northeast_cold` · `south_reservoir` · `southeast_coast` · `north_bohai` · `south_sea`

说明：`bioRegion` 写在 `ponds` 上，便于策划对照与 QA；**运行时出鱼不读 habitat 表**，只读该塘 `pond_fish_pool`。

### 3.4 出鱼规则（定稿）

```text
种：  candidates = pond_fish_pool[pondId] where enabled
      speciesId = weightedPick(spawnWeight)

品质：weights = pond_category_quality_weights[pond.pondCategory]
      ∩ species.qualityMin … qualityMax（序 1=gray … 7=gold）
      quality = weightedPick(weights)
      交集为空 → gray

体长：rollJuvenileSize(quality)  // 品质 sizeCapM；不读 typical*
重量：展示用 W = a × L^b（LENGTH_WEIGHT_A/B）；不落库
```

**种品质带（稀有度只抬高上限；下限恒 1）**

| rarityTier | qualityMax（序） | 上限品质 |
|------------|------------------|----------|
| common | 4 | purple |
| uncommon | 5 | red |
| rare | 6 | orange |
| legendary | 7 | gold |

**练杆塘**：pool 仅 `crucian` / `carp` / `loach`；塘 category 品质权重为 gray–green。

**巨物塘（兴凯湖）**：冷水鲑鳟 + 广布少量；`taimen` 等 spawnWeight 压低。
