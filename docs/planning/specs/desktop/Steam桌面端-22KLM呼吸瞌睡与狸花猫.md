## 范围

- **STEAM-DESKTOP-22K**：持续等待时呼吸，身体与握竿图层同步，脚底固定；呼吸不累计缩放，鱼线连接移动后的竿尖，浮漂保留水面位置。
- **STEAM-DESKTOP-22L**：服务器判定瞌睡、持久化及脱钩；客户端闭眼、慢呼吸、轻微前倾与 Zzz；真实点击照看，不能用播放动画、收到快照或 ACK 代替唤醒。
- **STEAM-DESKTOP-22M**：新增狸花猫「丧彪」，灰棕毛、深色虎斑与额头 M 纹、环纹尾、黄绿眼；沿用现有完整姿势和九层资源契约，使用绘制素材，不以旧猫改名代替。

## 玩法契约

`FISHING_SLEEP_AFTER_MS` 默认 `1800000`；允许 `60000–86400000`，`0` 禁用新的入睡。修改配置不会自动唤醒已经睡着的角色。

开始一次钓鱼会话或有效触碰更新照看时间。自动续钓、换皮、快照和重连不重置。到期仅在等待阶段入睡，正在处理的鱼获先结算。机器人不进入瞌睡。

服务端通过 `fishingAsleep` 和可空的 UTC 毫秒 `fishingSleepAt` 发布状态。`fishing_attention` 事件不接受目标玩家，仅作用于当前认证用户；客户端不能指定睡眠值。事件限流，只有服务器状态回传才能唤醒。

睡着时咬钩沿用既有逃鱼结算：没有捕获奖励，保留既有消耗和逃鱼处理，不引入另一套鱼池或经济逻辑。睡眠持续到触碰唤醒；普通自动续钓不会唤醒。

## 视觉契约

原画画布为 640×512，脚底参考点 `(264,450)`。正常呼吸周期 3.2 秒，纵向变化不超过 ±0.6%；瞌睡慢呼吸周期 4.6 秒，纵向变化不超过 ±0.9%，轻微前倾 1.2–3 度。进入／退出瞌睡用 800ms 平滑过渡，每次从源姿势计算，不累乘变换。

闭眼仅修改原等待图的眼部区域，身形、花纹、轮廓、透明边缘及握竿遮挡保持不变。鱼竿和角色同变换，鱼线沿端点修正，浮漂不随呼吸离开水面。离席／其他动作清除呼吸和 Zzz，隐藏窗口不增加额外动画计时器。

## 验收

- [x] 默认 30 分钟；配置边界、关闭配置、机器人豁免正确。
- [x] 自动续钓与重连保留照看时间／睡眠状态。
- [x] 睡眠咬钩直接逃鱼，无捕获奖励；点击清醒角色也重置照看计时。
