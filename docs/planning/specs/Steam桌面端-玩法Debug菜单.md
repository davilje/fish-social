## 1. 背景与目标

v0.7 玩法（等级、塘熟练度、扣费、巡警、鱼获）验收与联调需要集中 Debug，避免散落按钮。提供可呼出/关闭的 Debug 菜单，一键改进度与触发关键事件。

### 非目标

- 替代 Admin Web / A2 钓鱼概率面板
- Release 正式包默认暴露（仅 Development Build / Editor，或 `GAMEPLAY_DEBUG=1` 等显式开关）
- 复杂数值编辑器（任意等级输入框等可后置；本票固定按钮即可）

---

## 2. 入口与交互

| 操作 | 行为 |
|------|------|
| 呼出菜单 | 开发版快捷键或 Overlay/主窗固定入口（实现任选其一，须文档注明；建议 **F9** 或 Overlay 右上「Debug」） |
| 关闭菜单 | 再次快捷键 / 关闭按钮 / Esc；关闭后不再挡操作 |
| 可见性 | 非开发环境不显示入口；服务端生产且未开 Debug 开关时接口拒绝 |

菜单为浮层列表，点一项即执行并 toast/状态行反馈成功或失败原因。

---

## 3. 功能列表

| # | 按钮文案（建议） | 行为 | 权威 |
|---|------------------|------|------|
| 1 | 呼出菜单 / 关闭菜单 | 见 §2 | 客户端 |
| 2 | 升级 | 玩家钓鱼等级 **+1**（受表上限；已满则提示） | 服务端 |
| 3 | 升至满级 | 玩家等级设为 `player_levels` **最高级** | 服务端 |
| 4 | 升级当前鱼塘熟练度 | 当前所在塘熟练度 **+1**（无当前塘则提示；满则提示） | 服务端 |
| 5 | 升级当前鱼塘熟练度到满级 | 当前塘熟练度提到 **10** 或表上限（仍受玩家 `maxPondLevel` 锁则提到锁顶并提示） | 服务端 |
| 6 | 获得 1000000 金钱 | 金币 **+1_000_000**（可叠加） | 服务端 |
| 7 | 一键出警 | 与 `FEAT-RISK-01` **同源**强制巡警；须在禁止塘有效钓鱼中，否则提示原因 | 服务端 |
| 8 | 获得鱼获 | 向背包发放 **1 条**调试鱼获（默认：当前塘池常见种或固定 `crucian`/`gray`/中等尺寸；实现写死一种即可，日志注明） | 服务端 |
| 9 | 当前鱼塘钓鱼时长 +2 小时 | 将**有效钓鱼时长 / 入场费进度**推进 **+2h**（用于测每 2h 扣费切片）；须在收费塘且处于可计费钓鱼会话，否则提示。若因此触发扣费，走正式扣费逻辑；金币不足则按 PROG 停钓提示 | 服务端 |

说明：

- 「当前鱼塘」= Socket 会话 `CurrentPondId`；未进塘时 #4/#5/#7/#9 失败提示清晰。
- #7 可与禁止塘 Overlay 既有「一键出警」并存；本菜单为统一入口，Overlay 快捷按钮可保留。

---

## 4. 技术要点（预估）

- REST 或 Socket Debug 通道：鉴权同现有桌面 Debug（Development + 可选 env）；**禁止**仅改本地 UI 不同步服务端。
- 每次操作写结构化日志 / 可选埋点 `gameplay_debug_action`（实现时登记埋点表）。
- Unity：菜单 Prefab 或运行时生成；Overlay 与主窗至少一处可呼出。

---

## 5. 验收标准

- [x] 开发版可呼出/关闭菜单；Release 默认无入口
- [x] 升级 / 升满级：等级与 XP 云端正确；UI 刷新
- [x] 塘熟练度 +1 / 满级：仅当前塘；锁顶行为符合 PROG
- [x] +1000000 金币到账
- [x] 一键出警与 RISK-01 正式事件一致（10s / 免罚 / 罚款）
- [x] 获得鱼获进背包可见
- [x] +2h 可触发或推进扣费切片；不足金按正式规则停钓
- [x] 前置不满足时有明确中文失败提示，无静默失败
