## 产品决策（必守）

1. 咬钩率和脱钩率**与物种解耦**，只由品质 + 当前体长决定
2. 尺寸越大，咬钩率**越高**；脱钩率也越高
3. 品质越高，咬钩率越低、脱钩率越高
4. 个体浮动系数（±10%）**入库**（`bite_multiplier`、`escape_multiplier` 两列）
5. 满尺寸覆盖：`NEAR_MAX_BITE_RATE` 废弃；`NEAR_MAX_ESCAPE_RATE = 98.4%` 保留

## 任务 2 — 新增计算函数（`shared/fishing.ts`）

替换 `getFishBaseBiteRate` 和 `calcEscapeRate` 的调用源：

```typescript
/**
 * 品质×尺寸咬钩率（per 30s）
 * - QUALITY_BITE_BASE 为满尺寸（n=1）时的最高值
 * - 尺寸越大咬钩率越高，最小尺寸时降至满尺寸值的 35%
 * - 取代旧版 getFishBaseBiteRate / getSpeciesBiteRatePerTick
 */
export function calcQualitySizeBiteRate(quality: FishQuality, sizeM: number): number {
  const n = clamp01(sizeM / QUALITY_SIZE_CAP[quality]);
  return QUALITY_BITE_BASE[quality] * (1 - SIZE_BITE_K * (1 - n));
}

/**
 * 品质×尺寸脱钩率（渔具减免前）
 * - 满尺寸（n≥0.975）覆盖为 NEAR_MAX_ESCAPE_RATE
 * - 取代旧版 species.baseEscapeRate + QUALITY_ESCAPE_BONUS
 */
export function calcQualitySizeEscapeRate(quality: FishQuality, sizeM: number): number {
  const n = clamp01(sizeM / QUALITY_SIZE_CAP[quality]);
  if (n >= NEAR_MAX_SIZE_RATIO) return NEAR_MAX_ESCAPE_RATE;
  return Math.min(ESCAPE_RATE_MAX, QUALITY_ESCAPE_BASE[quality] * (1 + SIZE_ESCAPE_K * n));
}
```

删除 `shared/fishing.ts` 中的：
- `NEAR_MAX_BITE_RATE`（常量 + 所有引用）
- `QUALITY_ESCAPE_BONUS`（常量 + 所有引用）
- `getFishBaseBiteRate` 内部对 `NEAR_MAX_BITE_RATE` 的分支

旧函数 `getFishBaseBiteRate`、`getSpeciesBiteRatePerTick`、`calcEscapeRate` 标记 `@deprecated`，不删除（兼容旧调用点，后续统一替换）。
