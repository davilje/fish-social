## 1. 背景与目标

### 1.1 背景

v0.6.0 排行榜挂在**社交 Tab**内，子 Tab 含钓场/稀有；周榜按「出售金币总和」计分，与「展示最大鱼」心智不一致。产品希望：

1. 排行榜在**首页（世界地图）**露出  
2. 独立排行榜页  
3. **领奖台 + 纵向列表**  
4. 行字段统一为：昵称、头像、鱼、尺寸、鱼塘、名次  
5. 顶部分列仅 **每日 / 每周**  
6. **删除稀有栏**（钓场栏本迭代一并下线 UI）

### 1.2 目标

| # | 目标 |
|---|------|
| G1 | 首页可见排行榜入口；点击进入 `/leaderboard` |
| G2 | 页内仅「每日排行」「每周排行」二分栏 |
| G3 | 前三名顶部领奖台（2-1-3 视觉顺序）；第 4 名起纵向列表 |
| G4 | 每条展示：名次、头像、昵称、鱼种（名/图标）、尺寸、鱼塘名 |
| G5 | 稀有 / 钓场子 Tab 从玩家 UI 移除 |

### 1.3 非目标

- 不上架发奖、不做历史周查询 UI  
- 不重做 Bot 排除与 metrics 数据源规则（沿用 FEAT-SOC-03）  
- 不强制删除服务端 `/api/leaderboard/rare`、`/pond/:id`（可保留兼容；**客户端不再调用**）  
- 不做实时推送刷榜

### 3.2 交互与 UI

#### 3.2.1 首页（`/` 世界地图）

- 增加 **排行榜** 入口按钮（与社交/背包同级或次一级，须首屏可见）。  
- 点击 → `router.push('/leaderboard')`。  
- （P1）入口旁或地图上方可放「今日 Top3」迷你领奖台；点击区域同样进全页。

#### 3.2.2 排行榜页（`/leaderboard`）

```
┌─────────────────────────────┐
│ ← 返回    排行榜             │
├─────────────────────────────┤
│ [ 每日排行 ] [ 每周排行 ]    │  ← 顶部分列
├─────────────────────────────┤
│      🥈        🥇        🥉   │  ← 领奖台：视觉顺序 2 | 1 | 3
│     名次2     名次1     名次3 │     中间最高，左右略低
│     头像/昵称/鱼/尺寸/塘      │
├─────────────────────────────┤
│ 4  头像 昵称  鱼·尺寸  鱼塘  │  ← 纵向列表
│ 5  …                        │
│ …  Top 20                   │
├─────────────────────────────┤
│ 我的排名：#n / 未上榜 · 成绩 │  ← 沿用 my-rank
└─────────────────────────────┘
```

**领奖台规则**：

- 不足 3 人：有几人展示几座；空位不占假数据。  
- 第 1 名居中且视觉最高；第 2 左、第 3 右（经典领奖台）。  
- 列表从 **第 4 名** 起渲染；若总数 ≤3 则无下方列表。

**社交中心**：

- 删除原「排行榜」内嵌 `LeaderboardPanel` 的稀有/钓场/复杂子 Tab；  
- **推荐**：去掉社交「排行」Tab，避免双入口混乱；若保留 Tab，则仅作跳转按钮「前往排行榜页」。

### 3.3 行 / 领奖台字段（每日、每周相同）

| 字段 | 来源 | 展示 |
|------|------|------|
| 名次 | `rank` | 数字；领奖台可用 🥇🥈🥉 辅标 |
| 头像 | `avatarUrl` | `ProfileAvatar` |
| 昵称 | `nickname` | 单行省略 |
| 钓到的鱼 | `extra.speciesId` → 鱼种名/图标 | 必须有；无则显示「—」 |
| 尺寸 | `extra.sizeM` / `value` | 与现有 `formatFishSize` 一致 |
| 鱼塘 | `extra.pondId` → 塘显示名 | 无 pondId 显示「—」 |

点击行/领奖台人物 → `UserProfileModal`。

### 3.4 榜单口径（相对 FEAT-SOC-03 的变更）

| 分栏 | 口径 | API |
|------|------|-----|
| **每日排行** | 上海自然日，真人单条鱼 **尺寸最大** Top 20 | 沿用 `GET /api/leaderboard/daily-biggest` |
| **每周排行** | 上海周（周一 00:00 起），真人单条鱼 **尺寸最大** Top 20 | **改** `GET /api/leaderboard/weekly-king` 语义为「本周最大鱼」（或新增 `weekly-biggest` 并让前端改调；推荐 **改语义 + 文档注明 breaking**，减少双接口） |

**废弃对玩家展示**：

- 稀有榜 UI  
- 钓场榜 UI  
- 原「本周钓王 = Σ calcFishSellPrice」计分（改为最大鱼后，旧周榜价值口径不再对玩家展示）

数据源、Bot 排除、5 分钟缓存、卖鱼仍计分：仍遵 FEAT-SOC-03。

`extra` 必须带齐：`speciesId`、`sizeM`、`pondId`、`caughtAt`（日/周最大鱼路径已有则核对补齐）。

## 4. 验收标准

- [ ] 世界地图首页有排行榜入口，点击进入 `/leaderboard`  
- [ ] 排行榜页仅「每日排行」「每周排行」两栏，**无稀有、无钓场**  
- [ ] 有数据时前三为领奖台（中 1、左 2、右 3）；4+ 纵向列表含名次  
- [ ] 每日/每周每条可见：昵称、头像、鱼、尺寸、鱼塘、名次  
- [ ] 每周榜按**本周最大单鱼尺寸**排序（非金币总和）  
- [ ] Bot 不上榜；点击用户可开资料弹窗  
- [ ] 社交中心不再展示稀有/钓场排行 UI  
- [ ] （P1）首页 Top3 预览可选
