---

你是 Fish Social 开发 Agent。实现 **D9 钓点分区咬钩 + 鱼群迁徙**。

## 产品决策（必守，§0 已确认）

1. **迁徙与补充同 tick**：`tickPondEcology` 顺序 `trySupplement` → `migrateFishSpots` → `growAllFish`（均 15min 窗口）
2. **玩家 UI 不展示**钓点鱼数；**Debug 每个钓点只显示该点 `spot_id` 的鱼**
3. **有意降低咬钩率**：仅本点候选鱼；**不做**密度补偿、不调 `QUALITY_BITE_BASE`
4. **Bot** 与玩家相同，只钓所在 `spot_id` 鱼池

---

## 任务 1 — 数据库与实体

1. 迁移：`pond_fish ADD COLUMN spot_id TEXT NOT NULL`（存量鱼随机合法 spot）
2. 索引：`(pond_id, spot_id)`
3. 可选：`pond_state.last_migration_at INTEGER`
4. `PondFishEntity` 增加 `spotId: string`

## 任务 3 — server/pondEcology.ts

1. `insertPondFish`：写入 `spot_id`（`pickSpotForNewFish`）

3. `tickPondEcology`：
   ```
   trySupplement(...)
   migrateFishSpots(...)   // 与补充同 15min 节律（可共用 last 时间或独立 migration_at）
   growAllFish(...)
   ```
4. `listPondFishAtSpot(pondId, spotId): PondFishEntity[]`
