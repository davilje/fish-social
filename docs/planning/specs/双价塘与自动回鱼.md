## 1. 背景与目标

### 1.1 背景

RETURN-01 已提供手动回鱼（收杆弹窗 / 背包）。进一步希望用**进塘收费模式**区分玩法：便宜塘只能卖商店；贵塘支持高品质大鱼自动回鱼赚钱，但钓不到优质鱼会因高票价亏损。

### 1.2 目标

- 进塘确认时，玩家在两种收费中**二选一**（绑定本局 session）：
  - **不可回鱼档**（低价）：钓获只能卖商店；无回鱼。
  - **可回鱼档**（高价）：仅高品质、高体长可回；**达标鱼获自动入录并自动回鱼**，无需背包手动操作。
- 回鱼数值/增重/熟练度等**沿用 RETURN-01**；**FEAT-RETURN-03** 已将回鱼金调整为卖价 **×1.5**，准入收紧为 purple + 体长比 ≥0.75（手动/自动共用）。
- 经济张力：可回鱼档钓到达标鱼可赚钱；钓不到则相对低价档更易亏。

### 1.3 非目标

- 改卖价公式、改 RETURN-01 增重公式本体（仅复用）。
- 进塘后中途切换收费模式。
- 全量日志相册（仍归 ALBUM）；本票只需自动回鱼成功事件可供相册消费。
- Mobile 对齐（可后置）。

## 2. 用户与场景

| 角色 | 场景 | 期望结果 |
|------|------|----------|
| 玩家 | 进收费塘弹窗 | 看到两档价格与说明，选一后进塘 |
| 玩家 | 选「不可回鱼」 | 扣低价逻辑；钓获仅可卖；无回鱼按钮/自动回鱼 |
| 玩家 | 选「可回鱼」 | 扣高价；达标鱼自动回鱼并发奖；不达标仅入包可卖 |
| 玩家 | 可回鱼档但长期钓灰鱼 | 高票价下相对亏损（设计意图） |

## 3. 功能范围

### 3.1 功能列表

| # | 功能点 | 优先级 | 说明 |
|---|--------|--------|------|
| 1 | 进塘双价选择 UI | P0 | 地图/进塘确认弹窗 |
| 2 | Session 绑定 `returnFeeMode` | P0 | `sell_only` \| `auto_return` |
| 3 | 双价格表字段 | P0 | `feePer2hSellOnly` / `feePer2hAutoReturn`（或倍率） |
| 4 | 自动回鱼 | P0 | 可回鱼档 + 达标 → 收杆后自动执行 RETURN-01 管道 |
| 5 | 手动回鱼收敛 | P1 | 可回鱼档：达标鱼不再依赖背包手动；不可回鱼档隐藏回鱼 |

### 3.2 交互与 UI

1. **进塘确认**（在 08A2 扣费确认上扩展）：
   - 卡片 A：不可回鱼 · 每 2h **低价** · 「钓获仅可出售」
   - 卡片 B：可回鱼 · 每 2h **高价** · 「高品质大鱼自动回塘赚钱」
   - 确认后 `join` 携带 `returnFeeMode`。
2. **可回鱼档 · 收杆**：达标鱼 → 自动回鱼成功反馈（金币/增重/XP）；不进「待手动回鱼」背包路径（或短暂展示后自动完成）。
3. **不达标 / 卖出**：仍走卖出；无回鱼入口（或灰显「本局为出售档」）。

### 3.3 规则与数值

#### 收费

| 模式 | 字段建议 | 相对关系 |
|------|----------|----------|
| `sell_only` | `feePer2hSellOnly` | 低于现网或等于现网偏低档 |
| `auto_return` | `feePer2hAutoReturn` | **明显高于** sell_only（建议 ≥1.5×～2×，表定） |

- 日最多仍 4 次切片；模式选定后**本局不可改**；换塘需重新选。
- 免票塘（`feePer2hSellOnly = 0`）：**不可回鱼**；进塘仅 `sell_only`，不提供双价（`allowsAutoReturn = false`）。
- 收费塘门禁：`pondAllowsReturnFish = allowsAutoReturn && feePer2hSellOnly > 0`（见 RETURN-03）。

#### 自动回鱼准入（沿用 / 收紧 RETURN-01）

在 `return_rules` 上可增加或复用：

| 字段 | 建议 | 说明 |
|------|------|------|
| `autoMinQuality` | 如 `purple` / `gold` | 仅高品质 |
| `autoMinSizeRatio` | 如 0.7～0.85 | 高体长相对种 max |
| 其余 | RETURN-01 / RETURN-03 | 满尺寸不可回、增重、**金倍率 1.5**、XP |

```text
if session.returnFeeMode !== 'auto_return' → 永不自动回鱼
if !eligible(quality, size) → 入包，可卖，不回
if eligible → accept_catch 记账后立即 return-to-pond（同事务/同请求链）
```

#### 经济意图（策划说明，非公式）

- 高价档：偶尔一条达标回鱼的净收益应能覆盖多段票价差；多数「灰蓝小鱼」局应感到亏。
- 低价档：稳定卖鱼覆盖票价即可。

### 3.4 与 RETURN-01 关系

| RETURN-01 | RETURN-02 |
|-----------|-----------|
| 手动回鱼 API / 增重 / 发奖 | **复用** |
| 收杆+背包入口 | 可回鱼档：**自动优先**；背包手动可保留作兜底或隐藏（实现选「隐藏手动」更干净） |
| 卖出不回写塘 | **不变** |

## 4. 技术影响

### 4.1 数据模型

- `player_pond_session` 或内存 session：`returnFeeMode`
- `ponds` 表：`feePer2hSellOnly`、`feePer2hAutoReturn`、`allowsAutoReturn`
- 扣费 tick 使用当前 session 对应 `feePer2h`

### 4.2 API / Socket

| 类型 | 名称 | 说明 |
|------|------|------|
| join / 进塘确认 | 带 `returnFeeMode` | 缺省拒绝或默认 sell_only（表定） |
| 内部 | 捕获结算后 `tryAutoReturn` | 调用既有 return 管道 |
| REST | 手动 return | 可回鱼档达标鱼已回则 Item 不存在 |

### 4.3 埋点

| eventType | 字段 |
|-----------|------|
| `return_fee_mode_selected` | pondId, mode, feePer2h |
| `fish_auto_returned` | 同 `fish_returned_to_pond` + `auto: true` |

### 4.4 涉及文件（预估）

- 数值表 `ponds`、Unity 进塘确认、`playerProgress` 扣费、`inventory`/`returnFish` 捕获链

## 5. 验收标准

- [x] 进塘必须选择双价之一；费用按所选档扣
- [x] `sell_only`：无自动回鱼；不可手动回鱼（或明确禁用）
- [x] `auto_return`：达标鱼自动回塘增重并发奖；不达标可卖
- [x] 本局不可切换模式；离塘后再进需重选
- [x] RETURN-01 增重/金/XP 行为在自动路径一致
- [x] 埋点可选中 / 自动回鱼可查
- [x] **RETURN-03**：不达标鱼留背包；免票塘不可回；回鱼金 = 卖价×1.5
