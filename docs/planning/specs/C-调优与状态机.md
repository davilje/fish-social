## 1. 目标

基于 A0~B1 上线后的数据，进行数值调优、经济系统补强、机器人适配新玩法、完整状态机与阶段动画落地。

## 2. 子任务清单

### C1 数值调优基建

**目标**：策划无发版即可调整核心参数。

- `BITE_LAMBDA`、`QUALITY_ESCAPE_BONUS`、`hookDurationMs` 参数、鱼种 `biteWeight` / `baseEscapeRate` 落配置表 `game_config`（KV 结构，热更）
- Admin UI 增加「参数编辑」入口，写操作**双人确认**（一人提交、另一人 approve）
- 变更审计日志：who、when、from、to
- A2 面板显示当前生效值 vs 硬编码兜底值

**验收**：改配置无需重启服务；变更 5s 内所有 tick 生效；审计日志可查询近 30 天。

---

### C2 Bot 深度适配

**目标**：Bot 完全适配新玩法，鱼塘氛围真实。

- Bot 走完整状态机（依赖 C6 上线）；未上线前 Bot 仍走 A0 简化路径
- Bot 装备/购饵行为随机化，模拟真实玩家分布
- Bot 咬钩率与真人对齐（避免鱼塘被 bot 掏空）
- Bot 咬钩时同样触发飘字广播，保持鱼塘热度感

**验收**：真人与 Bot 混合的鱼塘中，Bot 钓获量占比 ≤ 40%。

---

### C3 金币 Sink 二期

**目标**：补齐主 spec §2.6 未做的长期金币出口。

**候选方案**（择一或组合实施）：

| 方案 | 说明 | 预估 sink 强度 |
|---|---|---|
| 渔具耐久 | 每次脱钩 -1 耐久，归零需修理，修理费 = 购价 × 5% | 中 |
| 钓位租金 | 高级鱼塘每分钟扣少量金币 | 中高 |
| 加工/烹饪 | 鱼可加工成料理售价更高，但需消耗其他材料 | 灵活 |
| 鱼塘门票 | 稀有鱼塘一次性/每日进入费 | 高 |

**上线前必须**：
- 30 日经济模拟（faucet/sink 曲线）
- 灰度 10% → 50% → 100%

**验收**：全服平均金币持有量 30 日稳定波动 ≤ ±15%。

---

### C4 繁衍品质遗传（可选）

**目标**：若产品验证需要，让父母品质影响子代掷骰。

- 单独 spec 论证品质通胀风险
- 候选公式：`childQualityWeight = baseWeight * (1 + parentBonus)`，`parentBonus` 为父母品质 index 之和的对数
- 需保证长期塘内 gold 数量收敛，不会指数增长

**验收**：模拟 100 代繁衍，gold 占比与初始配置差异 < 30%。

---

### C5 图鉴 / 钓鱼日志

**目标**：极低成本高留存收益。

- 个人图鉴：每种鱼的最大尺寸记录、首次钓到时间、总数
- 全塘/全服排行榜：最大鱼（按品质分档）
- 鱼种详情页：diet、biteWeight、baseEscapeRate（策划决定是否对玩家透明）、推荐鱼饵（关联 B1）
- 首次钓到新鱼种触发一次性动画 + 图鉴解锁提示

**验收**：图鉴入口 DAU ≥ 20%（钓鱼玩家中）。

---

### C6 完整状态机与阶段动画

**目标**：落地主 spec §4 完整状态机与 §5.2 各阶段动画。

**范围**：
- 服务端 `fishingPhase` 完整枚举实施（`idle / seated / baiting / casting / waiting / hooked / resolving / result / stopping / disconnected`）
- `PondCharacter` 各阶段动画（Lottie 或简单 transform）
- `hookEndsAt` 客户端校正
- Bot 走完整状态机（承接 C2）
- 玩家断线 60s 内可续接（依据 §4.11 决策 4）

**需求描述**：完整需求见 `状态机需求描述.md`，C6 spec 直接引用，无需补需求，仅需补动画资源与联调计划。

**建议单独立 spec**：`钓鱼系统 v2 - 状态机与阶段动画`，因涉及美术资源与前后端联调，工期估 2 周。

**验收**：
- 8 人同塘同步钓鱼，各端 `hookEndsAt` 差异 < 300ms
- 脱钩循环最长 20s，最短 3s（快钓路径）
- 断线 60s 内重连成功率 ≥ 95%

---

### C7 灰度指标监控

**目标**：建立钓鱼玩法长期健康度指标。

**关键指标**：
- 「连续脱钩 3+ 次」玩家比例（预警阈值 ≥ 15%）
- 「弃钓率」（进入钓鱼后 30s 内 stop_fishing）
- 高品质鱼稀有度感受调研（问卷）
- 各品质鱼实际到手率 vs 期望值
- 商店各档鱼饵/渔具购买占比
- 金币 faucet/sink 比

**输出**：每周自动报表推送到策划群 + Admin 页面看板。
