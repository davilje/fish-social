## 1. 背景与目标

### 1.1 背景

`FISH-SPOT-1` 定案：空闲点或 **仅 bot 占用** 的点可点；`take_spot` **可踢 bot**。现网 `server/src/pondSession.ts` 在目标座位已有 `occupant.isBot` 时 `removeBotUser`，埋点 `spot_take_bot_eviction`。

产品现状：玩家点他人（机器人）脚下的座位，机器人立刻消失、自己坐下。同塘氛围被打断，也和「座位上已有人」的直觉冲突。

### 1.2 目标

- **有人坐着的座位不可占**，机器人与真人一视同仁。
- 点击占用座位：不发成功占座、不踢走该座位上的机器人。
- 空座位仍可 `take_spot`；换座只换到空位。
- 塘满 / 全座已占时，为真人腾位的 `evictBotsForHuman` **保留**（容量压力，不是点谁踢谁）。

### 1.3 非目标

- 不改 bot 进塘、自动钓鱼、自动占空位。
- 不改真人占用时的「该钓点已被占用」。
- 不改 09A 右键机器人社交菜单。
- 不改 `mobile/` 以外的占座产品（本单以 Steam Overlay / Unity 桌面为准；服务端口径应对齐，避免桌面踢、手机仍踢）。
- 不做「花钱买座位 / 预约座位」。

## 2. 用户与场景

| 角色 | 场景 | 期望结果 |
|------|------|----------|
| 玩家 | 点空座位 | 自己落座，与现在一致 |
| 玩家 | 点机器人坐着的座位 / 椅图 | 座位仍是机器人的；机器人还在；自己不换到该点 |
| 玩家 | 点真人坐着的座位 | 仍拒绝（已有） |
| 玩家 | 塘满且自己无座，点空位失败后由服务端腾 bot | 仅容量压力路径可踢 **任意** bot，不是点谁踢谁 |
| 玩家 | 右键机器人猫 | 仍是 09A 社交菜单，不占座 |

## 3. 功能范围

### 3.1 功能列表

| # | 功能点 | 优先级 | 说明 |
|---|--------|--------|------|
| 1 | 服务端 `take_spot` | P0 | 目标 `spotId` 已被任何人占用（含 bot）→ 失败，文案与真人占用一致（「该钓点已被占用」） |
| 2 | Overlay 点击 | P0 | `ownSpotId` + `users[].spotId` 已占用的座位不发 `take_spot`；椅图可点穿或 no-op |
| 3 | 容量腾位 | P0 | `evictBotsForHuman`（塘满 / 全座占满）保持；**禁止**点指定 bot 座作为踢人入口 |
| 4 | 提示（可选） | P1 | 误点占用座：`txt_error` 或短气泡「这个座位有人了」；可只靠服务端错误回传 |

### 3.2 交互

```text
未落座 / 已落座可换座
  ├─ 点半透明空座位 → take_spot → seated
  ├─ 点占用座位（真人/bot）→ 不占座、不踢人
  └─ 点猫身 → 09A / 悬停，不占座
```

14A 显隐可不变：占用座仍画不透明椅，只是不再当作占座热区。

### 3.3 规则

- 占用判定与 14A 相同：`ownSpotId` 与任意 `users[].spotId`（含 `isBot=true`）。
- 自己当前座位再点：no-op，不踢自己。
- 钓鱼中换座：仍须先收竿（现网「请先收起鱼竿」）。

## 4. 实现分析（给开发）

### 4.1 现状

| 位置 | 行为 |
|------|------|
| `pondSession.ts` `takeSpot` | 先 `evictBotsForHuman`；若该座 bot → `removeBotUser` |
| Overlay `SpotSelected` | 一律 `take_spot` |
| `FISH-SPOT-1` | 明确「可踢 bot」——本单 **废止该条**，以本 spec 为准 |

### 4.2 建议改动

| 模块 | 改法 |
|------|------|
| `server/src/pondSession.ts` | 占用者无论是否 bot，一律 `spot_take_fail` / occupied |
| Overlay `PondScenePresenter` / `OverlaySpotMarker` | 占用座不抬 `SpotSelected` |
| Unity 主窗口若仍可点塘座位 | 同一规则 |
| `mobile/` 点座 | **对齐**同一服务端口径（服务端改后手机也会不可踢） |

不需要新 IPC 字段。埋点：不再打 `spot_take_bot_eviction`（点座路径）；容量腾位的 `bot_evicted_for_human` 保留。

### 4.3 涉及文件（预估）

- `server/src/pondSession.ts`
- `desktop-overlay/PondScenePresenter.cs`、`OverlaySpotMarker.cs`
- Unity 塘内点座（若有）
- 可选：`scripts/verify-*` 占座用例把「可踢 bot」改成「占用失败」

## 5. 验收标准

- [ ] 点机器人占用的座位：机器人仍在该座；自己 `spotId` 不变（或仍为空）
- [ ] 点空座位：仍可落座
- [ ] 点真人占用座位：仍拒绝
- [ ] 09A 右键机器人菜单仍可用
- [ ] 塘满腾位路径未误删（有人进塘需要位子时仍可按现政策踢 bot）
- [ ] 不改打窝 / 钓鱼权威公式
