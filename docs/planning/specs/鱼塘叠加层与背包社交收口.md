## 1. 背景

### 1.1 UI 层级（现状问题）

飘字与悬停气泡挂在**单个** `PondCharacter` 内部。场景按钓点 DOM 顺序叠放，后方/下方角色的容器会盖住前方角色的气泡与飘字（角色内 `zIndex: 20` 无法跨过兄弟 `spotMarker`）。

### 1.2 排行榜（分析结论，纳入改造）

| 事实 | 说明 |
|------|------|
| 不是「每天刷昨天」 | 日榜按 **上海当日** `dateKey` 现查 `fishing_metrics` 的 `catch_accept` / `pending_catch_accept` |
| 近似实时 | 进程内缓存 **TTL=5 分钟**；打开/刷新接口最多延迟约 5 分钟，非日终批处理 |
| 日初为空 | 当日尚无成功埋点 → 列表空（领奖台应仍显示空位，FEAT-UI-1） |
| 周榜 | 上海 **ISO 周（周一～周日）**；周内随渔获更新（同 5 分钟缓存）；**跨自然日 0 点不换周**，仅 **周一 0 点（上海）** 进入新周 key，上周成绩不再计入本周 |
| Bot 上榜缺口 | FEAT-UI-1 已去掉 `bot-%` SQL 过滤，但数据源仍是 **metrics 成功事件**；bot 只写背包不写 catch → **实际仍难上榜** |

本需求要求：排行榜产量口径改为与 OPS-CATCH-1 一致的 **inventory**（含 bot），日/周边界仍用上海日/周。

### 1.3 Bot 动态

当前：史诗+（`isAnnounceQuality` → `purple` 起）必发动态；另有 **45%** 概率分享普通渔获 → 动态墙被低品质刷屏。

目标：bot **仅**自动发布史诗及以上；去掉随机分享普通鱼。

### 1.4 背包

当前：格子数 = 鱼数量（仅补齐到整行空格）；无固定容量感。

目标：固定 **80** 格空位骨架，纵向滚动；有鱼填格，无鱼显示空格。

---

## 2. 目标

1. 悬停气泡、钓鱼飘字（咬钩/抛竿/脱钩等）在**场景统一叠加层**绘制，不被其它角色遮挡。  
2. 排行榜按 **inventory** 聚合当日/本周最大鱼（含 bot）；保持空台/前 50 空槽 UI。  
3. Bot 自动动态仅史诗+。  
4. 背包固定 80 格 + 纵向滑动。

### 非目标

- 不改真人分享规则  
- 不改 8h 时长、咬钩公式  
- 不做 WebSocket 推送排行榜（仍拉取 + 短缓存即可）  
- 不恢复稀有/钓场榜  

---

## 3. 功能需求

### 3.1 A — 场景叠加层（气泡 + 飘字）

```text
PondScene
├── 地面 / 水面 / 钓点角色（底层，可按 y 排序绘制）
└── Overlay（最高层，pointerEvents=box-none）
    ├── 各用户 FishingFloatText（按角色锚点定位）
    └── 各用户状态气泡（悬停时）
```

| 规则 | 约定 |
|------|------|
| 定位 | 叠加层项用与角色相同的场景坐标（spot.x/y + 偏移） |
| 层级 | Overlay 整层高于所有 `spotMarker` / 角色 |
| 交互 | 角色点击/悬停逻辑可仍在角色上；气泡视觉在 Overlay |
| 范围 | 含抛竿/咬钩/脱钩等全部 `FishingFloatText` |

验收：多人同塘时，任意角色气泡与飘字不被其它角色身体挡住。

### 3.2 B — 排行榜数据源

| 项 | 约定 |
|----|------|
| 日榜 | 上海当日 `inventory.caught_at`，每人当日最大 `size_m` 一条 |
| 周榜 | 上海本周周一 00:00～下周一 00:00，每人周内最大一条 |
| 含 bot | `player_id` 含 `bot-%` / 池 id |
| 缓存 | 可保留 ≤5 分钟内存缓存；换日/换周 key 自动隔离 |
| 空态 | 无数据时领奖台三席 + 4～50 名空行仍显示 |

验收：有 bot 背包入库时可上榜；新日 0 点后日榜从空开始累加；周一 0 点后周榜换期。

### 3.3 C — Bot 仅发史诗+动态

- 删除（或永久关闭）`BOT_SHARE_CATCH_CHANCE` 普通分享分支。  
- 保留 `isAnnounceQuality`（≥ purple 史诗）时的公告 + `createPostFromFish`。  
- 塘内喊话可与现网一致（仅史诗+）。

### 3.4 D — 背包 80 格

| 项 | 约定 |
|----|------|
| 容量展示 | 固定渲染 **80** 个格子（4 列 × 20 行或实现自定列数，总数 80） |
| 填充 | 前 N 格为鱼（N=`items.length`，若 >80 则只显示 80 或可滚更多——**MVP：最多展示 80，超出仍可进包但格外提示「已满展示」或允许格数=max(80, items.length)**；推荐 **格数 = max(80, items.length)** 以免丢显示） |
| 滚动 | 格子区 **纵向** `ScrollView`/`FlatList` |
| 空格 | 无鱼格子为空槽样式，可点不可选中鱼 |

推荐：`slotCount = Math.max(80, items.length)`，保证至少 80 空位骨架。
