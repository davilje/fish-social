# BUG 修复：资料弹窗与鱼塘侧栏

| 状态 | **已实现** | 目标版本 v0.1.1 |
|------|------------|-----------------|

---

## 1. 关弹窗仍闪「添加好友」

**现象**：加好友成功后关闭资料弹窗，fade 动画间仍会闪一下「添加好友」。

**原因（供开发）**：`onClose` 后 `useProfileModal` 将 `target` 置空，Modal 仍动画中却收到 `playerId=''`，好友态判断失效。

**改法（任选，以不闪为准）**：
- 关闭动画结束（`onModalHide`）后再清空 `target`
- 或 `visible=false` 期间冻结最后一帧 UI，不渲染好友操作区
- 或关闭时不把 `playerId` 提前置空

**验收**：加好友 → 立刻关弹窗 → 全程不出现「添加好友」闪回。✅

---

## 2. 首页头像：直进个人信息，不弹窗

**现象**：世界地图（`index.tsx`）点头像会打开 `UserProfileModal`，多余。

**规则**：

| 页面 | 点自己头像 | 点他人头像 |
|------|------------|------------|
| **世界地图** `/` | `router.push('/profile')` | 无（本页无他人头像） |
| **鱼塘** `/pond/[id]` | 打开资料弹窗（见 §3） | 打开资料弹窗 |
| **社交** `/social` | 打开资料弹窗 + 编辑按钮 | 打开资料弹窗 |

**改法**：`index.tsx` 移除 `useProfileModal`；顶栏头像改 `router.push('/profile')`。

**验收**：首页点头像只进 `/profile`，不弹窗。✅

---

## 3. 弹窗缺少「编辑资料」

**现象**：鱼塘内点自己头像打开弹窗，看不到「编辑资料」。

**要求**：
- 查看**自己**时，弹窗内必须有 **「编辑资料」** 按钮
- 点击 → 关闭弹窗 → `router.push('/profile')`
- 按钮放在 ID 下方、简介上方，**无需滚到底**才看到
- `onEditProfile` 必须在鱼塘、社交页传入（首页不需要弹窗）

**验收**：鱼塘顶栏点自己头像 → 弹窗内明显可见「编辑资料」→ 可进入编辑页。✅

---

## 4. 鱼塘：合并在线栏与聊天栏

**现象**：`OnlineUsersPanel` 与 `ChatPanel` 上下分开占空间；在线栏显示「钓鱼中 · 时长」冗余（场景里已有钓鱼状态）。

**要求**：
- 合并为**一块侧栏/底栏**（可新组件 `PondSocialPanel`）
- **上**：在线钓友横向头像+昵称 chips，可点击开资料弹窗
- **下**：原有聊天列表 + 输入框
- **去掉**在线 chips 上一切钓鱼状态文案（含「钓鱼中」及时长）；是否在场景角色上保留状态由现有 `PondCharacter` 负责，**在线栏不标**
- 桌面端仍可与鱼塘场景并排；移动端合并后少占一层高度

**涉及**：`pond/[id].tsx`、`OnlineUsersPanel.tsx`、`ChatPanel.tsx`（或合并新文件）

**验收**：鱼塘页仅一块「在线+聊天」区域；在线 chips 仅头像+昵称、无任何钓鱼状态文字；聊天功能不变。✅
