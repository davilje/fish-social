## 1. 背景与目标

### 1.1 背景

缺少竞争展示位，「今日最大鱼 / 本周钓王」等身份认同与日周留存钩子不足。

### 1.2 目标

| 榜 | 优先级 | 口径 |
|----|--------|------|
| 今日最大鱼 | P0 | 当日单条鱼 **尺寸** Top |
| 本周钓王 | P0 | 本周钓获 **折算出售金币总和** Top（`calcFishSellPrice`） |
| 钓场榜 | P1 | 指定塘本周钓获条数（兼最大鱼尺寸展示） |
| 稀有鱼榜 | P1 | 本周 **史诗+**（`purple` 及以上）条数 |

入口：社交中心新增 **排行榜** Tab。

> **改版**：首页入口、领奖台、仅日/周分栏、删稀有 — 见 [`排行榜-入口与领奖台改版.md`](./排行榜-入口与领奖台改版.md)（**FEAT-SOC-03b**）。

### 1.3 非目标

- 不做毫秒级实时榜（允许缓存与定时快照）
- 不做跨周历史查询 UI（快照表可留 `period_key` 供后续）
- 不做上榜发奖 / 称号发放
- 不做 Bot 上榜（`player_id LIKE 'bot-%'` **一律排除**）
- 不做「仍在背包」限制——**已卖出的鱼仍计成绩**（见数据源）

## 3. 功能范围

### 3.1 功能列表

| # | 功能点 | 优先级 | 说明 |
|---|--------|--------|------|
| 1 | 今日最大鱼 | P0 | Top 20；上海自然日 |
| 2 | 本周钓王 | P0 | Top 20；周一 00:00 起周 |

### 3.2 交互与 UI

社交中心 Tab 增加：`排行榜`（与现有 动态墙 / 好友动态 / 好友 / 私聊 / 设置 并列，移动端可缩文案「排行」）。

子 Tab：`今日最大鱼` | `本周钓王` | `钓场` | `稀有`（P1 两项可灰显「即将开放」若只做 P0，但推荐同迭代做完）。

**行字段**：

| 榜 | 列 |
|----|-----|
| 今日最大鱼 | 名次 · 头像 · 昵称 · 鱼种 · 尺寸 · 钓场（若有）· 时间 |
| 本周钓王 | 名次 · 头像 · 昵称 · 本周总价值 · 钓获条数 |
| 钓场榜 | 名次 · 头像 · 昵称 · 条数 · 最大尺寸 |
| 稀有榜 | 名次 · 头像 · 昵称 · 史诗+条数 · 最大稀有尺寸 |

前三：🥇🥈🥉（或主题色描边）；当前用户行背景高亮。

### 3.3 规则与数值

**日界 / 周界**：`Asia/Shanghai`；周 = ISO 周或「周一 00:00～周日 23:59:59」需在实现里固定一种，**推荐：上海时区下每周一 00:00 切换 `period_key=YYYY-Www`**。

**价值**：`calcFishSellPrice({ quality, sizeM })`（`shared/economy.ts`），与背包出售一致。

**并列**：同 value 时先到达者（更早 `created_at`）靠前；再按 `player_id` 稳定排序。

## 4. 技术影响

### 4.1 权威数据源（重要）

| 方案 | 说明 | 结论 |
|------|------|------|
| `inventory` | 卖鱼即删行，**成绩丢失** | ❌ 不可作唯一源 |
| `fishing_metrics` 收鱼事件 | `pending_catch_accept` / `catch_accept` 带 `playerId`+`pondId`，payload 含 `quality`/`sizeM` | ✅ **主数据源** |
| 补记 | Bot `handleBotCatch` 若未打点，本就不该上榜；真人路径须保证 payload 含 `quality`+`sizeM` | 验收时核对 |

聚合查询：按事件 `created_at` 落入上海日/周窗口；排除 `player_id LIKE 'bot-%'`。

**实现注意**：确认 `pending_catch_accept` 落库 payload 含 `sizeM`/`quality`（当前收鱼路径已写）；若历史行缺失则该行跳过不计入。

### 4.2 缓存表（可选但推荐）

```sql
CREATE TABLE leaderboard_snapshots (
  board_type TEXT NOT NULL,   -- daily_biggest | weekly_king | pond | rare
  period_key TEXT NOT NULL,   -- 2026-07-13 | 2026-W28 | 2026-W28:pond-calm
  rank INTEGER NOT NULL,
  player_id TEXT NOT NULL,
  value REAL NOT NULL,
  extra_json TEXT,            -- speciesId, sizeM, pondId, catchCount, ...
  snapshot_at INTEGER NOT NULL,
  PRIMARY KEY (board_type, period_key, rank)
);
CREATE INDEX idx_lb_player ON leaderboard_snapshots(board_type, period_key, player_id);
```

也可 MVP 仅用进程内 cache（`Map` + 5 min TTL），表作二期；**规格允许两种，验收以「5 分钟内重复请求不重扫全表」为准**。

### 4.3 API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/leaderboard/daily-biggest` | `date?`（默认今天上海）`limit?`（默认 20） |
| GET | `/api/leaderboard/weekly-king` | `week?` `limit?` |
| GET | `/api/leaderboard/pond/:pondId` | `week?` `limit?`（默认 10） |
| GET | `/api/leaderboard/rare` | `week?` `limit?` |
| GET | `/api/leaderboard/my-rank` | `boardType` + 对应 period 参数；需 `requireAuth` |

**列表项示意**：

```ts
interface LeaderboardEntry {
  rank: number;
  playerId: string;
  nickname: string;
  avatarUrl?: string;
  value: number;
  extra?: {
    speciesId?: string;
    sizeM?: number;
    pondId?: string;
    catchCount?: number;
    caughtAt?: number;
  };
}
```

**my-rank**：`{ rank: number | null, value: number, entry?: LeaderboardEntry }`（未上榜 `rank=null` 但仍给 value）。

只读接口可匿名；`my-rank` 必须登录。

### 4.4 刷新策略

1. 请求时：若 cache 未过期 → 直接返回  
2. 过期 → 聚合 metrics → 写 cache/快照 → 返回  
3. 日/周切换后首次请求自然换 `period_key`（不必强依赖 cron；有 `serverLoops` 时可预热）

### 4.5 涉及文件

- `server/src/leaderboard.ts`、`socialRoutes.ts` 或独立 `leaderboardRoutes.ts`
- `shared/social.ts`（类型）或 `shared/leaderboard.ts`
- `mobile/app/social.tsx`、`mobile/components/LeaderboardPanel.tsx`、`socialApi.ts`
- 可选 migration：`leaderboard_snapshots`

## 5. 验收标准

- [ ] 今日最大鱼：上海当日真人 Top 20，按 `sizeM`；卖鱼后成绩仍在
- [ ] 本周钓王：本周真人 `Σ calcFishSellPrice` Top 20
- [ ] Bot 不上榜
- [ ] 5 分钟内重复拉取不重复全量重算（可用日志/计数断言）
- [ ] 前三样式 + 当前用户高亮
- [ ] `my-rank` 对已登录用户返回名次或 null
- [ ] 点击行打开 `UserProfileModal`
- [ ] （P1）钓场榜按 `pondId` 过滤；稀有榜仅 `purple+`

## 6. 风险与依赖

| 风险 | 缓解 |
|------|------|
| 卖鱼丢成绩 | 禁止只扫 inventory；用 metrics 收鱼事件 |
| metrics 缺 sizeM | 收鱼埋点补全；旧数据跳过 |
| 大表扫描 | 按时间窗索引 + 5 min 缓存 |
| 与日报时区不一致 | 统一上海日界 |

**依赖**：`calcFishSellPrice`；收鱼埋点；社交 Tab 壳子。
