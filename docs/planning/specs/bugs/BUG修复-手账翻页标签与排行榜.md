## 合并后的缺陷

| 编号 | 合并了什么 | 结论 |
|------|------------|------|
| BUG-59a | 相册翻页、回忆便签出场；图鉴 / 展示柜 / 成就点选后中央不出场（空展示格尤其明显） | 功能在，接法不对。空卡的可见底板是根 Image，动效跳过了它；切页也不重播贴纸入场 |
| BUG-59b | 背包、道具、商店、成就、世界地图、列表选塘、排行榜、个人资料的右侧详情缺少出场 | 同一套拍立得揭示。商店和背包只在部分点击路径播放；选塘把「同一项才播放」写反了 |
| BUG-59c | 相册每张缺少日期和地点 | 数据在 `eventAt` / `pondName`，被写进一段超高正文后裁掉。卡片改成三行：鱼名 · 体长、稀有或值得记下、`M月d日 · 鱼塘` |
| BUG-59d | 展示柜、图鉴、相册右侧标签；五角星 | **不是缺素材**。`surfaces/category-chip` 已在主题里；品质也已有。缺的是把品质画成 `★`、把鱼塘 / 食性画成芯片的功能 |
| BUG-59e | 右上角通知从右侧滑入时没有底 | 便签图加载失败时 Image 没有回退纸底 |
| BUG-59f | 前三名左上角选中页签层级；排名栏只显示尺寸且字号一致；每周钓王显示金币；排名滚动条 | 页签画在头像下面。每日栏把鱼种和体长拼在一起导致换行。每周 `value` 服务端是体长米，客户端误标成金币。ScrollRect 没有竖向滚动条 |
| BUG-59g | 动态「公开」标签、鱼获底、左上角页签、鱼塘名、五角星、点赞评论；留言栏 | 公开是纯文字；鱼获底用了输入框图；鱼塘显示 id；留言打开没有揭示 |

## 非目标

- 不把每周钓王改成「本周累计重量」。服务端 `weekly_king.value` 是本周最大一条的体长，客户端按这条换算重量。
- 不补成就连续进度百分比，DTO 没有 current/target。
- 不伪造相册可钉选列表。
