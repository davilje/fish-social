## 1. 背景与目标

### 1.1 背景

开钓前缺少「撒窝」预备玩法。需独立于 GEAR-01 **按口扣饵**：打窝是坐席后、开钓前的金币+时间投资，弱提升咬钩并小幅抬附近鱼尺寸；可反复叠层，但**非线性**且有 **50 层硬上限**。

### 1.2 目标

- `seated` 态 Overlay：**「开始钓鱼」与「打窝」并列**。
- 点打窝 → 选窝料 → 扣金 + 等待 → 完成后**回到选项**，可继续打窝，直到 **50 层 / 没钱 / 点开始钓鱼**。
- 加成：咬钩概率非线性趋近上限；附近鱼尺寸小幅临时增益。
- 与咬钩饵完全分离。

### 1.3 非目标

- 全塘共享窝效、窝料背包库存、日次数上限（除 50 层硬 cap）。
- 与船具联动、Mobile 对齐。
- 线性叠乘咬钩（**禁止**）。

## 2. 用户与场景

| 角色 | 场景 | 期望结果 |
|------|------|----------|
| 玩家 | seated 点「打窝」且金币够 | 进入打窝等待，结束后 stack+1，回到选项 |
| 玩家 | 连续打窝 | 每层扣金+等待；加成边际递减；显示 x/50 |
| 玩家 | 金币不足点打窝 | **不进入等待**；文字气泡：「金币不足，无法继续打窝」 |
| 玩家 | 已 50 层再点打窝 | 禁用或提示「已达打窝上限」；仅可开始钓鱼 |
| 玩家 | 点「开始钓鱼」 | 带当前窝效进入既有开钓流程 |

### 3.2 交互与 UI（Steam Overlay）

参考 [Steam桌面端-08GOverlay钓鱼操作栏.md](./Steam桌面端-08GOverlay钓鱼操作栏.md)。

```text
[seated]
  操作栏：【开始钓鱼】 【打窝】
  状态条：窝层 x/50 · 咬钩+y% · 尺寸+z · 剩余时间/口数

点【打窝】→ 窝料选择（已解锁）→ 确认「-XX 金 · 约 X 秒」
  → 金币不足：气泡提示，停在 seated
  → 成功：phase=groundbaiting → 结束 → seated（选项再出）

点【开始钓鱼】→ 既有 start_fishing 门禁（竿/费等）
```

- 打窝过程中禁用「开始钓鱼」或允许取消（默认：**不可取消，等完**）。
- 收杆/停钓回到 `seated` 后可再次打窝（stack 是否保留见 §3.3）。

### 3.3 规则与数值

#### 状态机

在 [`fishingStateMachine`](../../../server/src/fishingStateMachine.ts) 增加短 phase：

| from | to | 条件 |
|------|-----|------|
| seated | groundbaiting | 打窝请求通过（金够、stack&lt;50、已解锁窝料） |
| groundbaiting | seated | `castDurationMs` 结束；stack+1；刷新 buff |
| seated | baiting… | 开始钓鱼（既有） |

`groundbaiting` **不可**直接进 `baiting`。

#### 叠层（定稿）

| 规则 | 值 |
|------|-----|
| `maxStackCount` | **50**（全局常量，硬 cap） |
| 同种窝 | **累层** `stackCount++` |
| 换窝料类型 | **重置** `stackCount = 1`（以新窝为第 1 层） |
| 离塘 / 换钓位 | **清空**窝效与 stack |
| 停钓回 seated（同钓位） | **保留**未过期窝效与 stack |

#### 咬钩加成（禁止线性）

每种窝料表字段 `perStackBiteBonus` ∈ **[0.005, 0.015]**（0.5%~1.5%）。

```text
stackCount = min(prev + 1, 50)   // 或换种重置为 1
bonus = maxBonus × (1 - exp(-stackK × stackCount))
effectiveBiteMul = 1 + bonus
```

- `maxBonus`：该窝渐近上限（须保证 **即使 50 层也不等于** `50 × perStackBiteBonus` 的线性满额）。
- 建议：`maxBonus ≈ perStackBiteBonus × 12` 量级再封顶（如 0.08 / 0.12 / 0.18），由数值表终定；**禁止** `1 + perStack × stack`。
- 与竿/饵加成：**各自 cap 后再相乘或相加**，总咬钩倍率再设全局 soft cap（建议 ≤ 1.5× 相对无窝基线，表 `biteMulGlobalCap`）。

#### 附近鱼尺寸（定稿）

- 窝效存续期间，对本钓位影响范围（同 `spotId` 或配置半径）内鱼实体施加 **临时** `sizeDelta`：
  - `sizeDelta = min(maxSizeBonus, f(stackCount))`，建议每层约 **0.002~0.008m**，总 cap **0.05~0.15m**。
- **不永久写库**：过期 / 离塘 / 换位后移除临时 buff；钓获结算用「基础尺寸 + 当时 buff」。
- 量级须**远小于**回鱼增重（RETURN-01 的 0.02~0.05m/次）。

#### 持续

`durationMin` 与 `maxBites` **先到失效**；失效后 stack 清零或仅清加成保留显示（默认：**清零 stack 与加成**）。

#### 数值表 sheet `groundbaits`

| 字段 | 说明 |
|------|------|
| `groundbaitId` | 主键 |
| `name` | 显示名 |
| `unlockPlayerLevel` | 解锁玩家等级 |
| `costGoldPerUse` | 单次金币 |
| `castDurationMs` | 等待 ms |
| `durationMin` | 持续分钟 |
| `maxBites` | 持续口数 |
| `perStackBiteBonus` | 0.005~0.015（策划标注用；曲线以 maxBonus/stackK 为准） |
| `maxBonus` | 渐近咬钩加成上限 |
| `stackK` | 曲线速率 |
| `sizeBonusPerStack` | 尺寸/层 |
| `maxSizeBonus` | 尺寸总 cap |

**初稿行（可调）**

| id | 解锁 | 金 | 等待 | perStack | maxBonus | stackK |
|----|------|-----|------|----------|----------|--------|
| gb-basic | Lv3 | 30 | 3000 | 0.006 | 0.08 | 0.08 |
| gb-mix | Lv5 | 50 | 5000 | 0.010 | 0.12 | 0.07 |
| gb-premium | Lv7 | 80 | 8000 | 0.014 | 0.18 | 0.06 |

全局：`maxStackCount = 50`。

## 4. 技术影响

### 4.1 数据模型

玩家 session 内存（权威）：

```text
groundbait: {
  groundbaitId, stackCount, expiresAt, bitesLeft,
  biteBonus, sizeBonus
}
```

可不落库；断线重连按既有 session 恢复策略（无则清空）。

### 4.2 API / Socket

| 类型 | 名称 | 说明 |
|------|------|------|
| Socket | `groundbait_start` | `{ groundbaitId }` → ACK 或错误 |
| Socket | phase / user 更新 | `fishingPhase=groundbaiting`，结束后 seated + buff 字段 |
| 错误 | `INSUFFICIENT_GOLD` | 触发 Overlay 文字气泡 |
| 错误 | `STACK_CAP` | 已达 50 |
| 错误 | `NOT_SEATED` / `LOCKED` | 状态不对 / 未解锁 |

咬钩结算读取 `user.groundbait.biteBonus`；尺寸抽样加 `sizeBonus`。

### 4.3 涉及文件（预估）

- `shared/generated/game-data`、`fishing` 咬钩合成
- `server/src/fishingStateMachine.ts`、扣金、塘实体临时 buff
- Unity Overlay 操作栏、窝料面板、气泡 presenter（复用 09C/SPOT）

### 4.4 埋点

| eventType | 关键 |
|-----------|------|
| `groundbait_cast_started` | playerId, pondId, groundbaitId, costGold, stackBefore |
| `groundbait_applied` | stackAfter, biteBonus, sizeBonus |
| `groundbait_rejected` | reason（gold / cap / state） |

## 5. 验收标准

- [x] seated 同时显示「开始钓鱼」「打窝」；打窝结束后回到选项，不自动开钓
- [x] 每次打窝扣表定金币与等待时间；金不足气泡提示且不进入 phase
- [x] stack 上限 50；满层不可再打
- [x] 咬钩加成为非线性公式，50 层不达到线性满额
- [x] 附近鱼尺寸有小幅临时增益，过期/离塘清除
- [x] 与 GEAR-01 按口饵扣金互不替代
- [x] 换窝料重置层数；离塘清空
- [x] 埋点三类事件可查（实现阶段同步埋点表）

## 6. 风险与依赖

| 风险 | 缓解 |
|------|------|
| 50 层刷金耗时过长 | 单次成本+等待；边际收益递减 |
| 尺寸 buff 被当成永久养成 | 明确临时、不写持久实体字段 |
| phase 与 start_fishing 竞态 | 服务端门禁：仅 seated 可 start / groundbait |
