## 1. 背景与定位

| 已有 | 缺口 |
|------|------|
| 单日运营日报 `report.html`（产量、生态、告警） | 缺**跨日趋势看板**（折线、可筛留存） |
| D-L3-03 留存雏形（多为 D1/D7） | 缺次日～30 日完整留存矩阵 + 可选曲线 |
| 业务健康近 N 日表 | 非增长/商业化视角，且无新进/留存/变现 |
| 策划进度看板 | 看需求进度，**不是**用户经营数据 |

**本需求**定义独立（或日报旁链）的 **「增长与经营看板」**：面向策划/运营看新增、活跃、留存与（预留）商业化；与 Admin 实时排障、单日日报互补。

```
Admin 实时排障  ≠  单日运营日报  ≠  本看板（跨日增长/商业化）  ≠  策划进度看板
```

入口建议：运营平台「每日必看」增加一卡，或分析归档索引置顶「增长看板」。

---

## 2. 北极星问题

打开看板应能回答：

1. 最近新增多少人？活跃稳不稳？  
2. 各 cohort 次日 / 3 / 7 / 10 / 14 / 30 日留存怎样？（可筛选）  
3. （上线变现后）投放贵不贵、人均产出多少、广告填充如何？（先占位）

---

## 3. 信息架构

```text
增长与经营看板 growth.html（建议路径 docs/analytics/growth/index.html）
├── 顶栏：日期范围 | 时区 Asia/Shanghai | 规则版本 | 刷新说明
├── §A 总览 KPI 卡（最新日 + 环比）
├── §B 活跃与新增（折线，可筛区间）
├── §C 留存（矩阵 + 可选折线，可筛 Dn）
├── §D 玩法健康（钓获/时长/断线，复用日报口径）
├── §E 商业化（预留 · 无数据时灰态「待接入」）
└── §F 数据说明 / 口径与已知局限
```

技术形态（实现可选其一，规格不绑死）：

- **静态**：日批生成 `growth/series.json` + Chart.js 页（与现有 analytics 一致，推荐 MVP）  
- **半动态**：Admin 或 `/analytics/growth/` 读预聚合 JSON

## 4. 指标词典

### 4.1 A. 增长核心（MVP 必须可算）

| 指标 ID | 名称 | 口径（权威） | 图表 |
|---------|------|--------------|------|
| `nu` | 新进用户 / 新增 | 当日 `players.created_at` 落在上海自然日的人数（**真人**；bot 账号不计） | 折线 · 柱 |
| `dau` | DAU | 当日任意有效行为 metrics 的唯一 `playerId`（排除 bot，口径对齐日报 `kpi_dau`） | 折线 |
| `wau` / `mau` | 周活 / 月活 | 滚动 7 / 30 日去重活跃 | 折线或卡 |
| `fishing_dau` | 钓鱼 DAU | 当日有 `fishing_start`（或等价）的唯一玩家 | 折线 |
| `nu_share` | 新增占 DAU | `nu / dau` | 卡 |
| `stickiness` | 粘性 | `dau / mau`（mau≥1） | 卡 |

**筛选（§B）**：日期范围（默认近 30 日）、是否含钓鱼 DAU 叠加线。

---

### 4.2 B. 留存（MVP 必须 · 扩展 D-L3-03）

| 指标 ID | 名称 | 口径 |
|---------|------|------|
| `retention_d1` | 次日留存 | cohort = 注册日新增；第 +1 日有活跃 |
| `retention_d3` | 3 日留存 | 第 +3 日有活跃 |
| `retention_d7` | 7 日留存 | 第 +7 日有活跃 |
| `retention_d10` | 10 日留存 | 第 +10 日有活跃 |
| `retention_d14` | 14 日留存 | 第 +14 日有活跃 |
| `retention_d30` | 30 日留存 | 第 +30 日有活跃 |

**活跃定义（与 D-L3-03 对齐）**：该自然日存在任意 `fishing_metrics`（或约定白名单事件）且 `playerId` 命中；**默认排除 bot**。

**展示**：

1. **Cohort 矩阵表**：行 = 注册日，列 = D1/D3/D7/D10/D14/D30，格内为比率；未到期格显示「—」或「未到期」。  
2. **折线图**：X = 注册日（或观察日），Y = 留存率；**可筛选显示哪些 Dn**（多选：默认勾选 D1、D7、D30）。  
3. **筛选**：注册日区间、最小 cohort 人数（默认 ≥5 才画点，防噪）、仅真人。

**计算时机**：日批可增量更新「已到期」格子；T+30 才满。看板需标注「截至某日已计算」。

### 4.3 C. 玩法 / 体验（MVP 建议有 · 复用日报）

| 指标 ID | 名称 | 说明 |
|---------|------|------|
| `daily_catch` | 日钓获 | 对齐 `kpi_daily_catch` |
| `catch_per_fisher` | 人均上岸 | |
| `avg_session_ms` | 人均钓鱼时长 | `daily_player_stats` |
| `disconnect_rate` | 断线率 | |
| `abandon_rate` | 弃钓率 | |
| `hook_rate` / `escape_rate` | 上钩频率 / 脱钩率 | D-L2-15 口径 |
| `join_fail_rate` | 进塘失败率 | |
| `avg_pop_ratio` | 鱼塘平均人口率 | 生态健康 |

折线：近 N 日可选叠加；告警阈值可链日报 alerts。

### 4.4 D. 商业化预留（P2 · 无数据也要占位）

> 当前无广告/IAP/投放账本时：**UI 灰态 + 「待接入数据源」**，禁止假数。  
> 下列为字段契约，便于后续埋点 / 广告平台 / 财务表接入。

#### D1. 变现与人效

| 指标 ID | 名称 | 典型口径 | 数据依赖 |
|---------|------|----------|----------|
| `revenue_total` | 总收入 | 日内 IAP+广告结算（本币） | 支付/广告回传 |
| `arpu` | ARPU | `revenue_total / dau` | 同上 |
| `arppu` | ARPPU | `revenue_total / 付费人数` | 付费事件 |
| `paying_rate` | 付费率 | 付费人数 / dau | |
| `iap_revenue` | 内购收入 | SKU 汇总 | IAP 埋点 |
| `ad_revenue` | 广告收入 | 广告平台或聚合 | 广告 SDK |
| `ad_arpu` | 广告 ARPU | `ad_revenue / dau` | |

#### D2. 广告库存

| 指标 ID | 名称 | 典型口径 |
|---------|------|----------|
| `ecpm` | eCPM | `ad_revenue / impressions * 1000` |
| `impressions` | 展示次数 | |
| `clicks` | 点击 | |
| `ctr` | CTR | clicks / impressions |
| `fill_rate` | 填充率 | filled / requests |
| `ad_ready_rate` | 就绪率 | 可选 |

#### D3. 投放获客

| 指标 ID | 名称 | 典型口径 |
|---------|------|----------|
| `spend` | 投放消耗 | 渠道账单 |
| `cpi` | CPI | `spend / 新增归因人数` |
| `cpa` | CPA | 按关键行为（如首钓） |
| `cac` | CAC | 综合获客成本 |
| `roas_d0/d7` | ROAS | 回收 / spend（按归因窗） |
| `channel` | 渠道维度 | organic / UA 渠道名 |

**归因**：预留 `attribution_source` / `campaign_id`（玩家或安装级）；未接归因前 CPI/ROAS 整区灰态。

### 4.5 E. 补充建议指标（本需求一并列入词典 · 分期实现）

下列为策划常问、与钓鱼社交场景相关；**列入规格以免遗漏**，实现可标 P1/P2/P3。

#### E1. 活跃质量（P1）

| 指标 | 说明 |
|------|------|
| 回流用户 | 曾活跃、间隔 ≥7 日再次活跃 |
| 连续活跃天数分布 | 1/3/7 日连登人数 |
| 高峰在线（近似） | 若有容量采样 / ready 快照可估；否则 P3 |
| Bot 占比 | 监控污染；默认图不混入真人曲线 |

#### E2. 内容 / 社交（P2，对齐 FEAT-SOC）

| 指标 | 说明 |
|------|------|
| 动态发布 UV/PV | 发帖人数/次数 |
| 点赞率 / 评论率 | 互动 / 曝光或 DAU |
| 私信 UV | 有发送行为的人 |
| 排行榜参与率 | 上榜或打开排行 UV / DAU |

#### E3. 经济循环（P1，对齐日报经济）

| 指标 | 说明 |
|------|------|
| 金币 faucet / sink / 净投放 | 防通胀 |
| 饵消耗 / 购买 | |
| 修竿次数与花费 | |

#### E4. 转化漏斗（P1）

| 步骤 | 说明 |
|------|------|
| 新进 → 进塘 | 注册当日 `join_pond_success` |
| 进塘 → 开钓 | `fishing_start` |
| 开钓 → 上钩 | `bite_hook` |
| 上钩 → 上岸 | catch accept |
| 新进 → D1 回访 | 与留存衔接 |

漏斗图：按日或按 cohort。

#### E5. 技术健康（P2，链 Admin/日报）

| 指标 | 说明 |
|------|------|
| crash / 客户端错误率 | client-logs 成熟后 |
| 进塘失败、断线超时 | 体验红线 |
| 日批失败 | `daily-batch-status` |

#### E6. 生态可持续（P1）

| 指标 | 说明 |
|------|------|
| 分塘人口率趋势 | 防竭泽而渔 |
| 品质结构 | 灰/绿占比漂移 |
