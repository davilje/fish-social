# 服务器维护：端口占用方案

| 状态 | **已实现** | 类型：运维 / 开发体验 |

---

## 1. 现状

| 服务 | 默认端口 | 启动方式 |
|------|----------|----------|
| API + WebSocket | **3001**（`PORT` 环境变量） | `npm run server` / `npm run dev` |
| Expo Web | **8082**（写死在 `mobile/package.json`） | `npm run web` / `npm run dev` |

**常见占端口原因**：

- 终端直接关掉，`tsx watch` / `expo` 子进程未退出
- 重复执行 `npm run dev`，旧实例仍在
- Cursor 多终端各跑一套 dev
- 服务端无优雅退出，`listen` 失败后无明确提示

## 2. 日常维护（立即可用，Windows）

### 2.1 查谁占了端口

```powershell
# 3001 服务端
netstat -ano | findstr :3001

# 8082 Web
netstat -ano | findstr :8082
```

最后一列为 **PID**。

### 2.2 结束进程

```powershell
taskkill /PID <pid> /F
```

### 2.3 一键清理（开发常用）

```powershell
# 结束监听 3001、8082 的进程（执行前确认无其他项目占用同端口）
foreach ($p in 3001, 8082) {
  netstat -ano | findstr ":$p " | ForEach-Object {
    $pid = ($_ -split '\s+')[-1]
    if ($pid -match '^\d+$') { taskkill /PID $pid /F 2>$null }
  }
}
```

### 2.4 推荐启动顺序

```bash
# 方式 A：一键（先确保端口空闲）
npm run dev

# 方式 B：分开终端，便于只看日志
npm run server    # 终端 1
npm run web       # 终端 2
```

**停止**：在对应终端 `Ctrl+C`，等进程退出后再关窗口；不要直接点 ×。

## 3. 规范方案（建议开发 Agent 实现）

### 3.1 npm 脚本（根目录 `package.json`）

| 脚本 | 作用 |
|------|------|
| `ports:check` | 打印 3001/8082 占用情况及 PID |
| `ports:free` | 仅结束本项目端口的 node/expo 进程（带确认或 `--force`） |
| `dev:clean` | `ports:free` → `npm run dev` |
| `server:clean` | `ports:free`（仅 3001）→ `npm run server` |

实现建议：跨平台用 `kill-port` 或 `scripts/ports.mjs`（Node），Windows 不必单独维护 ps1。

### 3.2 服务端优雅退出

在 `server/src/index.ts` 增加：

- 监听 `SIGINT` / `SIGTERM`
- `httpServer.close()`，关闭 Socket.io
- 超时后 `process.exit(0)`
- 端口被占用时 `listen` 错误打印：`端口 3001 已被占用，请运行 npm run ports:free`

### 3.3 环境变量统一

根目录 `.env.example`：

```env
PORT=3001
EXPO_WEB_PORT=8082
```

- 服务端：已有 `PORT`
- Web：`expo start --web --port ${EXPO_WEB_PORT}`（需脚本读取）
- 文档注明：改端口须同步 `mobile/lib/config.ts` 的 API 端口或改为读 env

### 3.4 开发约定

1. **单实例**：同一仓库只跑一套 `dev`
2. **换端口**：只改 `.env`，不手改多处 magic number
3. **提交前**：`ports:check` 确认无残留
4. **README** 增加「端口占用」小节，链到本文档

### 3.5 可选（后期）

| CI | 每次 job 随机端口或 job 结束 kill |

**本期不做** Docker/PM2，先把脚本 + 优雅退出 + 文档搞定。
