## 1. 背景与目标

### 1.1 背景

当前他人资料仅在 `UserProfileModal` 弹窗展示头像、昵称、ID、加好友按钮。个人中心（`/profile`）已有简介、8 格收藏品，但他人无法查看。服务端 `getPlayerPosts` 已实现按观看者过滤动态，但未暴露 REST API。

### 1.2 目标

- 在他人资料弹窗中展示：**简介**、**收藏品（8 格）**、**动态列表（按可见性过滤）**
- 弹窗可滚动，保留现有加好友 / 机器人标识逻辑
- 新增 API，复用服务端已有可见性逻辑

### 1.3 非目标

- 不做独立路由 `/profile/[playerId]`（后续可迭代）
- 不展示他人背包全量、金币数额
- 不改好友/私信核心流程（好友可见动态内可点进私聊入口为 P2，本期不加）
- 不做关注/取关

## 2. 用户与场景

| 角色 | 场景 | 期望结果 |
|------|------|----------|
| 访客 | 动态墙点击某用户头像 | 看到简介、收藏品、其 public 动态 |
| 好友 | 鱼塘在线列表点击好友 | 同上，且可见对方 `friends` 可见动态 |
| 非好友 | 查看陌生人 | 仅 public 动态；收藏品与简介仍可见 |
| 自己 | 点击自己 | 提示「这是你自己」，引导去 `/profile` 编辑 |

## 3. 功能范围

### 3.1 功能列表

| # | 功能点 | 优先级 | 说明 |
|---|--------|--------|------|
| 1 | 简介展示 | P0 | 来自 `profile.bio`；空显示「暂无简介」 |
| 2 | 收藏品展示 | P0 | 8 格只读；有鱼显示 emoji+品质色+鱼名+尺寸；空槽灰色占位 |
| 3 | 动态列表 | P0 | 最多 20 条，复用 `PostCard` 样式；按 viewer 过滤 |
| 4 | API | P0 | `GET /api/players/:playerId/public-view?viewer=` |
| 5 | 加载/错误态 | P0 | Loading、玩家不存在、离线提示 |
| 6 | 弹窗 UI | P0 | Modal 加 ScrollView，最大高度约 85vh |

### 3.2 交互与 UI

- **入口不变**：`social.tsx`、`pond/[id].tsx` 打开 `UserProfileModal`
- **布局**（自上而下）：头像 → 昵称 → 机器人徽章 → ID → 好友操作区 → 简介 → 收藏品标题+8格 → 动态标题+列表
- **自己**：不展示简介/收藏/动态区块，仅保留「这是你自己」
- **空状态**：无动态时显示「暂无动态」

### 3.3 规则与数值

| 规则 | 说明 |
|------|------|
| 动态可见性 | `public` 所有人；`friends` 仅好友或本人；与 `getPlayerPosts` 一致 |
| 收藏品 | 展示 `showcaseFishIds` 对应鱼信息；鱼已售出则从槽位显示「已失效」或空（槽位 id 在背包不存在则显示空位样式） |
| 动态条数 | API 默认 limit 20 |
| 简介长度 | 只读展示，最多 120 字（与 profile 一致） |

## 4. 技术影响

### 4.1 数据模型

无新表。响应 DTO：

```ts
interface PublicPlayerView {
  profile: PlayerProfile; // 不含敏感扩展
  showcaseFish: (FishInventoryItem | null)[]; // 8 格，按槽位顺序
  posts: SocialPost[];
}
```

收藏品：根据 `showcaseFishIds` 查对方背包中仍存在的鱼；id 为 null 或鱼不存在则该格为 null。

### 4.2 API

| 类型 | 名称 | 说明 |
|------|------|------|
| REST | `GET /api/players/:playerId/public-view?viewer=&limit=` | viewer 必填；返回 profile + showcaseFish + posts |

### 4.3 涉及文件

- `server/src/posts.ts` — 导出或复用 `getPlayerPosts`
- `server/src/players.ts` — 组装 showcase 鱼数据
- `server/src/socialRoutes.ts` — 注册路由
- `mobile/lib/socialApi.ts` — 客户端 API
- `mobile/components/UserProfileModal.tsx` — UI 增强
- `docs/planning/product/v0.1.0-功能全景.md` — 同步 §5.8、§12
