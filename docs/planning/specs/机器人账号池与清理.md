## 1. 背景

当前每次进塘 `spawnBot` 新建 `bot-{uuid}`，离塘只清内存，库内已堆积约 **1500** 个 bot 账号；昵称池仅 15 个。需要：固定账号池复用、扩名、一次性清理历史垃圾数据。

---

## 2. 目标态（运行时）

| 项 | 约定 |
|----|------|
| 账号池 | 一次性维护 **100** 个 `bot-*` 玩家（启动时 ensure，不足补齐，**禁止**运行中再 `randomUUID` 新建） |
| 进塘 | 从池中抽取 **当前未在任一塘内** 的 bot 进塘；离开后回池可再被抽 |
| 填满鱼塘 | **允许** bot 占满塘内全部钓位 / 人数上限（与 `spots.length` / `MAX_POND_USERS` 对齐，当前每塘 **20**） |
| 在塘上限 | `MAX_BOTS_PER_POND` 默认改为 **= 塘容量**（20），不再用 6；四塘理论同时最多约 **80** 在场（受池 100 约束） |
| 真人优先 | 真人进塘/占位时仍可踢 bot 腾位（既有逻辑保留） |
| 补人节奏 | 定期检查：塘内 bot+真人未满则从池抽空闲 bot 进塘直至满员或池空；**只进池、不建号** |
| 昵称 | 丰富名称库（≥80，建议 100+ 不重复或极少重复），池内 100 人尽量 **一人一名** |

```text
[100 bot 账号池]
    │ 抽取空闲
    ▼
进塘（可占满 20 位）──停留 1～3h / 被真人踢 ──► 离塘回池（账号保留）
```

---

## 3. 一次性清理（迁移 / 运维脚本）

### 3.1 保留与删除

1. 按「最近活跃」选出一批种子 bot（建议最多 **20～24**，或直接清空重建）。  
2. **删除**其余所有 `player_id LIKE 'bot-%'` 账号及相关行（见下）。  
3. 清理完成后（或同脚本第二步）：确保池内恰有 **100** 个 bot——  
   - 种子可并入新池后补满 100；  
   - 或：全部删光后重新创建 100 个（更简单，**推荐**）。  
4. 规格验收以 **池=100、可复用进塘、可填满单塘** 为准。

### 3.2 清除的 bot 历史钓鱼数据

对 **将被删除的 bot**，以及（若采用「池内也清空历史」）**最终 100 池账号**，清除：

| 数据 | 处理 |
|------|------|
| `fishing_metrics` 中 `player_id LIKE 'bot-%'`（目标集合） | DELETE |
| `inventory` 中对应 bot | DELETE |
| `daily_fishing` / gear / friend_* / posts 等明确归属该 bot 的行 | DELETE（能关联则清） |
| `players` 中被淘汰的 bot | DELETE |

### 3.3 看板数据 **不修改**（硬约束）

| 不做 | 说明 |
|------|------|
| 不重跑 / 不改写 | `docs/analytics/daily/**`、`growth/**`、已生成 `summary.json` / `report.html` / compact |
| 不 UPDATE | `daily_pond_stats` / `daily_player_stats` 等已聚合看板表（即使 bot metrics 已删） |
| 不因本需求 | 触发会改历史 KPI 的日批回填 |

清理只动 bot 原始明细；**历史看板数字保持现状**。新日批从清理后的库继续跑即可。

## 4. 名称

- 将 `BOT_NAMES` 扩到 **≥80**（目标覆盖 100 池一人一名）。  
- 风格：中文钓鱼/湖畔氛围昵称，避免低俗、避免与真人默认名强冲突。  
- 建池时按序或随机不重复分配；若名不够则后缀数字（尽量不用）。

---

## 5. 代码改造要点

| 区域 | 动作 |
|------|------|
| 池 | 表或约定：`bot_pool` / 或 `players` 标记 + 固定 100 id 列表；`ensureBotPool(100)` |
| `spawnBot` | 改为 `enterPondFromPool(pondId)`：抽空闲池成员 → `addBotUser`；池空或塘已满则跳过 |
| 上限 | `MAX_BOTS_PER_POND` 默认 **20**（或与塘 `spots.length` 同步）；配置项可保留供压测下调 |
| 离塘 | `removeBotUser` 后账号仍在池；**不**删 `players` |
| 禁止 | 运行热路径 `bot-${randomUUID()}` 新建 |
| 脚本 | `scripts/ops/cleanup-bot-pool.mjs`（或等价）执行 §3；可 `--dry-run` |
| 校验 | verify：池大小 100；同 id 可再进塘；无真人时可把单塘 bot 补到容量（填满） |
