## 1. 背景与目标

`FEAT-SPOT-02` 种子库约 **154 条**（22 tag × 7 条/tag），满足结构与 verify，但文案密度、塘型差异与口语节奏仍需策划扩写。

本票：在 xlsx **`spot_clue_texts`** 中增删改文案，丰富各 tag 的 habitat / 有征象 activity / 无征象 activity，并可选按 `pondCategory` 限定部分线索。

### 非目标

- 改坐席 UI / 气泡样式（`FEAT-SPOT-01`）
- 按 `activitySignal` 实时过滤（见 `FEAT-SPOT-05`）
- 文案绑定固定点位（仍按 tag 过滤，非一点一条）

---

## 2. 文案规则（权威：SPOT-02 §4.2）

### habitat

- **只写**地形、水色、结构、光照、风、岸貌等物理环境。
- **禁止**：鱼种名、喜好/厌恶、宜钓、开口、「会有 xx 鱼」等结论。

### activity

- **只写**可观察征象：气泡、涟漪、水色变化、草动、气味、声响、漂物、风向纹等。
- **禁止**：鱼星/鱼花/鱼群、开口差、白费力气、说明有鱼、xx 鱼出没、进窝等结论性用语。

每条 activity 必须填写 **`activitySignal`**：

| activitySignal | 用途 |
|----------------|------|
| `active_high` / `active_mid` / `active_low` | 有活性征象（强度递减） |
| `inactive` | 沉寂、无征象 |
| `disturbed` | 受扰动 |
| `habitat` | 仅 habitat 行使用 |
