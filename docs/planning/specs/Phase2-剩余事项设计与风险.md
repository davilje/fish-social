## 4. 实现后可能面临的风险（交付副作用）

| ID | 场景 | 等级 | 可能后果 | 护栏 |
|----|------|------|----------|------|
| R-post-01 | ARC-08 拆分后行为漂移 | **高** | 离塘/宽限/计时再次错乱 | 拆分前后对照 `verify:disconnect-reconnect` · `verify:session-checkpoint`；禁止「顺手改逻辑」 |
| R-post-02 | ARC-10 限流误伤 | 中 | 正规重连/多端被 429 | 按 IP+playerId 分层；白名单 admin；指标监控 429 率 |
| R-post-03 | DP-B 幂等落地不全 | **高** | 漏计或「看起来修了但仍双计」 | 明确 eventId 作用域（catch/accept）；聚合 DISTINCT 单测 |
| R-post-04 | PG 双写/切读 | **高** | 读写不一致、迁移窗口丢点 | 双写校验期；只读切换开关；回滚 SQLite 预案 |
| R-post-05 | admin-web 扩大攻击面 | 中 | 运维台暴露敏感 timeline | 复用 Admin RBAC；默认不公网；CSP/同源 |
| R-post-06 | L3/告警噪声 | 中 | 误报导致错误调参或告警疲劳 | 先对照、后告警；阈值需 `@data-analyst` 签收 |
| R-post-07 | BI 导出隐私 | 中 | CSV 含可还原身份 | D-L3-10 先于或同步 D-L3-06；导出脱敏清单 |
| R-post-08 | 用户删除/脱敏实现 bug | **高** | 删不干净或误删他人 | 干跑模式；审计日志；备份恢复演练 |
| R-post-09 | C6 状态机 + Bot | **高** | 真/Bot 不同步、塘被掏空或过冷 | C2 验收占比；灰度 C7；可回滚旧路径开关 |
| R-post-10 | C3 Sink 过猛 | 中 | 付费/留存下跌 | 先 30 日模拟；分塘/分档灰度 |
| R-post-11 | 可观测性「看起来很强」 | 中 | 团队只看仪表盘不改玩法 | L3 对照进周会；Kickoff 明确决策 owner |
| R-post-12 | 技术债反弹 | 低~中 | 新模块再堆巨型文件 | ARC-11 门禁 + code size 约定（单文件软上限） |
