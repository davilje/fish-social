## 1. 现象与复现

在已登录的桌面主壳中打开对应页面即可稳定看到。不经过鱼塘 Overlay，也不经过 Socket。

| 项 | 操作 | 预期 | 实际 |
|----|------|------|------|
| 设置 | 打开设置 | 窗口、通知、服务器字段上下分开，能点到每一项 | 多个字段叠在一起 |
| 探索世界 / 选择鱼塘 | 与商店、装备、图鉴对照 | 同一种页面外框：页眉 1370×96，正文高 496，内容右缘 1346 | 这两页的内容宽高和其它页不一致 |
| 首页 | 看首页左侧角色 | 全身分层猫咪（钓鱼/待机），不是资料头像 | `HeroCat` 显示成资料用的猫咪头像图 |
| 装备 | 打开鱼饵、钓竿列表和详情 | 同一件物品在卡片和详情上是同一张图，并跟物品 id 对应 | 图按中文名关键字猜测，列表和详情还会不一致 |

平台：Unity 桌面主窗口。与服务端进程启动时间无关。

## 2. 时间戳证据

本需求是主壳预制体和本地贴图，不经过下面这条链路。各节点记为不适用，不把责任归到服务器或网络。

```text
Overlay command_sent          不适用
Unity overlay_command_received 不适用
Socket event_sent             不适用
Server event_received         不适用
Socket ack_received           不适用
Unity state_queued            不适用
Overlay state_received        不适用
```

代码证据（2026-10-21，对照当前工程）：

- 设置：`CozyRedesignAuthoring.Settings` 把视口放成 1274×452，内容高 1080，控件仍是绝对坐标。`DesktopSettingsModalView.EnsureResolutionButtons` 把原来 555×50 的「普通窗口 1280×720」拆成四个分辨率按钮，塞进同一块区域。
- 页面尺寸：商店/装备页眉是 1370×96。探索世界、选择鱼塘的根节点被拉成铺满父级（`sizeDelta` 0，锚点 0–1）。选择鱼塘列表宽 1092；探索世界地图框 900×496、详情 402×496。图鉴是 900+402，商店是左栏 210 + 列表 710 + 详情 362，正文高都是 496。
- 首页：`HeroCat` 为 656×516。`DesktopShellUi.BuildHome` 调用 `PlayClip(..., "fishing")`。播放模式下 `SpriteFramePetRenderer.StartLayers` 只取缓存；缓存没有时 `Apply` 把 `Image` 设成 `PetArtLoader.FallbackPortrait`，也就是资料头像 PNG。
- 装备图：`DesktopShopPanel.CreateCard` 调用 `CozyItemArt.Product(tab, null, 显示名)`。详情则传入物品 id。`Product` 用「竹 / 远 / 木 / 虾 / 麦 / 混」等子串选图。目录里的鱼饵是 `bait-basic` 基础杂饵、`bait-veg` 谷物饵、`bait-mix` 腥香饵、`bait-meat` 荤腥饵。谷物饵、荤腥饵对不上关键字，卡片落到 `bait-basic`；腥香饵的详情因为 id 含 `mix` 会变成 `bait-mixed`，卡片不会。钓竿 8 支，图集只有 `rod-bamboo`、`rod-light`、`rod-wood`、`rod-long` 四张，除竹制手竿外多数落到 `rod-light`。

## 3. 根因分层

| 层 | 判断 |
|----|------|
| 服务端 / 数据库 | 不适用。物品 id 与名称已在本地 `GameData`，不改表。 |
| Socket / ACK | 不适用 |
| Unity 主线程表现 | 是。设置绝对坐标重叠；首页缓存未命中时退回头像；装备图按名称猜测。 |
| Named Pipe | 不适用 |
| Overlay 渲染 | 不适用。不改塘内画布。 |

## 4. 修复

### 4.1 设置

把设置内容改成从上到下的单列，行与行不得相交。分辨率四个按钮独占一行，顺序仍是 1280×720、1600×900、1920×1080、2560×1440。服务器、通知、托盘、退出各自成行。内容超出视口时只允许纵向滚动。保留 STEAM-DESKTOP-20 的窗口尺寸规则。

### 4.2 探索世界、选择鱼塘

两页外框与商店、装备、图鉴相同：

- 页眉 1370×96
- 正文顶在 y=112，高 496
- 内容右缘 x=1346

探索世界沿用图鉴的 900 宽主区 + 402 宽详情，不要再出现另一套页面宽高。选择鱼塘保留左栏 210，主列表宽与商店列表面板一致（710），右侧留出与商店详情同宽的 362 区域；没有独立详情时，这块区域可以是说明，不能把列表拉到 1092。

### 4.3 首页角色

`HeroCat` 显示全身分层猫咪。缓存未就绪时继续准备钓鱼或待机图层，不得把资料头像 PNG 画进这个格子。顶栏小头像仍用资料头像。

### 4.4 鱼饵与钓竿

列表和详情都按 id 取同一张图，禁止再用显示名子串。

| 鱼饵 id | 名称 | 图 |
|---------|------|----|
| bait-basic | 基础杂饵 | bait-basic |
| bait-veg | 谷物饵 | bait-wheat |
| bait-mix | 腥香饵 | bait-mixed |
| bait-meat | 荤腥饵 | bait-shrimp |

| 钓竿 id | 名称 | 图 |
|---------|------|----|
| rod-bamboo | 竹制手竿 | rod-bamboo |
| rod-tai | 台钓碳素竿 | rod-light |
| rod-stream | 溪流竿 | rod-light |
| rod-iso | 矶钓竿 | rod-long |
| rod-surf | 海竿 | rod-long |
| rod-lure | 路亚竿 | rod-wood |
| rod-heavy | 重型路亚竿 | rod-wood |
| rod-giant | 巨物竿 | rod-long |

现有图集只有 4 张竿。上表是 id 到现有格子的固定对应，同一 id 在卡片和详情必须相同。不新画竿图。

## 5. 非目标

- 不改 Overlay 960×560，不改窗口四档分辨率和禁止拖边。
- 不改鱼饵、钓竿的玩法数值和 id。
- 不新增钓竿插画。
- 不改 `mobile/`、`server/`、`shared/`。

## 6. 回滚

只动桌面 UI 预制体和 `CozyItemArt` / 首页渲染的取图路径。出问题时恢复这些预制体和这两个调用点即可，不影响存档和钓鱼结算。

## 7. 验收

- [ ] 设置页任意两个可点击控件的矩形不相交；四个分辨率按钮仍能切换窗口。
- [ ] 探索世界、选择鱼塘与商店的页眉宽 1370、正文高 496、内容右缘 1346。
- [ ] 首页 `HeroCat` 是全身猫咪图层，不是资料头像；顶栏头像仍是资料头像。
- [ ] 四条鱼饵在卡片和详情上使用上表同一张图。
- [ ] 八支钓竿在卡片和详情上使用上表同一张图。
