## 0. 文档目的

v0.4.4 解决了**可观测性**（埋点、timeline、断线修复）；v0.5 解决**架构根因**：

1. 身份可被伪造（P0 安全）
2. 在线态重启即丢（P0 一致性）
3. 定时器与咬钩双轨（P0 正确性）
4. 入口过载与映射碎片（P1 可维护性）
5. 性能与安全默认值（P2 扩展与部署）

本文档为**分期路线图**；每项需求的详细修复步骤见 xlsx 对应 sheet。

## 1. 当前架构摘要

```text
Express + Socket.io (index.ts 编排)
    ├── gameState（内存：sessions / pondUsers / 钓位）
    ├── fishingStateMachine（phase / disconnect 60s）
    ├── fishingSession（hook timer / bot 咬钩 — 待收敛）
    ├── inventory（pending 内存锁）
    ├── pondEcology（SQLite 生态）
    └── fishingMetrics + admin（SQLite 埋点 / 调试）
```

**身份模型**：`playerId`（持久）· `userId`（单次 join）· `socketId`（连接）三套 ID + 三套 Map。

**存储分界**：生态/背包/玩家资料落库；钓位、phase、pending、断线宽限全内存。

## 3. 分期实施

### 3.1 第一期 — 正确性加固（P0，必须）**已实现**

**目标**：不可伪造身份；重启可恢复核心在线态；定时器与咬钩单一权威路径。

| 顺序 | 项 | 依赖 | 交付物 |
|------|-----|------|--------|
| 1 | R0-1 鉴权 JWT | 无 | `auth.ts`、Socket `auth.token`、HTTP 中间件、`verify-auth.ts` |
| 2 | R0-3 定时器注册表 | 无 | `timerRegistry.ts`、迁移 disconnect/hook/pending |
| 3 | R0-4 咬钩收敛 | R0-3 | 废弃 `hookStateByUser`、bot 共用咬钩内核 |
| 4 | R0-2 在线态 checkpoint | R0-1 建议先 | `player_pond_session` 表、join/reconnect 恢复、pending 落库 |

**一期不改**：多实例、Redis、钓鱼公式。

## 4. 一期需求摘要（R0-1 ~ R0-4）

### 4.1 R0-1 鉴权

- 签发 JWT（`playerId`, `exp`）；环境变量 `JWT_SECRET`
- Socket.IO `io.use` 校验 `handshake.auth.token`
- REST 写接口 `requireAuth` 中间件；**以 token 内 playerId 为准**
- 日志：`auth_failed`、`identity_mismatch`
- 联调期可提供 `AUTH_DISABLED=1`（仅 development，默认 false）

### 4.2 R0-2 在线态 checkpoint

**表 `player_pond_session`**（migration）：

| 列 | 说明 |
|----|------|
| player_id | PK 之一 |
| pond_id | PK 之一 |
| user_id | 塘内会话 ID |
| spot_id | 可空 |
| fishing_phase | 可空 |
| phase_ends_at | 可空 |
| hook_ends_at | 可空 |
| disconnected_at | 可空 |
| updated_at | ms |

**写时机**：phase 变更、占座/离席、disconnect、lockPendingCatch  
**删时机**：leave、accept、expired、disconnect_timeout 清场

**pending**：`pending_catch_locks` 表或扩 inventory；重启扫描过期。

### 4.3 R0-3 定时器注册表

```typescript
// timerRegistry.ts 最小 API
register(opts: { userId?: string; socketId?: string; kind: string; ms: number; onFire: () => void }): string
cancelByUser(userId: string): void
cancelBySocket(socketId: string): void
cancelByKind(userId: string, kind: string): void
cancelAll(): void
listActive(): Array<{ id, kind, userId?, socketId?, firesAt }>
```

`kind` 枚举：`disconnect_grace` | `hook_legacy` | `pending_expire`

### 4.4 R0-4 咬钩收敛

- `fishingSession.ts` 保留：`rollBiteHook`、`pickSpotFishCandidate`、概率计算
- 移除：`hookStateByUser` 与 `processBotBiteTick` 独立 timer 路径
- `bots.ts` 调用与真人相同的 waiting tick 入口
- `hooked` 超时仅由 `tickFishingPhases` + `phaseEndsAt` 推进
