## 1. 背景与目标

### 1.1 背景

动态仅支持发布与浏览，无法讨论鱼获，社交深度不足。

### 1.2 目标

- 对可见动态发表评论
- `PostCard` 显示评论数；可展开评论区
- 新评论经 Socket 推给在线客户端
- 评论作者 / 动态作者可删除评论（P1）

### 1.3 非目标

- 不做评论点赞
- 不做楼中楼 / @ 回复链
- 不做内容审核机审（MVP 仅长度与空白校验）
- 不做评论编辑
- 不做站内信/推送「有人评论了你」（仅 Socket UI 刷新）

## 2. 用户与场景

| 角色 | 场景 | 期望 |
|------|------|------|
| 玩家 | 点 💬 | 展开评论区：列表 + 输入框 |
| 玩家 | 发送评论 | 列表追加、计数 +1、输入清空 |
| 玩家 | 看他人主页动态 | 同样可评（可见帖） |
| 评论作者 | 长按/按钮删除 | 删自己的评论 |
| 动态作者 | 删除不当评论 | 可删本帖下任意评论 |

## 3. 功能范围

### 3.1 功能列表

| # | 功能点 | 优先级 | 说明 |
|---|--------|--------|------|
| 1 | 发表评论 | P0 | 最长 200 字，trim 后非空 |
| 2 | 评论列表 | P0 | 时间正序；游标分页 |
| 3 | 评论计数 | P0 | `comment_count` + 列表字段 |
| 4 | Socket `post_commented` | P0 | 实时追加 |
| 5 | 删除评论 | P1 | 评论作者或动态作者 |
| 6 | 展开/收起评论区 | P0 | 默认收起，点 💬 展开 |

### 3.2 交互与 UI

**操作栏**（与点赞共用）：`[❤️ n]  [💬 m]`

- 点 💬：展开评论区（不必进独立路由）
- 列表：头像、昵称、正文、相对/本地时间；点头像 → `UserProfileModal`
- 输入：单行/多行均可，发送按钮；超 200 禁止发送并提示
- 发送成功：列表滚到底；失败保留草稿文案

**空状态**：无评论时示「抢沙发」类短文案 + 输入框。

### 3.3 规则

- 最长 **200** 字（按 JS 字符串 length）；超长 `400`
- 每帖每人评论条数不限（防刷：同玩家 3 秒内重复提交返回 `429`）
- 空白 / 纯空白拒绝
- **可删**：评论作者删自己的；动态作者删本帖任意评论
- **不可编辑**
- Bot 帖可被评论；Bot **不自动评论**

## 4. 技术影响

### 4.1 数据模型

```sql
CREATE TABLE post_comments (
  id TEXT PRIMARY KEY,
  post_id TEXT NOT NULL,
  player_id TEXT NOT NULL,
  nickname TEXT NOT NULL,
  text TEXT NOT NULL,
  created_at INTEGER NOT NULL
);
CREATE INDEX idx_post_comments_post ON post_comments(post_id, created_at ASC);

ALTER TABLE social_posts ADD COLUMN comment_count INTEGER NOT NULL DEFAULT 0;
```

### 4.2 类型

```ts
export interface PostComment {
  id: string;
  postId: string;
  playerId: string;
  nickname: string;
  avatarUrl?: string; // 读取时拼 profile，可不落库
  text: string;
  createdAt: number;
}

// SocialPost.commentCount 见点赞规格
```

Socket：

```ts
post_commented: (payload: { postId: string; comment: PostComment }) => void;
post_comment_deleted: (payload: { postId: string; commentId: string; commentCount: number }) => void;
```

### 4.3 API

| 方法 | 路径 | 鉴权 | 说明 |
|------|------|------|------|
| POST | `/api/posts/:postId/comments` | `requireAuth` | body: `{ text }`；nickname 取服务端档案 |
| GET | `/api/posts/:postId/comments` | 可见性校验 | `limit`（默认 20）· `before`（createdAt 游标，拉更早）首次正序最新一页也可用 `after` 省略=从旧到新首页 |
| DELETE | `/api/posts/:postId/comments/:commentId` | `requireAuth` | 评论作者或动态作者 |

**分页约定（MVP）**：

- `GET ...?limit=50` 返回该帖最早 50 条（正序），足够内测；超出再上 `before`/`after`
- 响应：`{ comments: PostComment[], commentCount: number }`

**POST 响应**：`{ comment: PostComment, commentCount: number }`

### 4.4 涉及文件

- `shared/social.ts`、`shared/types.ts`
- `server/src/posts.ts`（或 `postComments.ts`）、`socialRoutes.ts`、migration、`playerPrivacy.ts`
- `mobile/components/PostCard.tsx`（或 `PostCommentsPanel.tsx`）、`socialApi.ts`、`social.tsx`

### 4.5 隐私

- 导出：用户发表的评论
- 删号：删其评论并回减 `comment_count`；其动态下评论随帖删除策略与现帖删除一致

## 5. 验收标准

- [ ] 登录用户可对可见帖发表 ≤200 字评论；计数正确
- [ ] 评论区正序展示头像/昵称/内容/时间
- [ ] Socket `post_commented` 使其他在线客户端列表追加
- [ ] （P1）评论作者可删自己的评论；动态作者可删本帖评论；Socket `post_comment_deleted` 或等价刷新
- [ ] 未登录发表 → `401`；不可见帖 → `404`
- [ ] 3 秒防刷生效
