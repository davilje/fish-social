## 1. 背景与目标

### 1.1 背景

当前鱼塘出鱼、品质分布、咬钩/体长基数仍大量硬编码：

- **种池 / 出鱼**：`STOCK_TEMPLATES` 四模板轮转 20 塘（`shared/pondEcology.ts`），`pond_fish_pool.json` 曾为 stub、**运行时未读**。
- **品质权重**：全局 `FISH_QUALITIES.weight`，未按塘分级区分。
- **尺寸上限**：代码 `QUALITY_SIZE_CAP`；`pond_fish_size_cap` 未接线且已废弃。
- **咬钩 / 脱钩基数**：写在 `shared/fishing.ts`。

策划要求：**表格为权威源**，**公式结构不变**，仅把基数与出鱼规则迁入表。

### 1.2 目标

1. **塘鱼种池表驱动**：每塘独立种池（**仅种、不含品质列**）；播种先抽种，再抽品质。
2. **品质出率**：`pond_category_quality_weights` × 种 `qualityMin`/`qualityMax` 求交后加权。
3. **尺寸上限**：按品质 `fish_quality_stats.sizeCapM`；**不做**塘/种三维 override。
4. **体长 / 咬钩 / 脱钩基数表驱动**：迁入 `fishing_formula_constants` / `fish_quality_stats`。
5. **咬钩 / 脱钩公式不变**：仅常数改读表。
6. **重量展示**：`W = a × L^b`（`LENGTH_WEIGHT_A` / `LENGTH_WEIGHT_B`），**不落库**。

### 1.3 非目标

- 修改咬钩 / 脱钩 **公式形状**。
- 启用 `pond_fish_size_cap` / `pond_quality_cap`（已从 xlsx 移除）。
- 种池行绑定 `quality`（旧方案已废）。
- 改卖价 / XP / 回鱼 / 扣费逻辑。
- Mobile/Web 生态全量对齐（重量展示可顺手）。

### 3.2 数值表设计（权威）

来源：`scripts/game-data/build_balance_xlsx.py` → `npm run game-data:export`。

#### 3.2.1 `pond_fish_pool`（定稿）

| 列 | 类型 | 说明 |
|----|------|------|
| `pondId` | string | 塘 ID |
| `speciesId` | string | 鱼种 |
| `speciesName` | string | 中文名（只读展示） |
| `spawnWeight` | float | 抽种相对权重，≥0 |
| `enabled` | bool | FALSE 不参与抽取 |

**出鱼逻辑（定稿）**

```text
播种 / 补充一条：
  speciesId = pickPondSpecies(pondId)           // 种池加权
  quality   = rollPondQuality(pondId, qMin, qMax) // 塘权重 ∩ 种带
  sizeM     = rollJuvenileSize(quality)         // 品质 sizeCap
  // weightKg 仅 UI：calcFishWeightKg(sizeM)
```

**禁止**：在 pool 行上绑 `quality`（同种多品质多行方案已废）。

#### 3.2.2 `ponds` 人口列（原 `pond_ecology` 已并入）

| 列 | 说明 |
|----|------|
| `maxPopulation` | 塘内鱼实体上限 |
| `minPopulation` | 低于此触发补充 |
| `initialPopulation` | 开服 seed 数量 |

运行时仍可通过 `getPondEcologyDef(pondId)` 从 `ponds` 投影（兼容旧调用）；**不再导出** `pond_ecology.json`。

#### 3.2.3 `pond_category_quality_weights`（新）

| 列 | 说明 |
|----|------|
| `pondCategory` | novice … giant |
| `quality` | gray … gold |
| `spawnWeight` | 整数权重 |

用途：播种品质；补充 D8 ideal 占比。

| pondCategory | 倾向 |
|--------------|------|
| `novice` | 仅 gray–green |
| `advanced` / `veteran` | 接近全局基准 |
| `wilderness` / `reservoir` | 高品质略升 |
| `forbidden` / `giant` | 高品质再升 |

#### 3.2.4 `fish_quality_stats`（玩法 + 卖价同表）

| 列 | 说明 |
|----|------|
| `quality` | 主键 |
| `sizeCapM` | 品质体长上限 |
| `biteBaseAtMaxSize` | 满尺寸咬钩基数 |
| `displayName` | 中文品质名 |
| `QUALITY_BASE` / `SIZE_REF` / `MIN_SELL` | 卖价公式（**不含钓组系数**） |

卖价：`floor(QUALITY_BASE × (sizeM/SIZE_REF)^SIZE_EXP)`，再 `max(..., MIN_SELL)`。  
`catchGroup` 仅用于竿适配（`rods.fit*`），不参与卖价。

~~`fish_sell`~~：**已并入本表并删除。**

#### 3.2.5 `fishing_formula_constants`

既有咬钩/脱钩/幼鱼常数外，增加：

| key | 默认 | 用途 |
|-----|------|------|
| `LENGTH_WEIGHT_A` | 12 | `W(kg)=a×L(m)^b` |
| `LENGTH_WEIGHT_B` | 3 | 展示用不落库 |

### 3.3 与种表协作（FISH-CN）

| 字段 | 规则 |
|------|------|
| `qualityMin` | 恒为 **1**（gray） |
| `qualityMax` | rarity：common→4 … legendary→7 |
| `typicalMinM` / `typicalMaxM` | **图鉴展示 only**，不参与出生体长 |

### 3.4 废弃 / 不再接线

| 资产 | 处理 |
|------|------|
| `STOCK_TEMPLATES` | 删除 / deprecated 转发表 |
| `FISH_QUALITIES.weight` | 生态不读 |
| `pond_fish_size_cap` / `pond_quality_cap` | 已从 xlsx 移除 |
| `pond_ecology` sheet | **已并入 `ponds`** 人口三列 |
| `fish_sell` sheet | **已并入 `fish_quality_stats`**；卖价无钓组系数 |
| `fish_species_habitat` | 不接线（见 FISH-CN） |
| 物种 `biteWeight` / `baseEscapeRate` | deprecated |
