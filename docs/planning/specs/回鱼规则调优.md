## 1. 背景与目标

### 1.1 背景

R2 交付的回鱼 / 双价塘机制在实装后需收紧三条规则，使经济激励与玩法边界更清晰：

1. 回鱼不应「全鱼可回」——仅高品质、大体长鱼应回塘；其余照常入包可卖。
2. 回鱼应比直接卖店更划算，以激励养塘循环。
3. 免票塘不应提供回鱼能力，回鱼专属于收费塘玩法。

### 1.2 目标

- **准入统一**：手动回鱼与自动回鱼共用 `isReturnEligible`（紫品及以上 + 体长比 ≥75% + 未满尺寸）。
- **经济调参**：回鱼金 = `floor(卖价 × 1.5)`（`goldMulVsSell = 1.5`）。
- **塘别门禁**：仅 `feePer2hSellOnly > 0` 且 `allowsAutoReturn = true` 的塘允许回鱼；免票塘 / 仅出售收费塘返回 `POND_NO_RETURN`。
- **自动路径**：`auto_return` 档达标鱼自动回塘；不达标鱼**留在背包**，可卖。

### 1.3 非目标

- 不改卖价公式、增重区间、熟练度发放。
- 不改进塘双价 UI 结构与票价倍率。
- 不开放跨塘 / 免票塘回鱼。

## 3. 功能范围

### 3.1 功能列表

| # | 功能点 | 优先级 | 说明 |
|---|--------|--------|------|
| 1 | 统一回鱼准入 | P0 | `isReturnEligible`；表 `minQuality=minSizeRatio` 与 `autoMin*` 对齐为 purple / 0.75 |
| 2 | 回鱼金价 1.5× | P0 | `return_rules.goldMulVsSell = 1.5` |
| 3 | 收费塘门禁 | P0 | `pondAllowsReturnFish()` |
| 4 | 自动路径留包 | P0 | 不达标 `tryAutoReturnFish` → skip，鱼仍在背包 |
| 5 | UI 文案 | P1 | 背包预估「卖价×150%」 |

### 3.2 规则与数值（定稿）

**`return_rules`（表首行）**

| 字段 | 值 | 说明 |
|------|-----|------|
| `minQuality` | `purple` | 与自动门槛一致 |
| `minSizeRatio` | `0.75` | 与 `autoMinSizeRatio` 一致 |
| `autoMinQuality` | `purple` | 自动回鱼门槛 |
| `autoMinSizeRatio` | `0.75` | 相对品质 max |
| `goldMulVsSell` | **1.5** | 回鱼金高于卖价 |
| 其余 | 不变 | 增重 0.02~0.05m、XP 8/4 |

**塘别**

```text
pondAllowsReturnFish(pond) =
  pond.allowsAutoReturn === true
  AND resolvePondFeePer2h(pond, 'sell_only') > 0
```

**捕获结算（auto_return 档）**

```text
accept_catch → 入包
tryAutoReturnFish:
  if !pondAllowsReturnFish → skip（留包）
  if !isReturnEligible → skip（留包）
  else → returnFishToPond(auto=true)
```

### 3.3 错误码（新增）

| code | 含义 |
|------|------|
| `POND_NO_RETURN` | 本塘不支持回鱼（免票或未开启回鱼） |

## 5. 验收标准

- [x] 回鱼金 = `floor(卖价 × 1.5)`；表与运行时一致
- [x] 紫+且体长比 ≥0.75 方可回；灰/蓝/过小紫 → 拒绝或自动 skip 留包
- [x] 免票塘（如 `pond-novice`）`pondAllowsReturnFish === false`；API 返回 `POND_NO_RETURN`
- [x] `auto_return` 档：达标自动回塘；不达标鱼仍在背包且可卖
- [x] `sell_only` 档：与 RETURN-02 一致，无回鱼
- [x] verify 脚本全部通过
