## 1. 目标

1. 品质出生固定、终生不变；尺寸随品质封顶。
2. 咬钩概率改为「鱼 biteWeight + 钓点 spotBite + 饵加成」的**指数聚合模型**。
3. 咬钩瞬间判定脱钩（脱钩率 = 鱼种 base + 品质加成 − 渔具减免，本阶段渔具默认 basic）。
4. 池塘初始化产出多种品质与尺寸的合理分布。
5. 完成 v1 → v2 的数据迁移。
6. **不改动**现有 socket 事件时序与客户端动画；仅在服务端替换计算逻辑并调整 payload 字段。

## 2. 范围

## 3. 数值定稿

### 3.1 品质—尺寸上限

| 品质 | maxSizeM |
|---|---|
| gray | 0.30 |
| green | 0.80 |
| blue | 2.0 |
| purple | 4.5 |
| red | 9.0 |
| orange | 18 |
| gold | 40 |

### 3.2 出生尺寸公式

```
qualityIndex = 0..6  (gray=0 ... gold=6)
floor   = max(MIN_FISH_SIZE_M, species.typicalMinM * 0.6)
ceiling = min(maxSizeM(quality), species.typicalMaxM * 0.45)
r       = Math.pow(Math.random(), 2 + qualityIndex * 0.3)
sizeM   = floor + (ceiling - floor) * r
```

**设计意图**：高品质鱼出生更偏小，成长空间更大。

### 3.3 成长公式

```
maxSize     = min(QUALITY_SIZE_CAP[quality], species.typicalMaxM * 3.2, MAX_FISH_SIZE_M)
progress    = currentSizeM / maxSize
speedFactor = (1 - progress)^1.5
delta       = species.typicalMinM * POND_GROWTH_RATE_PER_HOUR * hoursElapsed * (0.8 + speedFactor)
newSize     = min(maxSize, round2(currentSizeM + delta))
// quality 字段不更新
```

### 3.4 鱼种字段扩展

```ts
interface FishSpecies {
  // ...现有字段
  biteWeight: number;         // 每 5s tick 参与累加抽选的基础权重
  baseEscapeRate: number;     // 咬钩后基础脱钩率 0~1
  diet: 'herbivore' | 'omnivore' | 'carnivore';  // A0 只落字段，B1 使用
}
```

**示例初值**：

| 鱼种类别 | 代表鱼种 | biteWeight | baseEscapeRate | diet |
|---|---|---|---|---|
| 常见小型 | crucian / tilapia | 0.12 | 0.08 | herbivore |
| 常见中型 | carp / herring / mackerel | 0.10 | 0.10 | omnivore |
| 稀有掠食 | bass / trout / mandarin | 0.08 | 0.14 | carnivore |
| 大型远洋 | tuna / salmon / pike | 0.06 | 0.18 | carnivore |
| 巨型稀有 | marlin / sturgeon | 0.04 | 0.25 | carnivore |

### 3.5 池塘初始种群分布

`seedPond` / `createFish` / `tryRecover` 补种统一走：

1. `speciesId` ← `pickSpecies(config)`
2. `quality` ← `rollFishQuality()`（沿用 `FISH_QUALITIES.weight`）
3. `sizeM` ← `rollInitialSize(quality, species)`
4. 可选个体咬钩浮动：`biteWeight = species.biteWeight * (0.9 + random*0.2)` 写入 DB

**繁衍**：子代品质独立掷骰（用全局 `FISH_QUALITIES.weight`），尺寸用 `rollInitialSize`，**不继承父母品质**。

### 3.6 钓点咬钩权重

保留 `spot_bite_weights` 表与 5 分钟刷新；数值语义为**与鱼 biteWeight 相加**。

- 建议刷新范围 `0.04 ~ 0.20`

### 3.7 咬钩检测（指数模型）

```
BITE_LAMBDA = 0.02          // 运行时可配置（C 期热更）
TICK_MS     = 5000

for each waiting player:
  w_i = (fish.biteWeight ?? species.biteWeight) + spotBite(pondId, spotId)
  W   = Σ w_i  (未锁定鱼)
  P_tick = 1 - Math.exp(-W * BITE_LAMBDA)
  if random < P_tick:
    target   = weightedPick(fishes, w_i)
    escaped  = random < escapeRate(target, tackleId='basic')
    hookMs   = clamp(1800 + qIdx*700 + target.sizeM*400, 2000, 12000)
    schedule resolve at now + hookMs
```

**P_tick 校准表**（验收基线）：

| W | P_tick | 场景 |
|---|---|---|
| 0.22 | ≈ 0.4% | 空塘 1 条鱼 |
| 2.2 | ≈ 4.3% | 稀疏塘 10 条鱼 |
| 6.6 | ≈ 12.4% | 常规塘 30 条鱼 |
| 17.6 | ≈ 29.6% | 满塘 80 条鱼 |
| 24.0 | ≈ 38.1% | 满塘 + live 饵（B0 上线后） |

### 3.8 咬钩时长与脱钩率

```
qualityIndex   = 0..6
hookDurationMs = clamp(1800 + qualityIndex*700 + target.sizeM*400, 2000, 12000)

QUALITY_ESCAPE_BONUS = {
  gray: 0, green: 0.03, blue: 0.06, purple: 0.10,
  red: 0.15, orange: 0.20, gold: 0.28
}

escapeRate = clamp01(
  species.baseEscapeRate + QUALITY_ESCAPE_BONUS[quality]
  // A0 无渔具减免，B0 上线后减 tackleEscapeReduction
)
```

**保持高脱钩率**（产品决策）：金色大鱼种可达 53% 脱钩，A0 上线后灰度期需监控玩家挫败反馈。

## 4. 数据迁移

**迁移脚本 `migrations/2026xx_fishing_v2_seed.ts`**：

1. `ALTER TABLE pond_fish ADD COLUMN bite_weight REAL NULL`
2. 扫描所有 `pond_fish`：
   - 若 `sizeM > QUALITY_SIZE_CAP[quality]` → **提升 quality** 到刚好覆盖当前 size 的档位（不砍尺寸）
   - `bite_weight` 保持 NULL（运行时用 species 默认）
3. 冻结 `deriveQualityFromSize` 调用路径，仅保留野生兜底 `rollFishCatch`，加 `@deprecated` 注释

**Dry-run**：上线前先执行仅打印模式，输出所有 `sizeM > cap[quality]` 的记录与调整后品质。

**回滚**：
- 备份 `pond_fish` 与 `spot_bite_weights`
- feature flag `FISHING_V2 = true` 可紧急切回旧公式（旧代码保留 1 个版本周期）
