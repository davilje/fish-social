## 背景（开发快速理解）

用户反馈三类问题：

1. 收杆后再次钓鱼，角色头顶时长没有归零
2. 收杆（`hooked`）倒计时是否准确
3. 时间文字框太窄，无法完整显示 `23小时59分59秒`

**根因**：角色头顶 `PondCharacter` 误用 `todayFishingMs`（今日累计），玩家期望看到的是 **本次会话** 时长（`fishingStartedAt` 起算）。今日累计应只在底栏「今日剩余」展示。

## 待开发（本交接范围，全部 P0）

### 任务 1 — 时长语义拆分（服务端）

**Spec**：主 Spec §3.1、§3.2

1. 新增 `computeSessionFishingMs(user)`（或等价）：
   ```text
   status === 'fishing' && fishingStartedAt != null
     ? Date.now() - fishingStartedAt
     : 0
   ```
2. `buildSnapshot` / 每秒广播的 `pond_user_updated` 中：
   - `todayFishingMs`：继续表示今日累计（含当前未落库段：`todayFishingMs + elapsed` 或落库后基准值）
   - 下发 **`sessionFishingMs`**（建议在 `shared/types.ts` 的 `PondUser` 增加可选只读字段，或在广播时附带）
3. **今日累计落库**（修复缺陷）：在以下时机调用 `addTodayFishingMs` 并重置 `fishingStartedAt` 锚点：
   - `advanceFromStopping` → `seated` 完成时
   - `hooked` 阶段 `stop_fishing` 走脱钩并回到 `seated` 时（若会话结束）
   - 与现有 `leavePond` / `removeDisconnectedUser` 逻辑对齐，避免重复累加

**涉及**：`server/src/gameState.ts` · `server/src/fishingStateMachine.ts`

---

### 任务 2 — 每秒广播覆盖全阶段

**Spec**：主 Spec §3.6

修改 `server/src/index.ts` 中 1s 广播的 `fishingUsers` 过滤条件，覆盖：

`baiting` · `casting` · `waiting` · `hooked` · `resolving` · `stopping`

广播时 `todayFishingMs` / `sessionFishingMs` 均用服务端实时计算，禁止客户端自行 `+1000` 累加（见任务 4）。

---

### 任务 3 — 统一时间格式化

**Spec**：主 Spec §3.3

1. 新增或改造 `formatFishingDuration(ms)`（可放在 `mobile/lib/config.ts` 或 `shared/` 若底栏与服务端 debug 也需复用）
2. 规则：
   - `< 1 分钟` → `45秒`
   - `< 1 小时` → `12分34秒`
   - `≥ 1 小时` → `2小时15分30秒`（**始终含秒**）
   - 最长边界：`23小时59分59秒`
3. 替换钓鱼相关展示：
   - `PondCharacter` 头顶 badge
   - `pond/[id].tsx` 底栏「今日剩余」（建议同函数）
   - `hooked` 倒计时文案
4. 评估是否替换 `formatDuration` 的其他调用点（生态恢复倒计时等）；若语义不同可保留原函数，但钓鱼路径必须用新函数

---

### 任务 4 — 角色头顶 UI（客户端）

**Spec**：主 Spec §3.4、§3.5

**文件**：`mobile/components/PondCharacter.tsx`

1. **禁止**再绑定 `user.todayFishingMs` 到头顶 badge
2. 非 `hooked` 阶段：`{阶段标签} · {formatFishingDuration(sessionFishingMs)}`
3. `hooked` 阶段：`上钩 · 预计收杆 {formatFishingDuration(hookRemainingMs)}`
   - `hookRemainingMs = max(0, phaseEndsAt - now)`，每秒刷新（已有 `setInterval`）
   - 以服务端 `phaseEndsAt` 为准，不本地累减
4. **布局**：
   - badge `minWidth` ≥ 148px，或气泡居中、宽度 `alignSelf: 'center'` 脱离 72px 角色宽限制
   - `fishingText` 字号 ≥ 10px
   - 禁止 `numberOfLines={1}` 截断数字
5. `seated` / `idle` 时不显示会话 badge（与现有一致）

**同塘他人可见**：依赖服务端广播的 `sessionFishingMs`，客户端不做本地推算。

---

### 任务 5 — Demo 模式对齐

**Spec**：主 Spec §3.2

- 改为：维护 `fishingStartedAt`，展示会话时长；今日剩余仍可用累计逻辑或简化 mock
- 开始/停止钓鱼时正确设置/清空 `fishingStartedAt`
