## 1. 背景与目标

`FEAT-SPOT-02` 用稳定哈希为 420 个钓位生成 **4–6 个跨类标签**，保证表结构完整、线索可过滤，但**未**对照 Unity 正交 Tile 岸线、进水方向、深浅与岸貌做策划审校。

本票目标：在 xlsx **`pond_spot_tags`** 中，按**实际地形**逐塘逐点替换/增删标签，使坐席线索与环境视觉一致。

### 非目标

- 修改 22 个 `tagId` 词表（见 [钓位标签与线索库-v2.md](./钓位标签与线索库-v2.md) §2）
- 改咬钩 / 出鱼 / 生态公式
- 新增程序化自动标注（可保留脚本作 diff 对照，权威以 xlsx 为准）

### 2.1 微调原则

1. **必保留**：每点 ≥1 `terrain` 类 + ≥1 `depth` 类标签。
2. **总数**：每点 **4–6** 个标签，逗号分隔，与 `spot_tag_defs.tagId` 对齐。
3. **一致性**：同一塘相邻岸位标签应平滑过渡（避免相邻点标签完全无关）。
4. **塘型偏置**（软约束）：
   - 水库/野外：略增 `structure` / `depth_deep` / `inlet_eddy`
   - 练杆/高级坑塘：略增 `shore_hard` / `depth_mid`
   - 湖荡类：略增 `weed_grass` / `shore_reed`

### 2.2 交付物

- 根目录 `钓鱼玩法固定数值表.xlsx` → sheet **`pond_spot_tags`** 全表审校
- `npm run game-data:export` 后 JSON 同步 Unity / shared
- 可选：`docs/planning/reports/spot-tags-audit-<date>.md` 记录各塘变更摘要
