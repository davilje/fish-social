## 1. 背景与目标

STEAM-DESKTOP-10 已完成可配置 `serverBaseUrl`。原计划 **方案 A：本机 + 公网端口映射** 已因 CGNAT **不可行**，本规格作废其外网目标。

### 1.1 目标

- 文档化本机公网映射逐步操作（公网 IP、防火墙、路由器转发、4G 探活）。
- 设置页可编辑并保存 `server.json`，并一键测试 `/health`。
- 提供本机检查脚本，降低排障成本。

### 1.2 非目标

- 不自动配置路由器（无 UPnP 强制依赖）。
- 不租云、不实现 HTTPS。
- 不解决运营商大 NAT（无公网 IP 时引导改云主机）。
- 不改变 Steam Ticket / JWT 协议。

## 5. 方案 A 运维手册（本机公网映射）

```text
1. 本机保持服务运行（dev.bat 或 npm run server）
2. 确认 http://localhost:3001/health → 200
3. ipconfig 记录局域网 IP（如 192.168.1.7）
4. Windows 防火墙入站放行 TCP 3001
5. 路由器：外网 TCP 3001 → 局域网IP:3001
6. 确认 WAN 为公网 IP（非 10.x / 100.64.x / 运营商大 NAT）
7. 手机 4G（非家里 WiFi）访问 http://公网IP:3001/health → 200
8. 外地玩家 EXE 旁 server.json：
   { "serverBaseUrl": "http://公网IP:3001" }
9. 玩家 Steam 已登录且拥有 App 2713340
10. 玩家 Steam 登录进游戏
```

失败对照：

| 现象 | 排查 |
|------|------|
| 本机 health 不通 | 先修服务进程 / `server:clean` |
| 局域网通、4G 不通 | 端口转发、公网 IP、运营商 NAT |
| 4G health 通、游戏登录失败 | `server.json` 地址、Steam App 权限、`.env` Steam 四项 |
