## 1. 目标

1. **全塘全点位**具备多类环境标签（表驱动，v0 脚本种子 + 后续人工微调）。
2. **线索文案**严格按标签过滤；每条线索绑定一个 `spotTag`。
3. **habitat / activity** 两类文案遵守「只描述环境、不暗示鱼种/鱼情结论」。
4. 为后续**鱼群迁移 / 钓位鱼量**接入预留 `activitySignal` 档位。
5. **上鱼经验**按体长乘子：`(sizeM/SIZE_REF)^0.85`（时长仍只发塘 XP，不发玩家 XP）。

### 非目标（本票）

- 咬钩/出鱼受标签影响
- 实时按 `activitySignal` 过滤（v2 生态接入后再开）
- 点位旁常驻 UI

## 2. 标签体系（22 种 × 6 大类）

## 4. 线索库 `spot_clue_texts`

### 4.1 字段

| 字段 | 说明 |
|------|------|
| `clueId` | 唯一 ID |
| `clueType` | `habitat` \| `activity` |
| `clueText` | 展示文案 |
| `weight` | 加权随机，默认 1 |
| `minPlayerLevel` / `minPondLevel` | 解锁门槛 |
| `pondCategory` | 可选塘类过滤；空=全塘 |
| `spotTag` | **必填**，匹配点位标签之一 |
| `activitySignal` | 见 §4.3 |
| `enabled` | 是否启用 |

~~`speciesHint`~~：**剔除**（避免策划误写鱼种导向）。

### 4.2 文案禁区

**habitat** — 只描述物理环境：

- ❌ 「会有 xx 鱼」「xx 鱼爱…」「宜钓」「开口」「主场」「觅食」
- ✅ 「草缘与亮水分界清晰」「水色泥浆样，近岸看不清底」

**activity** — 只描述可观察征象（泡、纹、色、草、风、气味、声响）：

- ❌ 「鱼星」「鱼花」「白费力气」「说明有鱼」「开口差」「xx 鱼出没」「进窝」
- ✅ 「草缘处不时冒出细泡」「水面长时间无泡、无漂物扰动」

每种 tag **至少**：habitat×3、activity(active)×4、activity(inactive)×2、disturbed×1。

### 4.3 `activitySignal`（鱼情信号档）

用于 **v2** 将钓位实时生态映射到可抽线索池；**v1 坐席随机时不按此过滤**。

| 值 | 含义 | 未来匹配（示意） |
|----|------|------------------|
| `habitat` | habitat 专用，不参与鱼情匹配 | — |
| `active_high` | 强活性环境征象 | 点位鱼量高 + 近期有咬钩 |
| `active_mid` | 中等活性 | 鱼量中、偶有动静 |
| `active_low` | 弱活性 | 鱼量偏低 |
| `inactive` | 沉寂无征象 | 鱼量很低 / 长时间无事件 |
| `disturbed` | 受扰动 | 刚被惊扰、迁移中 |

**v2 抽选算法（预留）**：

1. 服务端/生态层计算钓位 `computedTier`（上表之一）。
2. activity 线索优先抽 `activitySignal === computedTier`；无匹配时降级相邻档。
3. habitat 仍 50% 概率与 activity 混合。

## 5. 坐席抽选（v1 定稿）

1. 读 `pond_spot_tags` → 点位 tag 集合。
2. 过滤 `spot_clue_texts`：`enabled` + 等级 + `pondCategory` + **`spotTag ∈ 点位 tags`**。
3. 50% 倾向 `habitat` / 50% `activity`（该类型池非空时）。
4. 同会话内不连抽同一 `clueId`。
5. **忽略** `activitySignal`（直到生态 v2）。

## 6. 体长 → 钓鱼经验

```
sizeMul = (sizeM / SIZE_REF[quality]) ^ XP_SIZE_EXP   // XP_SIZE_EXP = 0.85
playerXp = max(1, floor(fish_xp.playerXp × sizeMul))
pondXp   = max(1, floor(fish_xp.pondXp   × sizeMul))
```

- `fish_xp` 表结构不变（种×品质基础值）。
- **时长 XP** 仍只发塘熟练度，`playerXp=0`（不变）。

常数：`fishing_formula_constants.XP_SIZE_EXP = 0.85`。
