## 1. 背景与目标

### 1.1 背景

人多时每人脚下状态+时长徽章拥挤；上钩主要靠角色变色不够清晰；分享等仍用系统 Alert；排行榜排除 bot 且空榜 UI 塌缩；在线钓友横滑不利于竖屏；动态评论区打不开/看不见。

### 1.2 目标

1. 默认只显示**自己**的状态信息；他人悬停（Web）/长按或点按（移动）才出气泡。  
2. 上钩过程用**环形倒计时**，不用整身变色作为主反馈。  
3. 获鱼 / 分享 / 上钩相关提示统一**自定义弹窗**。  
4. 排行榜**允许 bot 上榜**；始终展示领奖台前三 + 可滚前 50 名（可空位）。  
5. 鱼塘在线钓友改为**纵向滚动列表**，并单独考虑竖屏布局。  
6. **修复**动态评论区看不到评论。

### 1.3 非目标

- 不改咬钩/脱钩服务端公式与时长上限  
- 不重做整页社交墙信息架构  
- 不恢复稀有鱼榜 / 钓场榜（仍仅日/周，见 FEAT-SOC-03b）  
- Admin / 运营平台 UI 不在本需求范围

## 3. 交互与 UI

### 3.1 A/B — 状态展示

**自己（`userId === myUserId`）**

- 始终可见：精简状态区（icon ± 短时长），不挡操作按钮。  
- 相位映射到仅两档视觉：  
  - **上钩**：`hooked`（及若需含收杆动画的 `resolving` 且 outcome=catch 的短窗——实现时以「上钩中」为准，收杆中可仍用上钩 icon 或环形进度）  
  - **钓鱼中**：`waiting` / `baiting` / `casting` / 其它活跃钓鱼相位（除上钩）  
- `idle` / `seated` / 未在钓：**不显示**状态条。

**他人**

- **默认完全隐藏**脚下状态徽章与时长。  
- **Web**：指针在角色热区停留 ≥300ms → 气泡（icon + 时长）；移出消失。  
- **原生/触屏**：点按角色或长按 → 同款气泡；点空白或超时关闭。  
- 气泡内容：仅两档 icon + 时长文案（上钩显示剩余收杆倒计时优先；钓鱼中显示本局 `session` 时长）。

### 3.2 C — 抛竿飘字

- 进入 `casting`（或服务端等价抛竿瞬间）对塘内可见：与咬钩相同的 `FishingFloatText` 动效（上浮 + 渐隐）。  
- 文案示例：「抛竿！」或配置化短句；**不**占用上钩/获鱼弹窗。  
- 实现：优先扩展 `fishing_float_text` 的 kind=`cast`（服务端广播，与 hook 一致）；若仅客户端可可靠感知相位，可本端渲染但须保证**同塘他人也能看见**（故推荐服务端广播）。

### 3.3 D — 上钩环形倒计时

- `hooked`（及展示收杆进度时）：角色旁/脚下用 **圆环进度**，按 `phaseEndsAt` 从满到空（或空到满，全端统一一种）。  
- **不再**以整角色变色作为上钩主信号（可保留极弱高光，但不能替代圆环）。  
- 自己与他人：他人默认仍不常驻状态条，但**上钩圆环应对同塘可见**（否则他人看不到谁上钩）——例外约定：  
  - **他人上钩时显示圆环（可无文字）**；时长文字仍仅自己常驻或悬停气泡。  
  - 若圆环与「默认隐藏他人状态」冲突，以「圆环可见、文字/徽章隐藏」为准。

### 3.4 E — 统一弹窗

| 场景 | 现状 | 目标 |
|------|------|------|
| 上钩待确认 / 获鱼结果 | `CatchFishModal` | 保留并作为统一视觉母版（圆角卡片、主按钮、自动关闭可选） |
| 分享成功/失败 | 系统 `Alert` / `window.alert` | 同一套 Modal（标题+正文+按钮） |
| 其它钓鱼相关强提示（若仍 Alert） | 饵用尽等 | 同套 Modal；非钓鱼杂项可二期 |

母版命名建议：`AppNoticeModal` 或扩展 `CatchFishModal` 变体 `kind: catch | share | notice`。Web/原生观感一致，**禁止**网页原生 `alert`/`confirm` 用于上述场景。

### 3.5 F — 排行榜

**后端**

- `leaderboard.ts` 去掉（或改为可选）`player_id NOT LIKE 'bot-%'` 过滤，使 bot 可按同一口径上榜。  
- 日/周榜仍最大鱼口径（FEAT-SOC-03b）。

**前端 `leaderboard.tsx`**

- **始终**渲染领奖台三席（1/2/3）：无数据时显示空位占位（虚位/「虚位以待」）。  
- **始终**渲染「第 4～50 名」滚动区：固定约 47 行槽位（或列表高度可滚），不足用空行占位；超过 50 截断到 50。  
- 列表可上下滑动；空榜时领奖台+空列表仍占位，不塌成空白页。  
- Bot 昵称可带小标记（可选 P1：「机」徽），非必须。

### 3.6 G — 在线钓友纵向列表

- `PondSocialPanel` 在线区：由横向 chips 改为 **纵向 ScrollView/FlatList**。  
- 行内容：头像、昵称；（可选）是否在钓小点，**不**复制场景状态条全文。  
- **桌面/横屏**：可维持场景左 + 侧栏右。  
- **移动端竖屏**：重新布局——建议场景占上半可交互区，侧栏改为场景下方**固定最大高度**的可滚列表（或底部抽屉），避免把场景挤没；聊天与在线可 Tab 切换或上下分区，需保证竖屏可完整操作钓鱼主按钮。

### 3.7 H — 动态评论区修复

- 现象：评论区展开后看不到评论。  
- 修复范围：`PostCard` 评论面板高度/overflow/z-index/条件渲染/加载错误吞掉；确认 `getComments` 成功后列表可见；展开时列表可滚。  
- 验收：有评论的动态展开后可见历史评论；新发评论立即出现在列表。
