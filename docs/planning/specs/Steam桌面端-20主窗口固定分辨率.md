## 1. 目标

桌面客户端的系统窗口默认以 **1920×1080** 客户区打开。用户只能在设置面板里改成下面几种固定分辨率，不能靠拖拽边框得到任意尺寸。

| 分辨率 | 说明 |
|--------|------|
| 1280×720 | 可选 |
| 1600×900 | 可选 |
| 1920×1080 | 默认 |
| 2560×1440 | 可选 |

四种都是 16:9，和主界面内容区 1672×941 的比例一致。

## 2. 非目标

- 不改 Overlay 画布。塘内布局保持 `960×560`、`ConstantPixelSize`。
- 不改登录卡片尺寸。`LoginRoot` 仍是居中的 480×320。
- 不改主界面内容参考分辨率 1672×941，不重做背景双层。
- 不改 `mobile/`、`server/`、`shared/`。
- 保留现有「无边框」「全屏」。无边框铺工作区，全屏铺整屏，不进入上面的分辨率列表。

## 3. 行为

1. 首次启动、以及旧的自由拉伸存档（`fishsocial.desktop.window.v2`）都不再沿用。新键 `fishsocial.desktop.window.v3` 默认窗口模式、1920×1080。
2. 登录和进入主壳使用同一组已保存的固定分辨率。登录只是窗口里居中的小卡片，不再单独开 480×320 的系统窗口。
3. 登录画布参考分辨率改为 1920×1080、`MatchWidthOrHeight`，避免 3:2 参考把卡片拉变形。进入主壳后仍回到 1672×941、`Expand`。
4. 设置页把原来的「普通窗口 1280×720」换成四个分辨率按钮，点哪一个就把窗口切到该客户区并写入 v3。
5. 已保存尺寸若不在列表中，回到 1920×1080。拖拽产生的 `Screen.width/height` 不再写回宽高，只保存窗口位置。
6. 普通窗口去掉可调边框和最大化按钮。工程 `resizableWindow` 设为 0。
7. `SetWindowPos` 的宽高按标题栏换算成外框，使 Unity 客户区等于所选分辨率。

## 4. 验收

- [ ] 冷启动（无 v3 存档）登录窗口客户区为 1920×1080，登录卡片仍约为 480×320 并居中。
- [ ] 进入主壳后窗口仍是 1920×1080，除非用户已在设置里选过别的档。
- [ ] 设置中可切到 1280×720、1600×900、1920×1080、2560×1440，且不能拖出这四档之外的尺寸。
- [ ] 无边框、全屏仍可切换，回到普通窗口时恢复上次选中的固定分辨率。
- [ ] Overlay 塘内画布仍是 960×560。
