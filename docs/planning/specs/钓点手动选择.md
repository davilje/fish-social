## 1. 背景与目标

### 1.1 背景

当前点击底栏 **「开始钓鱼」** 时，客户端自动挑选空闲点（或 bot 点）并 `start_fishing({ spotId })`：服务端一次完成 **占点 + 进入钓鱼状态机**。玩家无法主动选择想坐的钓位。

### 1.2 目标

1. **手动选点**：玩家在鱼塘场景中点击目标钓点完成落座（`seated`），角色出现在该点。  
2. **开始钓鱼不再自动选点**：底栏「开始钓鱼」仅在**已落座**时启动状态机；未选点时禁用并提示。  
3. **换座**：未在钓时可点击其他可用点换座；钓鱼中不可换座（须先收竿）。

### 1.3 非目标

- 不改咬钩公式、日额度、状态机相位时长  
- 不重做整张鱼塘 Tilemap / 相机  
- 不强制改 bot 自动选点逻辑（bot 可继续自动占点）  
- 不做「选点预览热力 / 点位属性面板」（可后续）

---

## 2. 用户与场景

| 角色 | 场景 | 期望 |
|------|------|------|
| 玩家 | 进塘后未选点 | 可逛场景；「开始钓鱼」不可用，文案提示选点 |
| 玩家 | 点击空闲钓点 | 落座成功，自己出现在该点；仍未开钓 |
| 玩家 | 点击仅 bot 占用的点 | 允许踢 bot 占点（沿用现网 `startFishing` 占点规则） |
| 玩家 | 已落座后点「开始钓鱼」 | 在**当前 spotId** 进入 baiting…，不再另选点 |
| 玩家 | 钓鱼中点其他点 | 无效或轻提示「请先收起鱼竿」 |
| 玩家 | 收竿后 | 仍坐在原点（`seated`）；可换点或再开钓 |

## 3. 功能范围

| # | 功能点 | 优先级 | 说明 |
|---|--------|--------|------|
| A | 场景可点钓位 | P0 | 空闲 / 可踢 bot 的点可点；真人占用不可点 |
| B | 占点与开钓拆分 | P0 | 占点 → `seated`；开钓 → 已有 `spotId` 时 `beginFishingSequence` |
| C | 底栏按钮语义 | P0 | 未落座：禁用「开始钓鱼」+ 提示；已落座未钓：可开钓；在钓：收竿 |
| D | 选中态反馈 | P0 | 落座成功后角色位置更新；可选高亮当前点（轻量） |
| E | 失败提示 | P0 | 点满 / 被占 / 未选点开钓 → 现有或统一 notice |

### 3.1 交互定案

```
进塘(idle, spotId=null)
  → 点可用钓点 → take_spot → seated + spotId
  → 「开始钓鱼」→ beginFishing（禁止客户端自动 pick freeSpot）
  → 「收起鱼竿」→ stopping → seated（保留 spotId）
  → 点其他可用点（仅非 fishing 相位）→ 换座
```

### 3.2 服务端口径（推荐）

现网 `start_fishing` = `startFishing(占点)` + `beginFishingSequence`。本需求应拆成：

| 事件 | 行为 |
|------|------|
| **`take_spot`**（新，或复用等价 API） | 仅占点 / 换座 → `seated`；**不**进状态机；可踢 bot |
| **`start_fishing`** | 要求已有 `spotId` 且非在钓；**只** `beginFishingSequence`；若带 `spotId` 可与当前一致做校验，**禁止**服务端静默改点 |

兼容：旧客户端若仍一次传 `spotId` 开钓，可短期保留「未落座则先占再钓」兼容路径，但 **本产品新客户端禁止自动选点**；验收以新流程为准。

### 3.3 UI

- `PondScene`：钓点热区可点（未坐人 / bot）；占用真人点不触发占点。  
- 底栏：未 `spotId` 时按钮文案可用「请先选钓点」或保持「开始钓鱼」但 `disabled` + notice。  
- 删除 / 停用 `[id].tsx` 中 `freeSpot ?? botSpot` 自动挑选逻辑。

## 5. 验收标准

- [x] 点击「开始钓鱼」**不会**在未选点时自动落到某个空位
- [x] 点击空闲钓点后，自己角色落在该点，相位为 `seated`（或等价未开钓占位）
- [x] 已落座后「开始钓鱼」在该点进入钓鱼流程
- [x] 可踢 bot 占点；不可抢真人点，并有明确错误提示
- [x] 钓鱼中无法换座；收竿后可换座或再开钓
- [x] 收竿后仍坐在原点，不强制清 `spotId`（与现 stopping→seated 一致）
- [x] Web / 移动端均可点选（点按选点、拖拽平移）
- [x] 演示模式行为与线上一致（先选点再开钓）
