## 1. 背景与目标

### 1.1 背景

桌面端页面已经对齐三栏布局，但点击、切页和地图没有反馈。用户确认了「猫咪钓鱼手账」动效方案。

### 1.2 目标

- 按钮按下回弹，不可用时左右轻摇。
- 底部导航用浮漂跳到当前页签，落下时有水波。
- 切页时旧页淡出、新页从右侧滑入。
- 顶栏金币数字滚动，提示从右侧滑入。
- 地图浮标轻微漂动，点选时出水波。
- 主界面角落有钓鱼猫。
- 设置「托盘与其他」里可以打开「减少动效」，只保留短淡入。

### 1.3 非目标

- 不改 Overlay 960×560 画布。
- 不改 `mobile/`、`server/`、`shared/`。
- 本期不引入 DOTween 编辑器包。动效走 `CozyMotion`，时长与方案第 4 节一致，避免编辑器 Utility Panel 才能初始化的依赖。
- 胶带换皮、收获全套分镜、音效留在后续，不挡这一版手感。

## 2. 验收标准

- [ ] 可点的按钮按下会压扁再回弹；不可点的按钮左右轻摇。
- [ ] 切换底部页签时，浮漂跳到新页签上方并出现一圈水波。
- [ ] 页面切换约 0.3 秒内完成，旧页向左淡出，新页从右侧进入。
- [ ] 金币变化时数字滚动，而不是瞬间跳字。
- [ ] 探索世界里未锁定的浮标上下轻漂；点选出现水波。
- [ ] 主界面右下角有小猫。
- [ ] 「减少动效」打开后，不再循环漂动，切页改为直接切换。
- [ ] 切页和点按钮时 `Player.log` 不出现新的 `frame_stall`。
