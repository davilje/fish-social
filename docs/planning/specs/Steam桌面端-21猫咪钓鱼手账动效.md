## 1. 背景与目标

### 1.1 背景

桌面端页面已经对齐三栏布局，但点击、切页和地图没有反馈。用户确认了「猫咪钓鱼手账」动效方案。

### 1.2 目标

- 按钮按下回弹，不可用时左右轻摇。
- 底部导航用浮漂跳到当前页签，落下时有水波。
- 切页时旧页淡出、新页从右侧滑入。
- 顶栏金币数字滚动，提示从右侧滑入。
- 地图浮标轻微漂动，点选时出水波。
- 主界面角落有钓鱼猫。
- 设置「托盘与其他」里可以打开「减少动效」，只保留短淡入。

### 1.3 非目标

- 不改 Overlay 960×560 画布。
- 原动效规格不改 `mobile/`、`server/`、`shared/`；后续用户授权全 UI 替换，本轮为“我的动态”和鱼获附言扩展了 server API，详见实施记录。
- 本期不引入 DOTween 编辑器包。动效走 `CozyMotion`，时长与方案第 4 节一致，避免编辑器 Utility Panel 才能初始化的依赖。
- 本轮全 UI 替换已补胶带、普通/新鱼收获序列；音效不属于本轮新增内容。

## 2. 验收标准

- [x] 可点的按钮按下会压扁再回弹；不可点的按钮左右轻摇。
- [x] 切换底部页签时，浮漂跳到新页签上方并出现一圈水波。
- [x] 页面切换约 0.3 秒内完成，旧页向左淡出，新页从右侧进入。
- [x] 金币变化时数字滚动，而不是瞬间跳字。
- [x] 探索世界里仅选中且可进入的浮标轻漂；点选出现水波，同屏最多一个持续循环。
- [x] 主界面右下角有小猫。
- [x] 「减少动效」打开后，不再循环漂动或位移/缩放/旋转，切页采用短淡变。
- [ ] Windows 实机：切页和点按钮时 `Player.log` 不出现新的 `frame_stall`。该条不由 EditMode 测试代替。
