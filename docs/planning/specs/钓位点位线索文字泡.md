## 1. 目标

玩家达到解锁条件后，在 Overlay 各钓位旁显示**环境线索文字泡**（表现对齐角色聊天气泡），辅助找点；不暴露服务端隐藏概率表。

### 非目标

- 独立夜钓/时段系统（原 15 条 #9/#15 完整版）
- 主窗口完整观察 UI 面板
- 最终文案/点位美术锁定（占位即可）

## 2. 规则

- 数据：`spot_clues`（`pondId, spotId, minPlayerLevel, minPondLevel, clueText`）。
- 同时满足玩家等级与**当前塘**熟练度门槛才显示；否则不显示或「？？？」（二选一，默认不显示）。
- 文案倾向：「水很清澈 / 水草很多 / 有气泡往上冒 / 树荫茂密」等。
- 仅当前玩家可见（不广播给他人），避免刷屏。

## 3. 验收

- [ ] 未达标无线索泡；达标后对应钓位出现文案泡
- [ ] 样式与 Overlay 聊天气泡一致或可复用组件
- [ ] 换塘/升级后刷新正确
- [ ] 不泄露 bite/escape 原始数值

## 4. 预估代码

- Overlay 点位锚点 + 气泡
- Unity 根据进度与表过滤下发线索列表（或本地读表 + 服务端校验等级）
