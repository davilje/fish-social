## 1. 目标

玩家达到解锁门槛后，在 **坐到某钓位** 时，以与公屏聊天**相同的文字泡样式**，向本玩家展示一条（或短序列）钓鱼经验提示，帮助观察环境与鱼情；**不**暴露 bite/escape 等隐藏数值。

### 非目标

- 独立夜钓/完整时段模拟（原 15 条 #9/#15）
- 主窗口观察面板
- 点位旁常驻锚点文案（**本修订废弃**旧「钓位旁常显」表现）
- 文案与真实生态 RNG 强绑定（可弱相关，但禁止泄露表内概率）

---

## 2. 表现与触发（修订）

| 项 | 规则 |
|----|------|
| 样式 | **复用 Overlay 聊天气泡**（09C：气泡底、字号、出现/淡出节奏可一致）；发送者可显示为「观察」/「经验」等系统昵称，**不进公屏历史、不广播他人** |
| 何时显示 | 玩家 **落座到某钓位**（`seated` / 选点完成）后触发；离席或换点则收起当前泡，换点可再抽一条 |
| 何时不显示 | 未达解锁门槛；未坐席；引导教学关可不启用 |
| 旧行为 | ~~各钓位旁常驻环境字~~ → **删除**；改为坐席后聊天泡 |

解锁门槛（不变精神）：同时满足 `minPlayerLevel` 与当前塘 `minPondLevel`（熟练度）；未达标默认不显示。

---

## 3. 线索机制（修订：表驱动 + 随机）

### 3.1 原则

1. **所有提示文案**收入固定数值表（见 §4），不硬编码在客户端零散字符串。
2. **每个钓点不绑定唯一固定文案**；坐席时从**可抽池**中按权重 **随机** 抽 1 条展示。
3. 可选：同一次坐席只显示 1 条；换点或再次落座可重抽（避免同点连续 3 次同文案：简单冷却/去重即可）。
4. 池可按塘类型、点位标签过滤（见字段）；无标签时用全局池。

### 3.2 文案类型（必分两类）

| `clueType` | 含义 | 玩家读感 |
|------------|------|----------|
| `habitat` | **各类鱼喜欢的环境**经验总结 | 「这种地形/水色/遮荫，某类鱼爱待」 |
| `activity` | **是否有鱼情**的环境经验总结 | 「水面动静、鱼星、水草痕迹 → 像有/没有开口」 |

两类在解锁后都可进入随机池；抽选时建议按权重混合（默认各 50%，表可配 `weight`）。

### 3.3 表结构（替换旧 `spot_clues` 一行一固定文案）

**A. `spot_clue_texts`（文案库，权威）**

| 字段 | 说明 |
|------|------|
| `clueId` | 唯一 ID |
| `clueType` | `habitat` \| `activity` |
| `clueText` | 展示文案 |
| `weight` | 相对权重，默认 1 |
| `minPlayerLevel` | 最低玩家等级，默认 0 |
| `minPondLevel` | 最低当前塘熟练度，默认 0 |
| `pondCategory` | 可选过滤：`advanced`/`wilderness`/…；空=全塘 |
| `spotTag` | **已废弃**（保留列不影响）；运行时**不**按点位标签过滤 |
| `speciesHint` | 可选口味标签（如 `crucian`/`carp`/`grass`），仅供策划备注，**UI 可不显示种名 ID** |
| `enabled` | 是否启用 |

~~**B. `spot_tags`**~~：**已剔除**。全钓点线索统一按 `weight` 加权随机（仍可按等级 / `pondCategory` 过滤）。

坐席抽选算法（定稿）：

1. 过滤 `enabled` + 等级/塘熟练度 + `pondCategory`（**忽略 spotTag**）。
2. 按 `weight` 加权随机抽 1 条；展示 `clueText`。
3. 同 `clueId` 在同一坐席会话内不连抽（可选）。

## 4. 文案设计初稿（入表）

> 依据常见淡水野钓/坑塘观察经验（水色与清浊、鱼星形态、水草残缺、树荫与进水口/洄湾、鲫草鲤习性差异等）整理的**游戏化短句**，非科学论文；可继续增删。实现时以表为准，下表为 v0 种子。

### 4.1 `habitat` — 鱼喜欢的环境

|--------|----------|--------------|-------------|
