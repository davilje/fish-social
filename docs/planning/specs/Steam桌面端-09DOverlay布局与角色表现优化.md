## 1. 背景与目标

### 1.1 背景

当前 Overlay（`960×480`）存在体验问题：

1. 宠物基准 `128×128` 过大，同塘多人时遮挡严重。
2. 左上有状态/鱼塘/钓位，右上有「打开主界面」，底部有横向钓鱼操作栏，**控件分散**。
3. 09B 初稿沿 Web FEAT-UI-1「他人默认隐藏状态、悬停才出气泡」——与 Steam 挂机场景产品方向不一致；用户要求 **状态与上钩圆环默认可见**，**悬停只补充钓鱼时长**。
4. Bot 昵称带「· 机」后缀，桌面 Overlay 不需要该标记。
5. 纵轴空间不足，底部栏占用可玩区域。

### 1.2 目标

| # | 目标 |
|---|------|
| G1 | **每一位塘内用户**默认在头像/宠物**上方**显示昵称 |
| G2 | 宠物/形象渲染尺寸为现行基准的 **50%**（`128→64`） |
| G3 | **默认显示**钓鱼状态 icon/文案；**上钩时默认显示圆环进度条**（对齐 FEAT-UI-1 D） |
| G4 | **悬停**（≥300ms）**仅**显示本局钓鱼时长/收杆剩余时长文案，不重复状态 |
| G5 | Overlay **加高纵轴**；底部横向栏移除，与「打开主界面」合并为**左上角纵向可收纳菜单**，位于状态/鱼塘/钓位信息**之上** |
| G6 | Bot 昵称**不**追加「·机」 |

### 1.3 非目标

- 不改服务端钓鱼公式、PERF-03b tick 协议
- 不在本需求做 09A 玩家右键菜单、09C 聊天气泡（可预留布局空间）
- 不强制在本需求完成 ART-02 布局 JSON 导出（但画布尺寸变更须写入 ART-02 变更记录）
- 不改主窗口 `1280×720` 布局

## 2. 布局规格

### 2.1 窗口尺寸

| 项 | 现行 | 目标 |
|----|------|------|
| 宽度 | 960 | **960**（不变） |
| 高度 | 480 | **560**（+80px 纵轴；实现可微调 ±16px，须更新 Unity 启动 Overlay 参数与 WPF `MainWindow`） |

透明窗口总高度增加；鱼塘场景 Canvas 随窗口等高缩放，**场景可绘制区**应大于旧版「480 减底部 62px 栏」的有效高度。

### 2.2 左上角信息架构（自上而下）

```text
┌─ Overlay 960×560 ─────────────────────────────┐
│ [≡]  ← 纵向收纳菜单（默认收起为一图标/窄条）      │
│     展开后纵向：                                  │
│       · 打开主界面                                │
│       · 选择钓位 / 开始 / 收杆 / 领取 / 离席 / 退出鱼塘 │
│       · （可选）快捷入口：世界地图、好友、背包…      │
│ ┌ 状态胶囊 ─────────┐                            │
│ │ 连接/phase        │                            │
│ │ 鱼塘名            │                            │
│ │ 当前钓位          │                            │
│ └──────────────────┘                            │
│                                                 │
│           鱼塘场景（全宽，无底部横栏）              │
│     昵称                                         │
│     [64×64 宠物]  + 状态icon + 上钩圆环           │
│                                                 │
└─────────────────────────────────────────────────┘
```

| 规则 | 约定 |
|------|------|
| 收纳菜单 | 默认**收起**（仅 ≡ 或「菜单」按钮）；点击展开/再点收起；展开时 **Z-order 最高**，不挡场景拖动空白区 |
| 原底部 `ControlBar` | **移除**横向 DockPanel；按钮迁入左上收纳菜单 |
| 原右上「打开主界面」 | **移除**独立按钮；作为收纳菜单首项 |
| 状态胶囊 | 仍在左上，位于收纳菜单**下方**（菜单展开时向下推移或覆盖策略二选一，须不永久遮挡钓位） |
| 场景右键产品菜单 | 可保留（空白/背景右键）；与左上收纳菜单项语义允许重复 |

### 2.3 角色表现（全体塘内用户，含自己与他人）

```text
        [昵称]           ← 默认始终可见，头像上方
    [ 状态 icon ]        ← 默认可见（钓鱼中/上钩两档，对齐 FEAT-UI-1 B）
    ( ○ 圆环进度 )       ← hooked 相位默认可见；无文字亦可
    [ 64×64 宠物 ]
    [ 状态短文案 ]       ← 可选：「钓鱼」「咬钩」；与 icon 二选一或并存，以不拥挤为准
```

| 项 | 规则 |
|----|------|
| 昵称 | 所有 `users[]` 与 own 均显示；单行省略；**Bot 不加「·机」** |
| 宠物尺寸 | `BodySize` / `CatSize` = **64**（原 128 的 50%） |
| 默认状态 | `idle`/`seated`/未钓：**不显示** icon/圆环/短文案（与 FEAT-UI-1 一致） |
| 钓鱼中 | 默认显示「钓鱼中」icon（或等价短文案） |
| 上钩 | 默认显示圆环 + 可选上钩 icon；圆环进度 = `(hookDeadlineMs - now) / total` |
| 悬停 ≥300ms | **仅** Tooltip：`本局 12:34` 或 `收杆 0:08`；**不**在 Tooltip 重复 icon/圆环 |
| 移出 | Tooltip 消失 |

## 3. 技术影响

### 3.1 IPC（延续 09B）

`NativeOverlayActorDto` / own 字段（09B 已规划，09D **必须落地**）：

| 字段 | 用途 |
|------|------|
| `fishingPhase` | 控制 icon/圆环显隐 |
| `sessionFishingMs` | 悬停 Tooltip「本局时长」 |
| `hookDeadlineMs` | 圆环进度 + 悬停「收杆剩余」 |

### 3.2 涉及文件

- `desktop-overlay/MainWindow.xaml(.cs)` — 尺寸 960×560、左上收纳菜单、移除底栏/右上按钮
- `desktop-overlay/OverlayPetActor.cs` — 64px、昵称、默认状态/圆环、悬停仅时长、去 Bot 后缀
- `desktop-overlay/PondScenePresenter.cs` — `CatSize=64`、布局常量
- `fish-social-unity/.../NativeOverlayProcessController.cs` — 启动 Overlay 窗口尺寸
- `fish-social-unity/.../NativeOverlayStateDto.cs`、`OverlayPondStateBuilder.cs`
- `docs/planning/specs/Steam桌面Overlay场景布局管线.md` — 画布高度说明（ART-02 后续导出）

### 3.3 08G 关系

08G 验收时底部横栏为 P0；09D ** supersede 交互形态**：操作项迁移至左上收纳菜单，功能语义不变（仍发相同 IPC 命令）。08G spec **不 retro 改已实现**，以 09D 为 Overlay 布局新基准。

## 4. 验收标准

- [x] Overlay 窗口为 **960×560**（或 spec 写明的高度，Unity/WPF 一致）
- [x] 塘内**每位**用户昵称默认显示在宠物**上方**
- [x] 宠物/占位渲染基准 **64×64**（相对原 128 为 50%）
- [x] 钓鱼中/上钩默认可见状态表现；上钩有**圆环进度条**
- [x] 悬停 ≥300ms **仅**显示时长/收杆剩余；移出消失
- [x] 底部横向操作栏与右上「打开主界面」已移除；功能在**左上纵向收纳菜单**且位于状态胶囊**上方**
- [x] Bot 昵称无「·机」
- [x] 08G 钓鱼操作（选位/开钓/收杆/领鱼/离席/退出）仍可用且不 `leave_pond`
- [x] 场景拖动、钓位点击、08I 延迟/ACK 回归不退化
