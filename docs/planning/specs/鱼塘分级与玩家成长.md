## 1. 背景与目标

### 1.1 背景

产品为社交休闲挂机，核心爽感是钓大鱼炫耀，而非装备碾压。需建立鱼塘类型、双熟练度、时长入场扣费、新手个人塘与固定数值表驱动。

### 1.2 目标

- 七类 `pondCategory` 与解锁/开放规则落地（服务端权威）。
- 玩家钓鱼等级 + 每塘 10 级熟练度；满/锁满后停发塘 XP。
- 进塘确认后按**有效钓鱼时长每满 2h 扣费一次**，日最多 4 次；免票塘不扣。
- 新手：独立 `pond-novice`，开局进 Overlay 引导，不可跳过；结束后关 Overlay 回主界面且不可再进新手塘。
- 建立 `钓鱼玩法固定数值表.xlsx` → 导出 JSON；Node/Unity 共读；规则不进云库。
- 回鱼卖价改为品质×尺寸公式（偏高、社交向）。
- 野外/水库相对高级的乘子落地。

### 1.3 非目标

- 地图六区 UI 重排（`STEAM-DESKTOP-08A2`）。
- 竿/饵/断竿细节（`FEAT-GEAR-01`）。
- 禁止塘巡警完整交互（`FEAT-RISK-01`）。
- 线索文字泡 UI（`FEAT-SPOT-01`）。
- 船 QTE、巨物开放与榜、轮线配件、Mobile 对齐。

## 3. 功能范围

### 3.1 七类钓场

| 类别 | 代号 | 上地图 | 扣费 | 解锁 |
|------|------|--------|------|------|
| 新手 | `novice` | 否 | 0 | 仅引导；完成后不可再进 |
| 高级 | `advanced` | 是 | 每 2h **200** | 引导完成 |
| 老手 | `veteran` | 是 | 每 2h **500** | 玩家等级 ≥ **5** |
| 野外 | `wilderness` | 是 | 0 | 引导完成 |
| 水库 | `reservoir` | 是 | 0 | 引导完成 |
| 禁止 | `forbidden` | 是 | 0 | 引导完成（巡警见 RISK-01） |
| 巨物 | `giant` | 是（可见） | 每 2h 2500（开放后） | Lv≥15 且 `isOpen`；现 **false** |

公开 20 塘映射与 `pond-novice` 见 Epic 计划数值初稿；权威以 xlsx `ponds` sheet 为准。

### 3.2 入场扣费

- **不单独买票**；进收费塘时确认弹窗（告知每 2h 费用、今日已扣/剩余次数）。
- 只计**有效钓鱼时长**；每满 2h 扣 1 次；**每日最多 4 次**（对齐 8h）。
- 金币不足以支付下一切片：**立即停止钓鱼**并提示；再点开始钓鱼仍弹提示，不可开钓。不产生负金。

### 3.3 双熟练度

| 维度 | 云库 | 配置表 | 规则 |
|------|------|--------|------|
| 玩家等级 | level + xp | `player_levels` | 升级 XP、`pondXpPerHour`、`maxPondLevel` |
| 塘熟练度 | 每 pondId：level 1–10 + xp | `pond_levels` | 鱼获 `pondXp` + 时长速率 |
| 停发 | — | — | 塘 Lv 满或达 `maxPondLevel` 无法再升 → **停发塘 XP**；玩家 XP 仍发 |

### 3.4 新手引导

1. 新用户 → Overlay + `pond-novice`（发入门竿，依赖 GEAR）。
2. 五步：落座 → 开始钓鱼 → 等上钩 → 收获 → 完成；**不可跳过**。
3. 完成后：关 Overlay → 主界面；标记引导完成；**禁止再 join `pond-novice`**。

### 3.5 卖价公式

```
sellGold = floor( QUALITY_BASE[q] × (sizeM / SIZE_REF[q])^1.15 × SPECIES_MULT[catchGroup] )
sellGold = max(sellGold, MIN_SELL[q])
```

常量见计划初稿 / xlsx `fish_sell`（灰 BASE 80 … 金 14000 等）。替换现行 `shared/economy.ts` 偏小公式（实现阶段改代码）。

### 3.6 野外/水库乘子（相对 advanced=1）

| 系数 | wilderness | reservoir |
|------|-----------|-----------|
| biteRateMul | 0.75 | 0.65 |
| escapeRateMul | 1.10 | （默认 1.0 或略高） |
| infoRevealMul | 0.70 | 0.55 |
| qualityWeightSkew | 0.85 | （可同或更低） |
| sizeCapMul | 0.95 | — |
| pondXpMul | 1.10 | 1.15 |

### 3.7 固定数值表

工作簿根目录（或 `docs/planning/` 同步约定）：`钓鱼玩法固定数值表.xlsx`。  
Sheets：`_meta`、`ponds`、`player_levels`、`pond_levels`、`fish_species`、`fish_xp`、`pond_fish_pool`、`pond_quality_cap`、`pond_fish_size_cap`、`rods`、`baits`、`vessels`、`spot_clues`、`fish_sell`、可选 `pond_modifiers`。  
导出：`npm run game-data:export` → `shared/generated/game-data/` + Unity `Resources/GameData/`。  
**字段与初值**以策划计划「完整字段总表 / 数值初稿 v0」为准；用户可改表。

## 5. 验收标准

- [ ] 新账号首次进入走 Overlay 新手塘；不可跳过；完成后回主界面且无法再进 `pond-novice`
- [ ] 引导后可进高级/野外/水库/禁止；老手需等级；巨物可见不可进
- [ ] 高级/老手钓鱼满 2h 扣对应金；日最多 4 次；不足停钓并可重复提示
- [ ] 双熟练度发放与锁满停塘 XP 符合表
- [ ] 卖价符合公式；灰蓝日常可覆盖高级 2h 扣费量级（抽样验算）
- [ ] 野外/水库咬钩等乘子生效
- [ ] xlsx 可导出 JSON；服务端读表而非硬编码 STOCK 轮转（或过渡期双读有开关）
