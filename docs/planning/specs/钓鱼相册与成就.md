## 1. 背景与目标

### 1.1 背景

资料（08E）、图鉴（Gallery）、展示柜（showcase 8 格）入口割裂，无「钓鱼经历相册」与成就。玩家需要统一的**个人中心**表达「我是谁 / 我钓过什么 / 我得意的瞬间 / 我解锁了什么」。

### 1.2 目标

- 将 **资料 + 展示柜 + 图鉴 + 相册墙 + 成就** 整合为**单一「个人中心」大面板**。
- **大改 UI**：新信息架构与视觉层级，不是在现有 Profile / Gallery 弹窗上简单叠 Tab。
- 相册墙：精选经历卡片（钉选 / 自动收录）。
- 成就：表驱动；他人可查看精选相册与成就徽章。
- 图鉴：物种聚合只增不减，作为子区接入。

### 1.3 非目标

- 全量钓鱼时间线日志（后置 `fishing_catch_log`）。
- Steam 平台成就 API / 云成就同步。
- AI 生成纪念照（原 15 条 #8 后置）。
- Mobile/Web 对齐。

### 3.2 信息架构（定稿草案）

主窗单一面板 **「个人中心」**（建议侧栏 + 内容区）：

```text
┌─────────────────────────────────────────────┐
│ 个人中心                          [关闭]   │
├────────┬────────────────────────────────────┤
│ 资料   │  头像 / 昵称 / 简介 / 等级摘要     │
│ 展示柜 │  8 格 showcase（拖拽装备鱼）       │
│ 图鉴   │  物种网格 + 详情（原 Gallery）     │
│ 相册   │  精选墙 +「候选」列表             │
│ 成就   │  已解锁 / 未解锁网格              │
└────────┴────────────────────────────────────┘
```

- **入口**：主窗原「资料」「图鉴」合并为「个人中心」；他人 Overlay 右键「查看资料」打开**只读**同壳（隐藏编辑）。
- **视觉**：需新布局与层级；开发前由 UI 设计产出 [`docs/design/ui/steam-profile-hub.md`](../../design/ui/steam-profile-hub.md)（或等价），spec 实现以该稿为准微调间距/色，**不得缩回双弹窗割裂方案**。

### 3.3 相册墙规则

| 项 | 规则 |
|----|------|
| 墙上容量 | 精选 **N=12**（表可配） |
| 卡片内容 | 物种、尺寸、品质、塘名、时间、来源标签（捕获/回鱼/首次图鉴） |
| 自动候选 | 捕获稀有及以上；尺寸达种 80%+；回鱼成功；首次解锁图鉴 |
| 钉选 | 从候选或最近事件钉到墙；满则需先取消 |
| 存储 | 新表 `player_album_pins` + 可选 `player_album_candidates`（或事件派生） |
| v1 不做 | 无限滚动全历史 |

### 3.4 成就规则

Sheet `achievements`：

| 字段 | 说明 |
|------|------|
| `achievementId` | 主键 |
| `name` / `desc` | 文案 |
| `iconKey` | 资源键 |
| `category` | catch / social / progress / album … |
| `conditionType` | 如 `codex_count` / `return_count` / `max_size` |
| `conditionValue` | 阈值 |
| `sortOrder` | 展示序 |
| `isHidden` | 未达成是否显示条件 |

云库：`player_achievements(player_id, achievement_id, unlocked_at)`。

**初稿成就（≥6 条种子）**

| id | 条件 |
|----|------|
| ach-first-catch | 首次入包 |
| ach-codex-5 | 图鉴 ≥5 |
| ach-codex-20 | 图鉴 ≥20 |
| ach-return-1 | 回鱼 ≥1（依赖 RETURN） |
| ach-big-08 | 单次尺寸 ≥0.8m |
| ach-album-3 | 相册钉选 ≥3 |

解锁：服务端在对应事件后检查；弹轻量 toast；埋点 `achievement_unlocked`。

### 3.5 隐私

- 沿用 `share_visibility`（或扩展）：`public` / `friends` / `private`。
- 他人可见：资料摘要 + 精选相册 + 已解锁成就徽章；**不**暴露候选列表与未解锁隐藏成就条件（若 `isHidden`）。

## 4. 技术影响

### 4.1 数据模型

- 复用：`players`、`fish_codex`、`showcase_fish_ids`
- 新增：`player_album_pins`、`player_achievements`；表数据 `achievements`

### 4.2 API / Socket

| 类型 | 名称 | 说明 |
|------|------|------|
| REST | `GET /api/players/:id/profile-hub` | 聚合：资料+showcase+codex 摘要+pins+achievements |
| REST | `PUT /api/players/:id/album/pins` | 钉选列表 |
| REST | `GET /api/achievements` | 目录 |
| REST | 既有 showcase / profile 编辑 | 迁入或代理 |
| Socket | `achievement_unlocked` | 推送本人 |

- Unity：新 `DesktopProfileHubPanel`（或大改 `DesktopProfilePanel` + 废弃独立 Gallery 主入口）

- `server`：codex、新 album/achievement 模块
- `docs/design/ui/`：个人中心 wireframe（实现前置）

| eventType | 关键 |
