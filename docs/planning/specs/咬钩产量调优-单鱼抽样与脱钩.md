## 1. 背景与产量目标

### 1.1 v0.4.0 基线（模拟观测）

| 指标 | 数值 |
|------|------|
| 20 人全服日上岸 | **~1,235 条** |
| 人均 | **~2.57 条/人/小时** |
| 目标 | **< 100 条/天**，**~0.21 条/人/小时** |
| 需压降 | 约 **÷12** |

### 1.2 三策略叠加逻辑

| 策略 | 机制 | 相对 v0.4 预估 | 与 1min 检测关系 |
|------|------|----------------|------------------|
| **D10 单鱼抽样** | 每次只判 1 条，不再 Σ 累加 | 单次检测 ÷N（N≈本点鱼数） | 1min 使检测 ×5，净效果约略增 |
| **D11 BASE ÷20** | `BITE_BASE_SCALE = 0.05` | ÷20 | 线性叠加 |
| **D12 幼鱼脱钩** | 0.08–0.35m 脱钩曲线抬高 | 上岸 ×0.65–0.75 | 独立乘数 |

**推荐组合**：D10 + D11 + D12 一起上线。

**粗算**（20 人、本点 ~4 鱼）：

```
1235 × (1/4) × 5 × (1/20) × 0.7 ≈ 54–80 条/天  ✓ 接近目标
```

> 精确值以 `npm run analytics:pond-day` 重跑为准；`BITE_BASE_SCALE` 可在 0.04–0.06 微调。

## 2. D10 — 1 分钟检测 + 单鱼抽样咬钩

### 2.1 设计意图

| v0.4.0 | 问题 | v0.4.1 |
|--------|------|--------|
| 每 **5min** 扫描本点全部鱼 | 反馈慢 | 每 **1min** 一次 |
| `pBite = min(1, Σ effectiveBite)` | 本点鱼越多越容易中 | **先抽 1 条**，再 `pBite = eff(该条)` |
| 咬钩后再加权抽鱼 | 与检测重复 | 检测目标 = 咬钩目标 |

### 2.2 新流程

```
每 FISH_BITE_CHECK_MS = 60_000（1 分钟）:

1. candidates = listPondFishAtSpot(pondId, spotId) \ locked
2. if candidates.empty → return null（空杆，见 §4.3）
3. target = pickSpotFishCandidate(candidates)   // 按品质权重，§2.3
4. baseBite = calcQualitySizeBiteRate(target) × target.biteMultiplier
5. pBite = clamp01(spotMultiplier × (baseBite + baitBonus))
6. if random() >= pBite → return null（本次空杆）
7. 若咬钩 → 进入现有状态机（脱钩/收杆/上岸），target 即 hook 鱼
```

**删除**：

- `calcTickBiteProbability(Σ effectiveBite)` 用于咬钩检测的路径
- `buildBiteWeights` 全列表 + 加权二次抽鱼（可保留简化版供 Debug 列表展示）

## 3. D11 — QUALITY_BITE_BASE 全体 ÷20

### 3.1 设计意图

保留 `calcQualitySizeBiteRate` 公式形状，整体下调一个数量级；用 **`BITE_BASE_SCALE`** 便于调参。

### 3.2 实现（推荐）

```typescript
// shared/fishing.ts
/** 咬钩基础表全局缩放，默认 1/20 */
export const BITE_BASE_SCALE = 1 / 20;

export function calcQualitySizeBiteRate(quality: FishQuality, sizeM: number): number {
  const n = clamp01(sizeM / getQualityMaxSizeForBite(quality)); // 或现有 cap 逻辑
  return QUALITY_BITE_BASE[quality] * BITE_BASE_SCALE * (1 - SIZE_BITE_K * (1 - n));
}
```

**`QUALITY_BITE_BASE` 表数值不改**（文档/图鉴对照仍用原表 × SCALE）。

### 3.3 缩放后参考（满尺寸 n=1，×spot 2.5）

| 品质 | 原 BASE | ×0.05 | ×spot 2.5 |
|------|---------|-------|-----------|
| 灰 | 5.00% | 0.25% | 0.63% |
| 绿 | 3.20% | 0.16% | 0.40% |
| 蓝 | 1.80% | 0.09% | 0.23% |
| 紫 | 0.80% | 0.04% | 0.10% |

幼灰 0.14m（n≈0.47）：原 ~3.3% → **~0.16%** → ×spot **~0.4%**/次。

### 3.4 与 D10 叠加估算

```
P(单次咬钩) ≈ 8% / 20 ≈ 0.4%
60 次/小时 × 0.4% ≈ 0.24 咬钩事件/小时/人
20 人 × 24h ≈ 115 次咬钩事件
扣 D12 脱钩 → 上岸约 50–80 条/天
```

### 3.5 文案与表同步

- 所有「每 5 分钟」→「**每 1 分钟**」
- `BITE_CALIBRATION_TABLE` / 注释速查表按 `BITE_BASE_SCALE` 重算或注明「× SCALE」
- `formatBiteRatePct` 展示值自动反映 SCALE

### 3.6 风险

- 红/橙/金单次咬钩极低 → 符合稀有预期
- **仅 D11、不改 D10** 时 v0.4 Σ 模型仍偏高（~300+/天）→ 必须组合上线

### 3.7 验收标准

- [ ] `BITE_BASE_SCALE === 0.05`
- [ ] 灰幼鱼 Debug `baseBite` ≈ 0.16%（非 3.3%）
- [ ] 模拟器 `perAnglerPerHour` 较 v0.4 下降约一个数量级

## 4. D12 — 幼鱼脱钩 + 空杆体验

### 4.1 设计意图

D10/D11 降低「咬钩事件」；D12 降低「咬钩 → 上岸」转化率。

**现状**：0.10m 幼鱼 `calcSizeEscapeRate` ≈ **0.44%** → 几乎必上岸。

### 4.2 方案 4A：幼鱼体长脱钩曲线（必做）

```typescript
export const JUVENILE_ESCAPE_SIZE_M = 0.35;
export const ESCAPE_AT_JUVENILE_MIN = 0.22;  // 0.08m 锚点，减免前
export const ESCAPE_AT_JUVENILE_MAX = 0.08; // 0.35m，与原曲线衔接

export function calcSizeEscapeRate(sizeM: number): number {
  if (sizeM <= JUVENILE_ESCAPE_SIZE_M) {
    const t = clamp01((sizeM - 0.08) / (JUVENILE_ESCAPE_SIZE_M - 0.08));
    const juvenile =
      ESCAPE_AT_JUVENILE_MIN + (ESCAPE_AT_JUVENILE_MAX - ESCAPE_AT_JUVENILE_MIN) * t;
    return clamp01(juvenile);
  }
  // 0.35m 以上：原 40m 曲线不变
  const n = clamp01(sizeM / REFERENCE_SIZE_M);
  const curve = 1 - Math.pow(1 - n, SIZE_ESCAPE_CURVE_EXPONENT);
  return Math.min(ESCAPE_RATE_MAX, ESCAPE_AT_40M * curve);
}
```

| 体长 | 原脱钩 | 新脱钩 |
|------|--------|--------|
| 0.10m | 0.4% | **22%** |
| 0.20m | ~1% | **~17%** |
| 0.35m | ~2% | **8%** |
| 1.0m+ | 原曲线 | 不变 |

在 0.35m 处应平滑衔接（实现时校验 `juvenile(0.35) ≈ curve(0.35)`）。

### 4.3 方案 4B：空杆 / 脱钩飘字（必做）

| 事件 | 飘字（示例） | 鱼状态 |
|------|--------------|--------|
| 检测未中（D10 step 6） | 「水面平静…」 | 无变化 |
| 咬钩后脱钩 | 「鱼挣脱了！」（已有可复用） | 留塘 + ×1.02 |
| 收杆超时 | 「鱼溜了…」 | 同脱钩 |

**玩家 UI 不展示概率**；Debug 可记录空杆原因。

### 4.4 方案 4C：收杆基础失败率

**本版不做**（`HOOK_FAIL_BASE_RATE` 不引入）。

### 4.5 三策略叠加预估

| 阶段 | 20 人日上岸（粗估） |
|------|---------------------|
| v0.4 基线 | ~1,235 |
| +D10 only | ~1,540（略升） |
| +D10+D11 | ~77 |
| +D10+D11+D12 | **~50–60** ✓ |

### 4.6 验收标准

- [ ] `calcSizeEscapeRate(0.10)` ≈ 0.22（±0.01）
- [ ] `calcSizeEscapeRate(1.0)` 与改前一致（±2%）
- [ ] 检测空杆有飘字或 miss 事件（同塘可见）
- [ ] 模拟被钓均长仍偏低（幼鱼为主）
