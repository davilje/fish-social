## 1. 目标

- 钓竿进固定数值表；弱咬钩/防脱；品质与 D3 `catchGroup` 弱适配。
- 超规格成功钓满 N 条 → **竿销毁**，只能买新，不能修；**无可用竿则不能开钓**。
- 鱼饵：基础无限；进阶按低等级依次解锁；不进货；使用按次扣少量金；按鱼 `diet` 自动选用。
- 船具：高等级高价可买，`enabledUse=false`，不做使用逻辑。

### 非目标

- 船 QTE/动画/捕捞结算
- 轮/线/配件完整养成
- 竿数值碾压式成长

## 2. 竿（`rods`）

字段见 PROG-01 字段总表。初稿 SKU：`rod-bamboo`（赠/0 金）…`rod-giant` 等 8 把。

- `breakSizeM` + `breakMaxLandings`：超规格成功计数满 N → 销毁当前装备竿。
- 开钓门禁：必须装备未销毁竿；否则提示去商店。
- 首次读装备发放 `rod-bamboo`（本地教学关不依赖云端 `onboarding_completed`）。

竿弱加成幅度保持小；主体验靠熟练度线索（SPOT）。

## 3. 饵（`baits`）

| baitId | 解锁 | 消耗 |
|--------|------|------|
| bait-basic | 0 无限 | 0 金 |
| bait-veg / mix / meat | Lv2/3/4 | 15/20/25 金每次 |

咬钩时按鱼 `diet` 选已解锁对口饵并扣金；否则基础饵。云库只记解锁列表。

## 4. 船（`vessels`）

商店可买；使用按钮禁用或「即将开放」。
