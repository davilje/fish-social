## 1. 背景

在既有 Steam 桌面端（08/09）与挂机钓鱼基础上，扩展鱼塘分级、玩家/鱼塘熟练度、时长入场扣费、钓具/鱼饵、新手引导、禁止塘风险与点位线索。权威产品讨论见 Cursor 计划「后续玩法需求讨论」；**固定数值不进云库**，统一 `钓鱼玩法固定数值表.xlsx` → JSON。

**R1（2026-08-21～08-22）**：子票均已 **已实现**（PROG / 11 / GEAR / 08A2 / RISK / SPOT / 12）。  
**R2（2026-08-23～08-24）**：RETURN-01/02、GROUND-01、ALBUM-01、BUG-23 均 **已实现**。  
**R3**：原 15 条后置项（巨物/活动/社交/AI 照/夜钓等）+ 技术债，待开题。
