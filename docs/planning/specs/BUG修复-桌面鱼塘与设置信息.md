## 目标

在 BUG-57 的三栏外框上，把探索世界、选择鱼塘、设置里玩家能看到的内部信息和空说明收干净。

## 行为

1. 鱼塘卡片和详情只显示中文：水域类型、区域、地名、鱼种名。不出现 `east_plain_lake` 这类字段值。
2. 选择鱼塘：点「选择」后，右栏显示鱼种、费用、等级和位置；「进入鱼塘」直接进入（默认出售档）；「在地图查看」才切到探索世界。卡片宽度落在中栏内。
3. 探索世界：标记缩小为名称，并按鱼塘类型着色；左栏图例与颜色一致。进入前默认选中「回鱼出售」。状态栏不再重复图例。
4. 设置：当前分辨率或显示方式有选中态，切换后立即保存，不再显示「保存窗口设置」。窗口尺寸说明只在窗口页出现。连接测试成功只显示「连接正常」。非 Development 包隐藏「服务器连接」页签和「模拟连接错误」。
5. 选择鱼塘右栏写在预制体里，运行时只填文字和绑定按钮。

## 非目标

- 不合并探索世界和选择鱼塘。
- 不改 Overlay 画布。
- 不改 `mobile/`、`server/`、`shared/`。

## 验收

- [x] 选择鱼塘卡片没有英文区域 id，右栏随选中变化，并能进入或跳到地图。
- [x] 地图标记不挡住半个鱼塘名，颜色和图例一致，未选模式时也能进入。
- [x] 设置里当前分辨率有高亮，测试连接不出现 JSON。
- [x] 「进入鱼塘」一次点击即进入，费用已在详情中展示。
- [x] 鱼塘列表在卡片空白处和列表空白处都能拖动滚动。
