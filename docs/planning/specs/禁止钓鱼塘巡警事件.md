# FEAT-RISK-01：禁止钓鱼塘巡警事件

| 优先级 | P1 |
| 依赖 | `FEAT-PROG-01`（forbidden 塘）、Overlay 气泡（09C） |

## 1. 目标

禁止钓鱼塘在钓鱼过程中随机触发巡警：Overlay 文字泡警告，限时离塘可免罚但短时禁入；超时则罚款并当日禁钓该塘。

### 非目标

- 警察 3D 模型或复杂 QTE
- 跨塘全局通缉

## 2. 规则

| 步骤 | 行为 |
|------|------|
| 触发 | `forbidden` 塘内有效钓鱼中，按表 `fineChancePerHour`（初值 **0.15**）随机触发 |
| Overlay | 气泡文案：**「巡警来了！快跑！」**（样式同聊天气泡） |
| 主窗 | 系统警告弹窗（若主窗可见） |
| 时限 | **10 秒** |
| 时限内离塘 | **不扣罚款**；该 `pondId` **当日 2 小时内不可再 join** |
| 超时仍在塘 | 扣 `fineGold`（初值 **800**）；不足则金币**归零**；**当日禁止再在该塘钓鱼** |
| 提示 | 罚款/禁入均需明确系统消息 |

## 3. 验收

- [ ] 触发后 Overlay 出现约定文案气泡
- [ ] 10s 内离塘：无罚款、2h 内无法再进该塘
- [ ] 超时：扣金（不足归零）+ 当日禁钓该塘；再 join 被拒并提示
- [ ] 埋点：`forbidden_pond_fine` / `forbidden_pond_escaped`（实现时登记埋点表）

- Unity/Overlay：气泡与弹窗、倒计时
