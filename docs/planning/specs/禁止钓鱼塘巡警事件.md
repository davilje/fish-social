## 1. 目标

禁止钓鱼塘在钓鱼过程中随机触发巡警：Overlay 文字泡警告，限时离塘可免罚但短时禁入；超时则罚款并当日禁钓该塘。开发版本提供一键出警 Debug，便于验收。

### 非目标

- 警察 3D 模型或复杂 QTE
- 跨塘全局通缉
- 正式发行包默认暴露一键出警（仅 Development / Debug 构建或等价开关）

## 2. 规则

| 步骤 | 行为 |
|------|------|
| 触发 | `forbidden` 塘内有效钓鱼中，按表 `fineChancePerHour`（初值 **0.15**）随机触发 |
| Overlay | 气泡文案：**「巡警来了！快跑！」**（样式同聊天气泡） |
| 主窗 | 系统警告弹窗（若主窗可见） |
| 时限 | **10 秒** |
| 时限内离塘 | **不扣罚款**；该 `pondId` **当日 2 小时内不可再 join** |
| 超时仍在塘 | 扣 `fineGold`（初值 **800**）；不足则金币**归零**；**当日禁止再在该塘钓鱼** |
| 提示 | 罚款/禁入均需明确系统消息 |

## 2.1 Debug：一键出警（开发版本）

| 项 | 要求 |
|----|------|
| 入口 | **禁止钓鱼塘 Overlay** 右上（退出鱼塘下方），文案 **「一键出警」**；仅该塘显示 |
| 可见性 | 进入 `forbidden` 塘的 Overlay 即显示（含当前 Release 验收包）。设置面板不放此按钮。服务端 `NODE_ENV=production` 且未开 `POLICE_RAID_DEBUG=1` 时接口仍拒绝 |
| 行为 | 按下后对**当前玩家所在**且类别为 `forbidden` 的塘，**立即触发一次**与正式随机出警相同的巡警事件（同一套 10s / 免罚短禁 / 超时罚款日禁 状态机） |
| 前置 | 若不在禁止塘、或未在有效钓鱼中：按钮可点但应明确提示失败原因（如「需在禁止塘钓鱼中」），**不**伪造错误塘态 |
| 权威 | 优先走服务端 Debug API / Socket（与正式触发同源）；禁止仅客户端本地演戏而不改服务端禁入/扣金 |

## 3. 验收

- [x] 触发后 Overlay 出现约定文案气泡
- [x] 10s 内离塘：无罚款、2h 内无法再进该塘
- [x] 超时：扣金（不足归零）+ 当日禁钓该塘；再 join 被拒并提示
- [x] 埋点：`forbidden_pond_fine` / `forbidden_pond_escaped`（实现时登记埋点表）
- [x] 禁止塘 Overlay 有「一键出警」（含当前验收包）；按下后在禁止塘钓鱼中可立即出警；设置面板无此按钮
