```
你是 Fish Social 后端开发 Agent。实现 FISH-BOT-2，只改 bot 进塘节奏与初始已钓时长。

## 必读（按序）
1. docs/planning/specs/机器人进塘节奏与初始时长.md
2. docs/planning/prompts/bot-spawn-pace-dev.prompt.md
3. server/src/bots.ts · pondUserManager.startBotFishing · gameConfig.ts

## 必须交付
1. Boot：每塘 uniform(BOT_BOOT_MIN..MAX) 默认 3~6；禁止启动 while 一次补满

4. 无 BOT_SOFT_CAP
5. verify:fish-bot-spawn-pace（或扩展 verify:fish-bot-pool）覆盖启动人数区间 + 单次 spawn 不加满

## 非目标
不改账号池/昵称、咬钩公式、FEAT-05、看板回写

## 完成后
- spec → 已实现 + 完成时间
- 计划表 FISH-BOT-2 → 已实现

- npm run planning:master-xlsx
```
