# 钓鱼系统 v2 — 生态与玩法重构

## 元信息

| 字段 | 内容 |
|------|------|
| 功能名称 | 钓鱼系统 v2（成长曲线、咬钩/脱钩、阶段动画、鱼饵/渔具商店） |
| 负责人 | 策划 |
| 状态 | **已废弃** |
| 目标版本 | v0.2.0（建议拆期，见 §8） |
| 关联全景章节 | 鱼塘生态、钓鱼玩法、经济系统 |
| 替代/废弃 | 当前 `FISH_BITE_CHANCE` 全局概率、`deriveQualityFromSize` 随成长改品质、`FISH_CATCH_SUCCESS_RATE` 咬钩后再判定 |

---

## 1. 背景与目标

### 1.1 背景

当前实现存在与产品预期不符之处：

| 现状 | 问题 |
|------|------|
| 新鱼 `newbornSize` + `deriveQualityFromSize` | 初始几乎全是小尺寸低品质 |
| 成长时 `growAllFish` 会更新 `quality` 字段 | **品质随尺寸变化**，与「品质天生固定」冲突 |
| 咬钩：`14% × 钓点权重`，再 `70%` 成功 | 与「按鱼个体 + 钓点累加」不符；脱钩与鱼无关 |
| 无鱼饵/渔具 | 无经济消耗与策略深度 |
| 无钓鱼阶段动画 | 仅 `status: fishing`，他人看不到装饵/咬钩等过程 |
| Admin 仅看鱼列表 | 无法调试各钓点/各鱼的上钩概率 |

### 1.2 目标

1. **优先**定义鱼的成长曲线与品质—尺寸上限关系；品质在出生时确定，**终生不变**。
2. 每条鱼（按鱼种配置，可带品质修正）有独立的咬钩权重与脱钩概率；**品质越高，脱钩越高、可长越大**。
3. 池塘初始化与繁衍产出应具备**种类 + 品质 + 尺寸**的合理分布，而非清一色幼鱼。
4. 钓鱼流程改为：**装饵 → 抛竿 → 等待 → 咬钩（飘字 + 咬钩时长 + 即时判定脱钩）→ 拉起或空军**；全员可见阶段动画。
5. Debug/Admin 可查看每个钓点、每条鱼的有效上钩概率。
6. 鱼饵商店（提咬钩）、渔具商店（降脱钩）；默认鱼饵无限供应。

### 1.3 非目标（本 spec 明确不做）

- 不做 PvP 抢鱼 UI 大改（保留现有 pending 锁鱼机制，仅适配新事件）。
- 不做鱼塘可视化 3D 鱼游动（仍为数据驱动生态）。
- 不做付费货币/内购（仅用游戏内金币）。
- 不做钓鱼小游戏 QTE（咬钩时长内纯等待）。
- v0.2.0 **不**改世界地图结构、不新增鱼塘数量。

## 2. 核心概念

| 概念 | 说明 |
|------|------|
| **品质 `quality`** | 灰→金 7 档；鱼出生时掷定，**不随 `sizeM` 改变** |
| **尺寸 `sizeM`** | 随时间成长，上限由 `quality` 决定（见 §3.1） |
| **咬钩权重 `biteWeight`** | 鱼种基础值 + 可选个体浮动；与钓点权重**相加**后参与抽选 |
| **脱钩率 `escapeRate`** | 咬钩瞬间判定；鱼种基础 + 品质加成 − 渔具减免，clamp 0~1 |
| **咬钩时长 `hookDurationMs`** | 咬钩时确定，由品质与尺寸决定；结束后才弹窗 |
| **钓鱼阶段 `fishingPhase`** | 服务端权威状态机，广播给同塘所有人 |
| **鱼饵 `baitId`** | 影响咬钩权重加成；默认 `basic` 无限 |
| **渔具 `tackleId`** | 影响脱钩率减免；默认 `basic` |

## 3. 数值设计（`shared/`）

### 3.1 成长曲线与品质—尺寸上限

**原则**：品质决定**尺寸上限** `maxSizeM`；成长只改 `sizeM`，不改 `quality`。

沿用并强化现有 `QUALITY_SIZE_CAP`（可微调）：

| 品质 | 尺寸上限 `maxSizeM` |
|------|---------------------|
| gray | 0.30 |
| green | 0.80 |
| blue | 2.0 |
| purple | 6.0 |
| red | 15.0 |
| orange | 30.0 |
| gold | 50.0 |

**出生时尺寸** `rollInitialSize(quality, species)`：

```
floor = max(MIN_FISH_SIZE_M, species.typicalMinM * 0.6)
ceiling = min(maxSizeM(quality), species.typicalMaxM * 0.45)
sizeM = floor + (ceiling - floor) * random^1.2   // 偏小偏态，保留成长空间
```

**成长公式** `growFishSize(speciesId, quality, currentSizeM, hoursElapsed)`（替换现有仅按 species 的公式）：

```
maxSize = min(QUALITY_SIZE_CAP[quality], species.typicalMaxM * 3.2, MAX_FISH_SIZE_M)
// 逻辑尺寸倍率：接近上限时减速
progress = currentSizeM / maxSize
speedFactor = (1 - progress)^1.5
delta = species.typicalMinM * POND_GROWTH_RATE_PER_HOUR * hoursElapsed * (0.8 + speedFactor)
newSize = min(maxSize, round2(currentSizeM + delta))
```

**废弃**：`deriveQualityFromSize` 不再用于鱼塘实体与上钩结算；可保留供野生兜底 `rollFishCatch` 或标记 `@deprecated`。

**繁衍**：子代品质独立掷骰（见 §3.2），尺寸用 `rollInitialSize`；**不继承父母品质**（避免品质通胀，除非后续单独 spec）。

### 3.2 池塘初始种群分布

`seedPond` / `createFish` 改为：

1. `speciesId` ← 现有 `pickSpecies(config)`（常见/稀有池）。
2. `quality` ← `rollFishQuality()`（与 `FISH_QUALITIES.weight` 一致）。
3. `sizeM` ← `rollInitialSize(quality, species)`。
4. **可选**个体咬钩浮动：`biteWeight = species.biteWeight * (0.9 + random*0.2)` 存 DB（见 §4.1）。

**恢复枯竭鱼塘** `tryRecover` 补种时同样走上述分布，而非 `newbornSize`。

**品质分布目标（单塘 48 条量级）**：灰~绿占多数，紫以上稀少，与 `FISH_QUALITIES` 权重一致。

### 3.3 鱼种咬钩 / 脱钩配置

在 `FishSpecies` 扩展字段（示例初值，开发时可放 `shared/fishing.ts`）：

```ts
interface FishSpecies {
  // ...现有字段
  /** 每 5s 检测周期内，参与「累加抽选」的基础咬钩权重 */
  biteWeight: number;
  /** 咬钩后基础脱钩率 0~1 */
  baseEscapeRate: number;
}
```

**品质对脱钩的加成**（加法后 clamp）：

```
escapeRate = clamp01(
  species.baseEscapeRate
  + QUALITY_ESCAPE_BONUS[quality]
  - tackleEscapeReduction(tackleId)
)
```

| 品质 | `QUALITY_ESCAPE_BONUS` |
|------|------------------------|
| gray | 0 |
| green | 0.03 |
| blue | 0.06 |
| purple | 0.10 |
| red | 0.15 |
| orange | 0.20 |
| gold | 0.28 |

**示例鱼种初值**：

| 鱼种 | biteWeight | baseEscapeRate |
|------|------------|----------------|
| crucian / tilapia / perch | 0.12 | 0.08 |
| carp / herring / mackerel | 0.10 | 0.10 |
| bass / trout / mandarin | 0.08 | 0.14 |
| tuna / salmon / pike | 0.06 | 0.18 |
| marlin / sturgeon | 0.04 | 0.25 |

大鱼种 bite 低、escape 高，符合「难钓但易脱钩」体感。

### 3.4 钓点咬钩权重

保留 `spot_bite_weights` 表与 5 分钟刷新；数值语义改为 **与鱼 biteWeight 相加的项**。

```
spotBite = getSpotBiteWeight(pondId, spotId)   // 建议刷新范围 0.04 ~ 0.20
```

### 3.5 咬钩检测（每 `FISH_BITE_CHECK_MS` = 5s）

仅对 `fishingPhase === 'waiting'` 的玩家执行。

**步骤**：

1. 若鱼塘枯竭或无鱼 → 跳过。
2. 枚举塘内所有未锁定鱼实体 `fish[]`。
3. 对每条鱼计算有效权重：  
   `w_i = fish.biteWeight + spotBite + baitBiteBonus(player.baitId)`  
   （若存了个体浮动，用 DB 字段替代 `fish.biteWeight`）
4. `W = Σ w_i`。若 `W <= 0` 跳过。
5. 本周期是否发生咬钩：`P_tick = min(0.95, W * TICK_SCALE)`，其中 `TICK_SCALE = 0.35`（可调，使全塘多鱼时约 10~25%/5s）。
6. 若未触发咬钩 → 结束。
7. 若触发：按 `w_i` 加权随机选中鱼 `target`。
8. **咬钩瞬间**判定脱钩：`escaped = random() < escapeRate(target, player.tackleId)`。
9. 计算 `hookDurationMs`（§3.6），写入 session，切换 `fishingPhase = 'hooked'`，广播事件。

**与旧逻辑差异**：不再使用全局 `FISH_BITE_CHANCE`；`FISH_CATCH_SUCCESS_RATE` 删除。

### 3.6 咬钩时长

```
qualityIndex = 0..6
hookDurationMs = clamp(
  1800 + qualityIndex * 700 + target.sizeM * 400,
  2000,
  12000
)
```

高品质、大尺寸 → 更长拉扯感。

### 3.7 鱼饵与渔具

**默认**：`baitId = 'basic'`，`tackleId = 'basic'`，背包无限（不扣数量）。

| 鱼饵 id | 名称 | 价格（金币） | `baitBiteBonus` | 消耗 |
|---------|------|-------------|-----------------|------|
| basic | 蚯蚓 | 0 | 0 | 不消耗 |
| corn | 玉米粒 | 50/次 | +0.04 | 每次装饵扣 1 |
| pellet | 商品颗粒 | 200/次 | +0.08 | 每次装饵扣 1 |
| live | 活虾 | 800/次 | +0.14 | 每次装饵扣 1 |

| 渔具 id | 名称 | 价格（金币） | `escapeReduction` | 说明 |
|---------|------|-------------|-------------------|------|
| basic | 竹竿 | 0 | 0 | 默认 |
| carbon | 碳素竿 | 3000（一次性购买） | 0.05 | 永久装备 |
| pro | 专业路亚 | 12000 | 0.10 | 永久装备 |
| master | 大师套装 | 50000 | 0.18 | 永久装备 |

**脱钩仍吃饵**：`escaped === true` 时，若当前鱼饵非 basic，装饵阶段已扣过则不再扣；若 basic 无限则仅标记「饵被吃」飘字，进入 `rebaiting`。

玩家 `player_gear` 表记录已购渔具与当前装备。

### 3.8 卖鱼经济（微调，P1）

鱼饵为金币 sink；售价公式可维持现状，本 spec 不强制改价，但商店需有合理金币来源（卖鱼）。

## 4. 钓鱼状态机

### 4.1 阶段枚举 `FishingPhase`

```
idle          // 在塘内未占钓位
seated        // 占座，未开始
baiting       // 装饵（可跳过动画时长 800ms）
casting       // 抛竿（600ms）
waiting       // 垂钓中，参与咬钩检测
hooked        // 已咬钩，计时 hookDurationMs；头顶飘字
reeling       // 未脱钩，咬钩时间结束，拉起（800ms）
escaped       // 已判定脱钩，咬钩时间结束，展示脱钩（600ms）
result        // 弹窗展示中（catch / miss），客户端本地；服务端 phase 可置 waiting 或 seated
```

**转移**：

```
占座 → seated
开始钓鱼 → baiting → casting → waiting
waiting + 咬钩 → hooked（同时下发：鱼种、是否 escaped、hookDurationMs、飘字文案）
hooked 计时结束：
  - escaped → escaped 动画 → fish_miss 弹窗 → baiting（需重新装饵）
  - !escaped → reeling → fish_bite 待领取 → result 弹窗 → accept 后 → baiting
离开钓位 / 停止钓鱼 → idle
```

**权威端**：服务端；客户端请求 `start_fishing` 仅触发 `seated → baiting` 链，阶段计时由服务端 `setTimeout` 或 tick 驱动。

### 4.2 飘字

咬钩进入 `hooked` 时，向**整个鱼塘**广播：

```ts
{
  userId: string;
  text: string;  // 例：「🐟 鲫鱼咬钩！」或「💨 脱钩了！」（脱钩文案在结束时也可再飘一次）
  kind: 'hook' | 'escape';
}
```

客户端在对应 `PondCharacter` 头顶播放向上淡出动画，持续约 1.2s。

### 4.3 脱钩与空军

- **脱钩**：咬钩时已 `escaped=true`；`hookDurationMs` 结束后发 `fish_miss { reason: 'escaped' }`，**鱼仍在塘内**，饵消耗逻辑见 §3.7。
- **空军**（本周期无咬钩）：不发事件；若产品需要「长时间无咬钩提示」为 P2，本 spec 不做。

### 4.4 钓到鱼

- `hooked` 且 `!escaped`，`reeling` 结束后发 `fish_bite`（含 `pondFishId`、品质、尺寸），与现 `PendingFishCatch` 兼容。
- 领取 `accept_catch` 后从塘内移除该鱼实体。

## 5. 同步与动画（客户端）

### 5.1 `PondUser` 扩展

```ts
interface PondUser {
  // ...现有
  status: 'idle' | 'fishing';  // 保留；fishing = phase 非 idle/seated
  fishingPhase: FishingPhase;
  /** 咬钩结束时间戳，仅 hooked 有效 */
  hookEndsAt?: number;
  /** 当前咬钩鱼种 icon，供他人展示 */
  hookSpeciesId?: FishSpeciesId;
  baitId?: string;
  tackleId?: string;
}
```

广播：`pond_user_updated`（现有）携带完整 `PondUser`。

### 5.2 各阶段动画（`PondCharacter`）

| 阶段 | 表现（全员可见） |
|------|------------------|
| seated | 坐在钓点，手持竿 idle |
| baiting | 低头装饵 |
| casting | 甩竿向前 |
| waiting | 竿尖微动，水纹 |
| hooked | 竿身弯曲抖动 + 头顶飘字 |
| reeling | 后仰拉杆 |
| escaped | 竿尖弹起 + 飘字 |

动画可用 Lottie/帧动画或简单 transform，**时长与服务器阶段对齐**；网络延迟以服务端 `hookEndsAt` 为准校正。

### 5.3 弹窗

- 未脱钩：`CatchFishModal`（现有），在 `reeling` 结束后显示。
- 脱钩：`fish_miss` 空军弹窗（现有），文案区分「脱钩，饵被吃了」。

## 7. API / Socket 变更

### 7.1 Socket 客户端 → 服务端

| 事件 | 变更 |
|------|------|
| `take_spot` | 不变；占座后 `fishingPhase=seated` |

## 11. 验收标准

### P0（期 A）

- [ ] 新初始化鱼塘：可见多种品质与尺寸，非全灰最小尺寸。
- [ ] 生态 tick 后鱼尺寸增长，**品质字段不变**。
- [ ] 咬钩概率由「鱼 biteWeight + 钓点 spotBite + 饵加成」决定，无全局 14% 常量。
- [ ] 咬钩瞬间判定脱钩；脱钩则计时结束后空军弹窗，鱼仍在塘内。
- [ ] 未脱钩则计时结束后钓起并弹窗，领取后鱼从塘内移除。
- [ ] 咬钩时全员可见头顶飘字；`PondCharacter` 展示 §5.2 各阶段动画。
- [ ] Admin 钓鱼 debug 面板可查看各钓点 `tickBiteChance` 与每条鱼贡献。
