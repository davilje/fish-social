## 1. 背景

### 1.1 非目标（本系列不做）

- FEAT-05（C5/C6/C2/C3）玩法与动效
- 改钓鱼公式 / Bot AI

## 3. 全量问题汇总表

### 3.1 批次 A — 安全（P0）

| 子编号 | 问题 | 证据（路径） | 为何重要 | 批次 |
|--------|------|--------------|----------|------|
| SEC-01 | `POST /api/players/register` 无鉴权即可发 JWT | `socialRoutes.ts` | 可冒充任意 playerId | A |
| SEC-02 | 玩家域 GET 无 `requireAuth`（资料/好友/动态/私信等） | `socialRoutes.ts` | PII 可被扫 | A |
| SEC-03 | `GET /api/inventory/:playerId` 无鉴权 | `createApp.ts` | 背包明文可读 | A |
| SEC-04 | `GET /api/dm/...` 未鉴权且调用 `markConversationRead` | `socialRoutes.ts` | 读接口带写副作用 | A |
| SEC-05 | `POST /api/client-logs` 无鉴权、批次无上限 | `createApp.ts` | 灌库/伪造 playerId | A |
| SEC-06 | 生产缺 `PLAYER_ERASE_PEPPER` 仍用固定盐 | `playerAnonymize.ts` | 匿名化可预测 | A |

### 3.2 批次 B — 热路径性能（P1）

| 子编号 | 问题 | 证据 | 为何重要 | 批次 |
|--------|------|------|----------|------|
| PERF-01 | 生态 tick 每塘 `buildSnapshot` 只为发 ecology | `serverLoops.ts` | O(用户) 白做 | B |
| PERF-02 | 生态 `tickAllPonds` 大事务 + 逐鱼 UPDATE | `pondEcology.ts` | 阻塞事件循环 | B |
| PERF-03 | 会话计时每秒全量 `pond_user_updated` | `serverLoops.ts` | 广播最热 | B |
| PERF-04 | `consumeDirtyUsers` 导出无调用方 | `pondUserManager.ts` | R2-1 半完成 | B |
| PERF-05 | `getSpotBiteWeight` 热路径重复查库 | `pondEcology.ts` / `fishingSession.ts` | 咬钩额外 IO | B |

### 3.3 批次 C — 停机与稳定性（P1）

| 子编号 | 问题 | 证据 | 为何重要 | 批次 |
|--------|------|------|----------|------|
| STAB-01 | 优雅停机无 session checkpoint 扫盘 | `index.ts` shutdown | 杀进程丢内存态 | C |
| STAB-02 | PG pool / OTEL shutdown 未稳健等待 | `index.ts` · `postgresMetricsStore.ts` | 双写窗口丢点 | C |
| STAB-03 | `uncaughtException` 只记日志不退出 | `errorLog.ts` | 半死进程 | C |
| STAB-04 | Socket 无 per-event 限流 | 仅有连接上限 | 连接内刷事件 | C |
| STAB-05 | Admin `?key=` query 可用 | `admin.ts` | 密钥进日志/Referer | C |
| STAB-06 | `/health` 停机中仍 ok:true | `createApp.ts` | 负载均衡误导 | C |

### 3.4 批次 D — 工程债与部署（P2）

| 子编号 | 问题 | 证据 | 为何重要 | 批次 |
|--------|------|------|----------|------|
| QUAL-01 | vitest 几乎只有 timer/gray | `server/src/__tests__/` | 回归靠脚本 | D |
| QUAL-02 | `fishingStateMachine` / `fishingMetrics` / `admin` 过大 | 各 500～800 行级 | 难测难改 | D |
| QUAL-03 | PG Metrics 同步读空、按行 insert | `postgresMetricsStore.ts` | 切读不可用 | D |
| QUAL-04 | env 散落、部分未进 `.env.example` | 多处 `process.env` | 运维踩坑 | D |
| QUAL-05 | Docker `ALLOWED_ORIGINS` 默认 `*` | `docker-compose.yml` | 与生产校验冲突 | D |
| QUAL-06 | 生产镜像 `tsx` 跑源码；Node 20 vs types 22 | `Dockerfile` | 冷启动/ABI | D |
| QUAL-07 | `/ops` `/planning` 与 API 同端口无鉴权 | `createApp.ts` | 内网文档暴露 | D |
| QUAL-08 | 生产默认不掩码用户字段 | `logger.ts` | 日志 PII | D |
| QUAL-09 | 部分内存 Map 无 LRU（debug cache 等） | `admin.ts` · metrics | 长跑缓泄漏 | D |
| QUAL-10 | `MAX_SOCKET_CONNECTIONS` 与 `MAX_HUMAN_SOCKETS` 双默认易混 | `securityMiddleware` · `humanCapacity` | 容量误配 | D |
