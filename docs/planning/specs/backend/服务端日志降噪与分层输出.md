## 目标

日常控制台默认只保留**有业务语义**的日志；高频心跳 / 调试打印 / 旁路 tap 不刷屏。  
指标（Prometheus）与 Debug 抽样能力保留，不靠「关掉所有日志」偷懒。

## 分层原则

| 层 | 默认 | 内容 |
|----|------|------|
| **业务** | info 常开 | connect / disconnect / join 成败 / reconnect / 相位跳转 / bite·escape / 错误 |
| **性能** | 默认不打 info；异常才升 info | tick / bite_loop / ecology_tick / snapshot；平时只进 Histogram |
| **广播 fanout** | 默认不打 info | `socket_broadcast_fanout` → 指标或 debug；可设阈值（如 fanout≥N 或 duration 异常）才 info |
| **生态补鱼** | 默认 debug 关闭 | `[fish supplement]` / `[pond supplement]` / `[pond migration]` |
| **socket tap** | 抽样保留，但排除高频事件 | 默认忽略 `session_timer_tick`、`pond_ecology_updated` |

## 方案分阶

### A. 立刻可做（本需求范围）

1. **`socket_broadcast_fanout`**  
   - 去掉每次生态 tick 的 info 结构化日志（四塘 × 每轮）。  
   - 保留/补齐 Prometheus counter（channel × pond 可选 label）。  
   - 可选：`FANOUT_LOG_MIN=1` 且仅当 `fanoutCount >= MIN` 时 debug；生产默认不写。

2. **perf 结构化日志**（`tick_fishing_phases_duration_ms` / `bite_check_loop_duration_ms` / `ecology_tick_duration_ms` / `snapshot_build_duration_ms`）  
   - Histogram **必须保留**。  
   - info 抽样改为：**仅当 `durationMs >= PERF_LOG_SLOW_MS`（默认建议 50）** 才 `logStructuredEvent`；或环境变量 `PERF_LOG_INFO=0` 完全关闭 info。  
   - 现有 `PERF_LOG_INTERVAL_MS` 可保留作「慢日志最小间隔」。

3. **生态 `console.log` 补鱼/迁徙**（`pondEcology.ts`）  
   - 改为 `logStructuredEvent` 且 level=debug，或包在 `ECOLOGY_VERBOSE=1` 开关后。  
   - 默认生产 / 本地日常不输出。

4. **`socket_tap` 高频白名单忽略**  
   - `SOCKET_TAP_IGNORE_EVENTS` 默认含：`session_timer_tick,pond_ecology_updated`。  
   - Debug 玩家若需看秒表，可设空忽略列表或 `SOCKET_TAP_INCLUDE_TIMER=1`。

5. **`[metrics-validation] missing … for reconnect`**  
   - 根因：`validateMetricPayload` 只看 `opts.payload`，而 `playerId`/`pondId` 已在 `recordFishingMetric` 顶层传入 → **假告警**。  
   - 修法：校验时合并 `{ ...payload, playerId: opts.playerId, pondId: opts.pondId }`（或顶层字段优先）。  
   - 校验告警保留（dev 有用），修完后 reconnect 不应再刷。

### B. 后续（可选）

| 项 | 说明 |
|----|------|
| B1 | join/leave 类 fanout 同样降级（`socketPondHandlers` / `socketLifecycle`） |
| B2 | 运营平台「日志说明」小节：哪些默认安静、如何开 verbose |
| B3 | 统一 `console.log` 清扫：服务端热路径禁止裸 console |

### C. 明确保留（不要砍）

- `socket_connect` / `join_pond_*` / `reconnect` 业务日志  
- `fishing_phase_transition`（短码后）  
- 错误、慢 SQL、Admin 鉴权失败  
- Prometheus 直方图/计数（perf、fanout）

## 环境变量约定（建议）

| 变量 | 默认 | 含义 |
|------|------|------|
| `PERF_LOG_INFO` | `0`（或仅 slow） | 是否打 perf info |
| `PERF_LOG_SLOW_MS` | `50` | 超过才打 perf info |
| `PERF_LOG_INTERVAL_MS` | `30000` | 慢日志节流（可保留） |
| `ECOLOGY_VERBOSE` | `0` | 补鱼/迁徙明细 |
| `SOCKET_TAP_SAMPLE_RATE` | `0.01` | 现有抽样 |
| `SOCKET_TAP_IGNORE_EVENTS` | `session_timer_tick,pond_ecology_updated` | tap 忽略列表 |
| `FANOUT_LOG_INFO` | `0` | 是否打 fanout info |
