## 1. 背景与目标

### 1.1 背景

`FEAT-RETURN-03` 将回鱼准入定为「紫品及以上 + 体长比 ≥75% 品质上限」。实装与运营反馈表明：

- 玩家更直观理解**体重（斤）**，而非相对体长百分比；
- 大体长但低品质鱼（如 debug 发放、跨档尺寸）常被体长/品质门槛误拦；
- 需要**超重鱼更高回鱼激励**，与卖价形成清晰分档。

### 1.2 目标

- **准入**：须在进塘时选择 **回鱼档（`auto_return`）**；品质 ≥ `minQuality`（默认 **purple**）；市斤体重 ≥ `minWeightJin`（默认 **10 斤**）。
- **回鱼金分档**：
  - 体重 **> 100 斤** → `floor(卖价 × 3)`；
  - 体重 **≥ 10 斤** → `floor(卖价 × 1.5)`；
  - 体重 **< 10 斤** 或品质低于紫 → 不可回鱼。
- **手动 / 自动**共用 `isReturnEligible` 与 `calcFishReturnGold`（自动路径仅在回鱼档触发）。
- Unity 背包预估文案与 `return_rules.json` 表驱动一致。

### 1.3 非目标

- 不改卖价公式、增重区间（0.02~0.05m）、熟练度发放。
- 不改进塘双价 UI、免票塘门禁、出售档逻辑（仍见 RETURN-02）。
- 不改体重公式常数（仍 `W(kg)=12×L(m)^3`，市斤 = kg×2）。
- 成长曲线 `growFishSizeV2` 不变（品质尺寸上限另表调参）。

## 3. 功能范围

### 3.1 体重计算

```text
W_kg   = round2( LENGTH_WEIGHT_A × sizeM ^ LENGTH_WEIGHT_B )   // 默认 A=12, B=3
W_jin  = round2( W_kg × 2 )                                     // 1 市斤 = 0.5 kg
```

### 3.2 准入与回鱼金

```text
isReturnEligible(fish, rules):
  quality ≥ (rules.minQuality ?? purple)
  AND calcFishWeightJin(fish.sizeM) ≥ (rules.minWeightJin ?? 10)

流程门禁：进塘 returnFeeMode === 'auto_return'；出售档不可回。

calcFishReturnGold(item, rules):
  sell = calcFishSellPrice(item)
  jin  = calcFishWeightJin(item.sizeM)
  if jin > (rules.heavyWeightJin ?? 100): mul = rules.goldMulHeavy ?? 3
  else if jin ≥ (rules.minWeightJin ?? 10): mul = rules.goldMulVsSell ?? 1.5
  else: mul = 0
  return floor(sell × mul)
```

**废弃字段（表内可保留兼容，不参与逻辑）**：`minSizeRatio`、`autoMinSizeRatio`、`maxSizeRatio`（准入）。

### 3.3 `return_rules`（表首行定稿）

| 字段 | 值 | 说明 |
|------|-----|------|
| `minQuality` / `autoMinQuality` | **purple** | 紫品及以上 |
| `minWeightJin` | **10** | 可回最低体重（含等号） |
| `heavyWeightJin` | **100** | 超重档门槛（不含等号） |
| `goldMulVsSell` | **1.5** | ≥10 且 ≤100 斤倍率 |
| `goldMulHeavy` | **3** | >100 斤倍率 |
| `playerXp` / `pondXp` | 8 / 4 | 不变 |
| `sizeGainMinM` / `sizeGainMaxM` | 0.02 / 0.05 | 不变 |

### 3.4 错误码

| code | 含义 |
|------|------|
| `WEIGHT_TOO_LOW` | 体重 ≤ minWeightJin，不可回鱼 |

（`AT_MAX_SIZE`、`QUALITY_TOO_LOW` 不再作为回鱼准入失败原因。）

## 5. 验收标准

- [x] 出售档不可回；回鱼档方可自动回鱼
- [x] 体重 <10 斤 → `isReturnEligible === false`；手动回鱼返回 `WEIGHT_TOO_LOW`
- [x] 品质低于紫 → `QUALITY_TOO_LOW` / 自动 skip
- [x] 紫+ 且体重 ≥10 且 ≤100 斤 → 可回；金 = `floor(卖价 × 1.5)`
- [x] 紫+ 且体重 >100 斤 → 可回；金 = `floor(卖价 × 3)`
