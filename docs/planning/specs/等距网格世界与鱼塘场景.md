## 1. 背景与目标

### 1.1 背景

现世界地图为 4 个矩形色块；鱼塘为伪等距条纹 + 椭圆 20 点，缺乏「可游走网格世界」与「不规则水塘 + 岸边钓位」的空间感。Unity 移植暂缓，先在 RN 落地可读场景。

### 1.2 目标

- **世界地图**：等距网格；相邻地形构成陆地板块；板块内有可点**进塘入口格** → 弹窗「进入」→ 进入对应钓鱼场景。
- **钓鱼场景**：等距色块网格；蓝色水格组成不规则池塘；与水相邻的岸格中固定 **20** 个为钓位（沿用现有 `*-spot-1..20`）；其余为土地；可拖拽、平移、缩放。
- 两边共用等距投影与相机能力；Web 优先可用。

### 1.3 非目标

- Unity 工程 / UNITY-P3 实现  
- 真 3D、自由旋转透视镜头  
- 世界地图铺满 4×20=80 个可坐钓位（首期用**每塘入口格**）  
- 改咬钩公式、8h、人数上限、FSM、生态权威  
- 完整序列帧角色美术（可用色块/现有角色占位）  
- Admin / 运营平台进场景改造

## 3. 功能范围

### 3.1 分编号

| 编号 | 名称 | 优先级 | 说明 |
|------|------|--------|------|
| **FEAT-SCENE-ISO-1** | 鱼塘等距色块网格 + 相机 | P0 | **先做**；替换 `PondScene` 椭圆布局 |
| **FEAT-SCENE-ISO-2** | 世界等距地图 + 入口格 | P0 | 依赖 ISO-1 的 `isoMath` / 相机可复用 |

### 3.2 FEAT-SCENE-ISO-1 — 鱼塘

| # | 功能点 | 说明 |
|---|--------|------|
| 1 | 地形网格 | `land` / `water` / `fish_spot`；水团不规则；四塘可用不同水形或色板区分 |
| 2 | 20 钓位 | 与水四邻（或八邻，实现时定一种）的岸格中选定 20 格，绑定现有 `calm-spot-1`… 等 id |
| 3 | 投影 | `(col,row) → screen` 等距（diamond / 2:1）；`FishingSpot.x/y` 可由格中心生成 |
| 4 | 相机 | 平移 + 缩放（Web：拖拽 + 滚轮；移动端：拖 + 捏合优先） |
| 5 | 深度 | 角色/码头按 `y` 或 `row+col` 排序绘制 |
| 6 | 联网 | 不改事件名；进塘钓鱼闭环与 FEAT-UI 叠层语义保持 |

**点选入座**：首期可保留自动占空位；点钓位高亮/预留回调为加分，不阻塞验收。

### 3.3 FEAT-SCENE-ISO-2 — 世界地图

| # | 功能点 | 说明 |
|---|--------|------|
| 1 | 大网格 | 逻辑格规模建议先 **64×64～128×128**；视口外 culling / 虚拟化 |
| 2 | 陆地板块 | 相邻地形格构成板块；四塘对应四板块（或同图四区域） |
| 3 | 入口格 | 类型 `pond_entry` → `pondId`；可做成水岸/钓点外观 |
| 4 | 交互 | 点入口格 → 弹窗（塘名、占用人数）→「进入」→ `router.push('/pond/[id]')` |
| 5 | 相机 | 与塘内同套拖/缩；缩放下限保证能看见整块大陆级结构 |

### 3.4 规则

- 每塘仍 **最多 20 人 / 20 spot**（`MAX_POND_USERS` 不变）  
- 服务端继续只校验 `spotId` 存在与占位，**不读**格坐标  
- 改 `shared/ponds.ts` 的 `x/y` 或新增 grid 配置均可；**无 DB 迁移**

## 5. 验收标准

### FEAT-SCENE-ISO-1

- [x] 塘内为等距色块网格；蓝色水团不规则；岸边恰有 20 个钓位格且 id 与现网一致  
- [x] 可拖拽平移、可缩放；角色锚在钓位格上  
- [x] 连本地/现服完整钓一条鱼入库（Socket 闭环）  
- [x] 四塘在色板或水形上可辨  

### FEAT-SCENE-ISO-2

- [x] 世界地图为等距网格 + 陆地板块；可拖、可缩  
- [x] 点击入口格 → 弹窗 → 进入对应塘  
- [x] 大地图有视口裁剪或等价性能手段（不卡死常见桌面 Web）  
- [x] 未在世界地图铺 80 个可坐钓位（符合非目标）

## 6. 风险与依赖

| 风险 | 缓解 |
|------|------|
| Web 上千格卡顿 | culling；首期限制逻辑图尺寸 |
| 手势与页面滚动冲突 | 场景容器 `overflow:hidden` + 独占手势 |
| 与 Unity 文档重叠 | 本 FEAT 为 RN；UNITY-P3 仍已定稿排队，不互相阻塞 |
| 20 岸格生成不准 | 手写四塘 grid JSON 优先于纯随机 |

**实现顺序**：ISO-1 → 抽出相机/math → ISO-2。
