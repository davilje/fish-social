## 4. 流程根因（为何反复调 + 曾有多个 Bake）

1. **Create ≠ 填布局**：多数 Generate 只做空壳，Populate/`BuildEditorLayout` 另一步。  
2. **无统一注册表**：每面板手写 Create / Populate / NeedsLayoutBootstrap 三处 switch。  
3. **管理器不稳时加顶栏 Bake**：绕过两步流程，入口分裂。  
4. **一键更新不重建布局**：只保存 Prefab Mode 修改。

## 5. 目标口径（本迭代）

1. 壳层 + 产品菜单 + 商店卡 + 弹层铬 → Prefab。  
2. Prefab 管理：**创建 = 生成结构 + 灌布局一步完成**；禁止再加单面板 Bake 菜单。  
3. 新 UI：必须登记 Catalog，并同时产出 Prefab（见同目录流程说明）。
