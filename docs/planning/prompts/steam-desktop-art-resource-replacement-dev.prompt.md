# STEAM-DESKTOP-ART-01：桌面宠物与鱼塘视觉资源替换

请作为美术/资源 Agent，为 Fish Social 的 Unity 桌面宠物版本交付一套可替换的基础视觉资源。

## 产品范围

- 2D 桌面宠物猫咪。
- 2D 鱼塘环境、水面和钓位。
- 自己和同塘玩家可复用的宠物表现资源。
- 不要求为每个菜单、弹窗建立独立美术需求。

## 优先交付

1. 猫咪主视觉：默认姿态、钓鱼姿态、等待/通知状态。
2. 鱼塘环境：背景、水面、岸边、钓位和基础层级规范。
3. 玩家宠物表现：颜色/标识差异、昵称标签和基础状态标识。
4. 基础 UI 资源：可选图标、字体和色板；程序暂时使用通用 UGUI 的菜单和弹窗样式。

## 交付要求

- 资源清单、文件命名、尺寸、锚点和导入设置。
- 需要动画时提供状态列表、帧率和循环规则。
- 说明资源对应的 Unity Prefab/组件接口。
- 资源替换不得要求重写业务脚本。
- 优先提供可直接放入 `fish-social-unity/Assets/` 的资源或明确的接入说明。

## 不做

- 不修改 Unity 业务脚本、Node、Socket 或数据契约。
- 不为 `07A～07F` 各自创建一套独立 UI 美术任务。
- 不把菜单/弹窗的完整视觉精修作为当前阻塞条件。

## 验收

- 猫咪和鱼塘视觉资源可在 Unity 中替换占位资源。
- 自己和同塘玩家可以复用同一套宠物资源规范。
- 资源清单、命名和导入说明完整。
