## 实现要点

### PostCard 操作栏

```text
[❤️ n]  [💬 m]
```

- 点赞乐观更新 + 失败回滚  
- 💬 展开评论区（列表 + 输入 + 发送）；P1 删除入口  
- 列表字段使用 `likeCount` / `commentCount` / `likedByMe`

### 排行榜 Tab

- `social.tsx` 增加 Tab「排行榜」  
- `LeaderboardPanel`：子 Tab + 列表 + 前三样式 + 当前用户高亮  
- 点击行 → 已有 `UserProfileModal`  
- `my-rank` 展示在列表下方或顶栏

### API

经现有 `api()` 助手带 JWT；不要把 playerId 塞进 like/comment body。
