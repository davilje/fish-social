# Steam UI 美术资源任务线

请作为 UI/美术 Agent，按 `docs/planning/specs/Steam桌面宠物UI需求拆分.md` 产出以下美术 UI 项的资源和规范：

- `STEAM-UI-ART-01`：桌面宠物主视图视觉资源
- `STEAM-UI-ART-02`：鱼塘场景与 HUD 视觉资源
- `STEAM-UI-ART-03`：同塘玩家宠物、昵称标签和状态动画
- `STEAM-UI-ART-04`：右键菜单布局、图标和交互态
- `STEAM-UI-ART-05`：统一弹窗框架、标题栏、按钮和遮罩
- `STEAM-UI-ART-06`：好友/聊天、背包、图鉴、设置的页面视觉
- `STEAM-UI-ART-07`：通知、托盘图标、连接和错误状态视觉

每项交付：

- 视觉规范或设计说明
- 资源清单、尺寸、命名和导入要求
- 状态变体：默认、悬停、按下、禁用、错误、空状态
- 对应 Unity Prefab/组件的接入说明

美术 Agent 不修改 Unity 业务脚本、Node、Socket 或数据契约。优先保证 `ART-01/02` 原型资源先交付，供程序 UI 先完成方向验收；正式资源替换不应要求重写业务逻辑。
