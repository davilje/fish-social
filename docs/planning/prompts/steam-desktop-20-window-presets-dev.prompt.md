## 范围

- 登录窗口和主壳窗口的默认客户区都是 1920×1080。
- 设置面板只允许 1280×720、1600×900、1920×1080、2560×1440。
- 禁止拖拽边框得到任意分辨率；旧的自由尺寸存档不沿用。
- 无边框、全屏保留。

## 不要改

- Overlay 画布 `960×560`。
- 登录卡片 `LoginRoot` 的 480×320。
- 主界面内容参考分辨率 1672×941。
- `mobile/`、`server/`、`shared/`。

## 验收

对照 spec §4。用户确认前保持规格状态为 **已确认**，不要改成已实现。
