# STEAM-DESKTOP-22I v3 听感修订与验证

> 历史记录：当前已采用 v5 配乐与 v3 音效，v1–v4 旧音频已删除，旧试听入口转至 v5。本文原始测试事实保留，资源清单与许可归档见 [retired](audio-22i-retired/README.md)，当前状态见 [采用及清理报告](2026-10-24-audio-22i-adoption.md)。

日期：2026-10-24；本轮开始基线 `fb6ce820`。用户指出按钮短促像截断、整体偏轻，钢琴旋律催眠，水声杂音和重击不适。本轮替换离线音频和试听，沿用已实现的 Unity 统一播放器／WPF marker／事件身份与四短音仲裁。并行 22H 源码、纹理及文档修改不计入本报告。

## 修改与测量

| 项目 | v3 结果 |
|---|---|
| 按钮音 | 145–540ms；短 click 从85/90ms改为245/260ms；49–120ms平滑尾音，7ms柔和起音 |
| 按钮响度 | 相同 cue 增益下有效事件 RMS 比 v2 提高 4.582–7.267dB；只用线性增益和滤波，无强压缩 |
| 水声 | 28 条分档/物体水声及脱钩声改用轻柔实录；源事件不重叠、不变调；170–3900Hz滤波，平滑底噪削减最多6dB，无硬门限和饱和压缩 |
| 水声峰值 | 29 条均低于 v2；S/M/L/XL 素材真峰值目标 .125/.14/.155/.17，以运动内容和时长区分，不用沉重冲击制造大鱼感 |
| 音乐 | 原创《阳光落在鱼塘》；86 BPM、G大调6/add9色彩、32小节A/B/C/A′；真实尼龙吉他两个声部，无钢琴、铃音或重鼓点 |
| 完整循环 | 89.302336秒；PCM首尾左右声道分别相等，4×过采样真峰值 .11601008 |
| 配器候选 | 同旋律前8小节、各22.325578秒；A为正式吉他，B加入真实大提琴，供比较 |
| 内存 | 46条单声道短音解码3,383,056字节，低于4MiB |
| 最坏混音 | 100%音量、不计duck，UI＋2钓鱼＋猫叫＋音乐各声部最大绝对峰值相加，4×估算上界 −1.494dBTP |

有效事件 RMS 使用绝对值超过各片段峰值2.5%的样本，供同操作对照；它不是主观响度评分。上界计算保守覆盖不同相位叠加，不是声卡回录。音乐未使用自动审美判断来代替听感。最新反馈取代 v2 的60–76 BPM制作初值和水声强制增响目标。

## 待验收与边界

耳机／普通扬声器的主观听感、Windows至少30次实际画声同步采样仍待验收。所有可响接触继续由实际动画marker决定，未产生合格接触时不伪造水声。本次调整不等于修复或证明Windows端到端延迟。三条猫声沿用v2，第一条仍如来源声明为人声模仿猫叫。

## 复现

```sh
python tools/audio/compose_sunlight_v3.py --sources <source-cache>
python tools/audio/build_desktop_audio_v3.py --sources <source-cache>
python tools/audio/verify_desktop_audio.py
python tools/audio/analyze_desktop_audio_v3.py
PLAYWRIGHT_MODULE="/path/to/node_modules/playwright" CHROME_PATH="/path/to/chrome" node docs/art/audio-22i/v3/preview.test.mjs
```

Python依赖numpy/scipy/soundfile，下载只发生在缺少缓存时并核验hash。浏览器检查需Playwright和仓库根目录HTTP服务，默认端口8891。`preview.test.mjs`同时执行浏览器内策略断言和实际资源播放；证据保存在上述JSON。若仓库没有安装Playwright，须按示例显式提供模块和浏览器路径；本机使用Codex bundled runtime及系统Chrome。不带环境变量的裸命令会报缺少Playwright，不是音频检查失败。旧v1/v2生产脚本拒绝覆盖更新版本。
