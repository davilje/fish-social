# BUG-59 手账翻页、标签与排行榜

对照 `docs/设计/界面/原型/手账/`。只改 `fish-social-unity/` 与本需求文档。不要改服务端榜单。

## 已合并的 7 条

1. 相册翻页和回忆便签要重播；图鉴、展示柜、成就切页后中央贴纸要重播。空展示格的底板也要入场。
2. 背包、道具、商店、成就、世界地图、列表选塘、排行榜、个人资料的右侧详情用同一套拍立得出场。选塘是换一项才播，不是同一项才播。
3. 相册卡片三行：鱼名 · 体长、稀有或值得记下、`M月d日 · 鱼塘名`。日期和鱼塘用真实 `eventAt` / `pondName`。
4. 五角星用品质画 `★`，芯片用已有 `surfaces/category-chip`。不是缺图。
5. 右上角滑入通知在便签图缺失时仍有纸底。
6. 排行榜：前三名左上角名次和选中胶带在头像之上；排名栏只显示尺寸或重量，字号 22；每周钓王按体长换算重量，不再写金币；名单有竖向滚动条。
7. 动态：公开是绿色圆角标签，鱼获底是暖色块，鱼塘用中文名，体长旁是五角星，点赞评论用 quiet 按钮；留言打开时揭示。
