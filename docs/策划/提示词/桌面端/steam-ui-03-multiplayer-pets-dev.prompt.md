# STEAM-UI-03：同塘玩家宠物表现

在 `fish-social-unity/` 内实现同塘其他玩家的宠物和状态表现。

范围：
- 处理 `pond_user_joined`、`pond_user_left`、`pond_user_updated`。
- 显示其他玩家宠物、昵称和基础钓鱼状态。
- 玩家离开时清理对象，重复事件不得重复生成对象。

边界：
- 所有多人状态必须来自服务端快照/Socket。
- 不伪造在线玩家，不修改 Lobby、Node 或鱼塘权威逻辑。

验收：
- 两个玩家进入同塘后能互相看到宠物。
- 进出场和状态变化正确同步。
- 重连后无残留玩家对象。
