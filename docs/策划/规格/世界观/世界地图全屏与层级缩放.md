## 1. 背景与目标



### 1.1 背景



| 问题 | 说明 |

|------|------|

| 缩放异常 | 相机 `scale` / 视口 layout / 绘制缓冲（若 Canvas）坐标系不一致，导致缩放中心偏移、HUD 与地块错位 |

| 区域不一致 | 地图外还有 margin、页脚文案、「钓鱼世界」叠字，地图未占满主内容区 |

| 层级混乱 | 顶栏、地图 HUD、场景未严格分层；塘名可能画进顶栏区域 |



### 1.2 目标



1. **排查并修复缩放**：滚轮/捏合以视口客户区为坐标；HUD 投影与场景同一套 `translate/scale`；Web 注意 DPR/与 layout 宽高一致  

2. **地图全屏（主内容区）**：地图舞台占满顶栏以下全部空间（去掉多余 margin/页脚挤占；页脚提示可并入顶栏旁或角标）  

3. **严格三层（z 从高到低）**：  

   - **L0 顶栏导航**（`Fish Social`、头像、背包/商店等）— 永远最上层，可点  

   - **L1 地图 HUD**（塘名、人数等）— 在顶栏之下；**不得压住顶栏**（裁剪或 `top` 从顶栏底边起算）  

   - **L2 地图场景**（Tile/Canvas + 相机）— 最底，全屏铺满 L1 同区域  

4. 塘内若同类「画布/UI 区不一致」一并按同原则处理（可选，不阻塞世界地图验收）  



### 1.3 非目标



- 改 20 塘数据/玩法权威  

- 重做顶栏按钮集合  

- Unity  



---



## 2. 层级结构（定案）



```text

AppScreen

├─ L0 Header（position 顶栏，zIndex 最高，pointerEvents auto）

├─ MapStage（flex:1，顶栏以下全屏）

│  ├─ L2 Scene（TileCamera + 地图绘制，absoluteFill）

│  └─ L1 Hud（absoluteFill，pointerEvents none；内容避开顶栏安全区）

└─ Modals（高于 L0）

```



- 首页内嵌「🗺️ 钓鱼世界」大标题若与顶栏重复，删除或并入顶栏副标题  

- 底栏「拖拽浏览…」改为舞台内角提示或顶栏副文案，避免再占高度  



---



## 3. 缩放修复要点



| 项 | 要求 |

|----|------|

| 视口尺寸 | `onLayout` 宽高 = 命中与投影用的 viewport；Canvas 缓冲与 CSS/layout 比例一致（含 DPR） |

| 缩放轴心 | 滚轮/捏合 pivot 用视口内坐标，与 `applyZoom` 一致 |

| HUD | `screen = world * scale + translate`，原点与 L2 视口左上对齐；L1 相对 MapStage，**不是**相对含顶栏的全屏 |

| 初始 scale | 全屏后重算 `panable` fit，避免仍按旧小视口 |



---



## 4. 验收标准



- [x] 地图占满顶栏以下可视区（无明显左右大 margin / 底栏永久占高）  

- [x] 顶栏始终在最上层，塘名/人数 HUD **不会画到顶栏矩形内**  

- [x] 滚轮/捏合缩放中心与手感正确；缩放后点击塘区与 HUD 位置仍对齐地块  

- [x] 拖拽平移正常；进塘弹窗仍可用  

- [x] 层级：L0 > L1 > L2 文档与实现一致
