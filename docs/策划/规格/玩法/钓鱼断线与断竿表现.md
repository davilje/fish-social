本次交付为设计与开发交接，游戏功能尚未实现。首版在现有钓鱼结果上补充两种明确表现：鱼线被鱼扯断导致逃鱼；超规格成功次数达到上限后，钓竿折断，当次鱼获保留。

## 1. 已有规则与新增范围

当前 `shared/gearRules.ts` 的 `isOversizeForRod` 按 `sizeM > breakSizeM` 判断超规格，`shouldDestroyRod` 按累计成功次数判断损坏。`server/src/inventory.ts` 在鱼获入包后调用 `noteRodOversizeLanding`；`server/src/gear.ts` 销毁旧竿并优先装备剩余竿。现有 `rod_broke` 是装备结果，尚不足以驱动与当次鱼获关联的折断动作。

| 场景 | 判定与结果 | 装备影响 | 下一步 |
|------|------------|----------|--------|
| 普通脱钩 | 延用现有自然失败 | 延用已有渔具耐久结算 | 按现有规则续钓 |
| 鱼线被扯断 | 自然脱钩中的一部分改为断线表现；该鱼逃走 | 竿保留，基础线自动补好；已有失败耐久只扣一次 | 断线收尾后续钓 |
| 钓竿折断 | 成功钓上超规格鱼使累计次数达到上限 | 当前竿销毁，不能修；当次鱼获保留 | 有备用竿则装备后续钓；无竿则停止并显示商店入口 |

首版不增加线材购买、独立鱼线耐久、拉力 QTE 或新的随机断竿概率。线的复位是表现收尾，不产生额外金币消耗。教学关不展示断线与断竿，沿用教学脚本。

## 2. 断线触发规则

### 2.1 先决定结果，再选失败表现

1. 服务端先走已有咬钩、自然脱钩判定。
2. 只有已判为**自然脱钩**的鱼才可选 `line_snap`；成功结果不能转为失败。
3. 打瞌睡、主动停止、离塘、切塘、连接中断、巡警、待领取过期等导致的结束各走原原因，不能伪装成鱼把线拉断。
4. 在当次咬钩锁定鱼体长和钓竿配置，失败表现只抽一次并持久关联该次结果；重连、重播和多端不重新抽取。

建议首版参数如下，属于表现分配参数，不是总脱钩概率：

```text
r = 当次锁定体长 sizeM / 当次锁定钓竿 breakSizeM
p(断线表现 | 自然脱钩) = clamp(0.30 × (r - 1), 0, 0.60)
```

钓竿或正数阈值缺失时取 0。使用独立、稳定的表现随机种子，不消耗现有生态与钓获随机序列。以入门竿阈值 0.45m 为例：

| 鱼体长 | 比例 r | 自然脱钩后显示断线的比例 |
|--------|--------|--------------------------|
| ≤0.45m | ≤1 | 0% |
| 0.675m | 1.5 | 15% |
| 0.90m | 2 | 30% |
| ≥1.35m | ≥3 | 60%（封顶） |

若某情形原本自然脱钩率为 20%，表现分配为 30%，则总失败率仍为 20%，其中断线 6%、普通脱钩 14%。这是演算示例，不代表该体长现行脱钩率。

### 2.2 动作与反馈

从权威失败进入收尾时起，断线动作总长建议 **900ms**，覆盖原失败收尾中的对应动作；不得等整段上钩计时结束后再追加一次失败判定。

| 时间 | 鱼线、钓竿与角色 | 水面与声音 |
|------|----------------|------------|
| 0–180ms | 竿尖受力下压、线逐渐拉直，猫身体轻向前；竿根与握点固定 | 入水点一组原有挣扎波纹；一次轻微绷线声 |
| 180–240ms | 水面附近的子线断开；断裂前保持完整线，断裂后明确出现缺口 | 断裂 marker 只触发一次短促“啪”；提示“鱼线被扯断，鱼逃走了” |
| 240–500ms | 靠竿一段线向竿尖回弹并下垂；远端子线随鱼沉入水中 | 鱼在水下则继续隐藏；无真实出水不生成出水水花 |
| 500–900ms | 猫回稳并收回空线；下一次抛竿前恢复完整线与浮漂 | 波纹自然消失，续钓或回到坐姿 |

竿侧断线端最多回弹 12 个标准逻辑像素，竿尖位移最多 6px，角色倾斜最多 4°（以 128px 槽位为基准）。浮漂随竿侧回收；被鱼带走的仅为短子线，不遗留永久漂浮物。断裂一帧起旧的完整鱼线必须隐藏，防止新旧鱼线重叠。视觉参数为首版试调值，待统一预览确认。

## 3. 断竿规则与表现

### 3.1 继续使用现行成功累计

仅**成功领取/自动结算入包**的超规格鱼增加一次计数。`sizeM == breakSizeM` 不增加。第 N 次成功使 `oversizeLandings >= breakMaxLandings` 时折断；脱钩和断线均不增加这个计数。当前配置举例：

| 竿 | 超规格阈值（严格大于） | 累计成功上限 |
|----|------------------------|--------------|
| 竹制手竿 | 0.45m | 3 次 |
| 台钓碳素竿 | 0.80m | 5 次 |
| 溪流竿 | 0.55m | 4 次 |
| 矶钓竿 | 1.20m | 5 次 |
| 海竿 | 1.50m | 6 次 |
| 路亚竿 | 1.00m | 5 次 |
| 重型路亚竿 | 2.50m | 8 次 |
| 巨物竿 | 4.00m | 10 次 |

以上抄自 `shared/generated/game-data/rods.json`，实施时仍以配置为准，不在动作脚本另写一份门槛。当前“按 rodId 计数”的装备模型继续使用。

### 3.2 先保证鱼落袋，再表现折断

折断动作安排在成功鱼已离水、鱼获领取确认后，接在成功收杆与持鱼之间，总长建议 **1,100ms**。若服务端已销毁旧竿并自动装备备用竿，表现层仍用锁定的旧竿播完折断，再切换备用竿。

| 时间 | 表现 |
|------|------|
| 0–250ms | 猫已控制住鱼，旧竿出现最后一次弯曲，接合处轻颤；鱼保持成功姿态 |
| 250ms | 在距竿根约 65% 的可配置断点折开；一次“咔”声，不能套用断线声 |
| 250–650ms | 上段折向下方并回落，靠近角色的一小段线松垂；鱼保持持鱼接触点，不随断竿飞走 |
| 650–1,100ms | 猫短暂看向断竿，旧竿与断片淡出；接成功展示或备用竿坐姿 |

提示：“钓竿折断了，这条鱼已收进背包。”随后按真实装备状态显示“已换上备用钓竿”或“暂无可用钓竿，去商店看看”。一次鱼获只展示一次完整折断提示，不反复弹窗。装备详情显示“超规格成功累计 n/N”；当 n=N−1 时提示“再成功钓起 1 条超规格鱼后会损坏”，没有实际裂纹状态时不永久画裂痕。

折断仅作用于道具层；角色、鱼、椅子、浮漂各自独立。断片使用钓竿的分段资源或遮罩，不撕裂含鱼线的整张 PNG。不同竿长的断点按自己的 rig 配置，不能把全部竿统一切在同一屏幕坐标。

## 4. 权威结果、去重与中断

实施时需扩展结果表现契约，以下为**拟新增字段**，不是当前已存在的接口：

- 逃鱼结果：保留原有 `outcome=escape` / `reason=escaped`，增添 `failureVisual=unhook|line_snap`、`resultId`、`rodIdAtHook`、`visualSeed`。其业务结果仍只结算一次逃鱼。
- 成功结果：保留 `catchId/resultId`，附带 `rodBreak={rodId, oversizeLandings, limit}` 或空值；领取结算返回明确结果供表现消费，不能从装备列表少了一把竿推断。
- `rodIdAtHook` 与 `sizeMAtHook` 作为当次上下文锁定；同一上钩过程禁止换装备，或将换装排到本轮结束。实施时统一选择前者：上钩/收尾阶段拒绝换装并给出提示，避免旧竿表现和新竿计数不一致。
- 断线以 `(resultId,line_snap)`、断竿以 `(resultId,rod_break)` 去重；一次结果可为“成功且断竿”，不能同时为“逃鱼断线且成功断竿”。

业务结算由服务端完成，不等待动画 marker。断线只走现有逃鱼的成长/耐久结算一次；断竿只走现有成功鱼获与销毁一次。断线不入包、不发成功经验、不广播成功鱼获，鱼按现有逃鱼规则回到生态。自动回鱼、背包容量和领取失败必须走现有事务结果；领取未成功不扣断竿成功次数。

正常观看时等当前收尾结束再开始下一次抛竿；隐藏窗口、重连快照、切塘、离塘和角色销毁不补播历史断裂及声音。旧动作硬取消后销毁线段、断片和时间任务，装备与鱼获保留权威结果。其他玩家只消费服务端允许公开的同一结果，不自行按体长抽断线，也不读取隐藏鱼情。

实施中若增添/调整埋点或 `fishing_metrics` 字段，必须同步 `shared/metrics-schema.ts`、埋点表生成器及正式/同步副本；本次设计不修改埋点实现。现有 `rod_broke` 业务事件只记一次，不能每个动画观察者各记一次。

## 5. 实施范围与验收标准

依赖先打通权威结果，再制作道具断裂层、动画 marker 和本地化文案，最后接 Unity / WPF。新音效先进入总预览试听，采用后再进入正式音频配置。新增效果预览统一纳入根目录 `现行预览.html` 的钓鱼分类，保留已有路由与选择记录。

- [ ] 自然脱钩、断线、瞌睡、主动停止、连接中断分别有确定结果；同随机种子的成功数与总失败数不变。
- [ ] r≤1、r=1.5/2/3、缺配置的表现分配符合 §2；重连不重抽。
- [ ] 断线瞬间完整线消失，竿保持完整；断竿瞬间分段明确，鱼获保留。
- [ ] 超规格阈值相等不计数，第 N−1/N 次行为正确；断线不增加成功计数。
- [ ] 当次旧竿固定；无竿停止、有备用竿恢复；拒绝上钩过程中换装。
- [ ] 重复结果、重复领取、多人观察、快照恢复不重复发奖、销毁、成长、扣耐久或播声。
- [ ] 断线/断竿中隐藏、离塘、切塘、换角色、关闭后，无孤立鱼线、断片或旧动作复活。
- [ ] 96/128/192px 槽位、十一角色、低特效和 Windows 实机通过视觉验收；低特效也保留断裂与回弹的基本可读性。
- [ ] 与 FISH-SCALE-01 的最小/最大鱼联测，嘴部锚点、持鱼接触与水面裁剪保持正确。
