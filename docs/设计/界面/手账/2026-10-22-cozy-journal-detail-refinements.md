# 手账 UI：本轮缺口修复与社交分区

日期：2026-10-22。范围：用户在认可修复版之后补充的八类具体缺口。沿用 `e0799785` 的正式 `DesktopShellUi → PanelRouter`，本轮没有启用 JournalV2。

## 本轮实现

| 用户反馈 | 正式实现 |
| --- | --- |
| 排行榜前三名渐变底图缺失 | 从原版 `pages.css` 导出金、银、铜三张渐变底板及三张名次标签。保留透明边距、白描边和固定原始尺寸，选中、悬停、修复预制体后仍保留对应底图。 |
| 个人资料经验条被拉伸 | 保留切片圆端，以实际宽度表示进度，不再用横向 Filled 拉伸整张图片。数值使用等级配置；当前样例 Lv.7 的目标是 650，原网页的 500 仅为演示数值。 |
| 动态文字与动效错位 | 17px 正文按真实字体指标换算为 28.9px 行高；长文推动鱼获摘要和底部操作区。标题、评论数量、作者与正文分别渲染；列表数据返回后启动入场，空数据与错误结束透明状态。留言按钮图文整体居中。 |
| 图鉴、展示柜、成就标签与描述不符 | 鱼名、品质/捕获信息、槽位标签分离；图鉴记录以标签和值两列排列。恢复独立奶油/渐变插画底与对应间距。成就使用真实 `iconKey`，未解锁徽章灰阶显示。 |
| 红色已收录章错位 | 使用原圆环蒙版着红色，围绕中心旋转，按网页右上外露的位置放置；只在已收录鱼种显示。胶带仅在选中卡片显示。 |
| 好友申请、聊天、通知混用 | 同一手账页内提供五个独立目的地：我的钓友、好友申请、私信、鱼塘聊天、消息通知。铃铛直接进入通知；好友申请接受/忽略调用原 API，阅读通知只标记已读；私信指定接收者并与公共塘聊分开。 |
| 选塘缺标签、文案拥挤 | 补分类色点、水域、收费、准入和真实鱼种摘要；准入文字置于徽章底图之后绘制。长说明缩为明确短标签，左栏说明放在清筛与地图入口之间。 |
| 世界地图左栏冲突、入塘字体错位 | 图例、两行操作说明、列表选塘与重置视图分区；22px 入塘文案和小鱼按真实文字宽度整体居中，忙碌、错误或准入文案变化后重新测量。 |

社交通知由本次账号登录期间的真实 socket 与通知服务事件生成，界面标注“本次登录收到的通知”。没有伪造历史通知接口。关闭社交页继续接收事件，切换账号清空旧账号的收件箱；接受申请、打开私信、阅读通知各自独立。

保留正式业务的八个展示位、真实品质字典、鱼种目录和收费/等级准入；不把原型的三张演示卡、示例星级或演示经验阈值写成正式规则。

正式资源保存在 `fish-social-unity/Assets/Resources/Desktop/Prefabs`，新增插画与徽章由原生 uGUI 图形绘制，渐变底图在 `Theme/Cozy/手账`。

- Unity 菜单 `Fish Social → Cozy Redesign → Apply Approved Detail Refinements`：只烘焙本轮涉及的预制体。
- `Render Saved Prefab Previews`：通过正式呈现接口绑定示例 DTO，导出 21 个页面/状态。静态截图统一停在动画最终态；不会用入场首帧的低透明度冒充最终结果。

## 本轮验证结果

- Unity 2021.3.29f1c1 全套 EditMode：**468 通过、0 失败、0 跳过**。覆盖渐变底板在选中/悬停/修复后的保持、名次文字绘制顺序、经验条端点、收藏卡片与印章、真实标签、好友申请处理、通知阅读、私信分区及重复布局。
- 正式预制体构建守卫：**PASS**。
- 美术清单检查：**134 个 UI 资源**，其中 **94 个参考对齐资源**，同时校验角色姿势、鱼塘图及参考状态，结果通过。
- 正式预制体实际渲染：**21 个页面/状态**，逐张复核本轮相关页面。网页静态对照 **15 组**，页签/排行榜动效采样 **11 对帧**。

最终结果及每张 Unity PNG 的源哈希保存在 [evidence.json](../../../美术/手账/production/evidence.json)。本轮执行中发现过准入标签遮挡、社交列表堆叠、收藏插画底被覆盖及名次底牌遮住文字，均已修正后重新烘焙、截图和回归。

截图使用编辑器示例数据，不代表 Steam 真账号和 Windows 平台验收。自动测试和采样帧也不等同于全交互逐像素验收；Windows 构建、联机、DPI 与实机动效性能继续保留待办。
