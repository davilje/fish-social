# 小屋动作首版原画预览

2026-10-24。按最新优先级，橘猫首版已接入 Unity 正式小屋，当前仍待美术验收。大肥鱼不在本轮范围。其余八种猫保持待制作，在首套动作确认后扩展。

## 查看

打开上两级的 `index.html`，点击「小屋动作预览」。也可直接打开 `home-animation-review.html`。支持动作与方向切换、播放/暂停、逐帧、循环段、速度、放大、深浅背景及单帧下载。

## 本轮交付

| 内容 | 数量 |
| --- | --- |
| 橘猫打滚 | 16 帧 |
| 橘猫左右四足行走 | 每方向 12 帧 |
| 橘猫左右起步、停步 | 每方向每动作 4 帧 |
| 橘猫左右进食 | 每方向 14 帧，循环段 `[3,11)` |
| 公共倒粮 | 12 帧时间表，末帧为空，量勺退出 |
| 公共粮食累积层 | 12 帧时间表，空→少量→三分之一→三分之二→满；相邻保持帧在清单中标注 `hold` |
| 公共粮食状态 | 5 个逻辑状态，4 张 PNG；吃完复用空层 |

共有 112 张独立运行 PNG，其中角色 84 张。粮层保持帧是倒粮期间的离散状态保持，不是 12 个不同的粮堆原画。画布分别为 512×384、512×512、480×400、270×88。

## 制作来源与导出

- 使用内置 imagegen，根据现有小屋橘猫站姿、坐姿及食盆参考绘制。完整提示词保存在 `prompts/`，生成原稿在 `masters/`。
- `jobs.json`、`shared-jobs.json` 保存制作任务；`build.mjs` 只切分、等比缩小、平移装入透明画布和写清单，不用代码重画角色或生成姿势。
- 默认使用 0.62 倍像素缩小；进食批次另按 `scale-calibration.json` 中的人工头宽标尺校准，每批所有帧保持同一倍率。未按每帧包围盒自动适配尺寸，播放器也不动态缩放。原稿行间分界按透明间隔寻找，避免固定网格裁掉耳尖或脚掌。
- 当前平移以图像重心与底部对齐审稿画布；这只是预览注册，尚不能代替四足接触点的正式标定。`export-audit.json` 记录每帧来源、裁切、倍率与偏移。
- `*-replacement.png` 优先于同名旧原稿。进食 04/08 批次已重绘为低头循环，12 批次采用重绘图的前两格。原始 12 批次及 `*-clean.png` 因光晕问题未被引用，只留作过程记录。
- `prompts/shared-food-fill.txt` 对应的额外粮堆试绘带光晕，未选入素材。当前累积层使用已选中的 `shared-bowl-food-states.png` 原稿各粮量状态，不使用该试绘。
- 部分原稿单格原生分辨率不足规格要求的运行画布 2 倍边长。本轮未放大这些文件冒充高清母版；高清生产稿仍是后续质量要求。
- `data.js` 支持本地 `file://` 加载；`manifest.json` 是同一清单的 JSON 版。

这些是已经接入、尚待美术验收的首版原画。仍需验收跨原稿批次的头身比例、花纹和末首帧衔接，尤其打滚翻身和进食抬头。源清单的逐帧嘴部与脚掌接触点暂记 `null` / 空列表；Unity 另使用当前画稿的左右嘴部参考坐标合成，不能视为完成逐帧标定。

网页展示的固定注册点是放置参考；Unity 已接通倒粮、前往食盆、进食和返回的交互链，食盆采用独立前景遮挡。合成效果仍待用户验收。未对未完成的猫种冒用橘猫。运行资源由 `scripts/art/export-home-room-animation.mjs` 导出，原生实现见 `CozyHomeRoom.Animation.cs`。

## 复现与检查

使用 Node.js 和 sharp；如 sharp 不在默认依赖路径，可通过 `SHARP_MODULE` 指向其安装目录。

```sh
node build.mjs
node verify.mjs
```

检查涵盖帧数、RGBA 与画布、角色边界、粮层不覆盖右半水碗、固定缩放和循环区间。`verification.json` 是结果，`review/` 是按帧号从左到右、从上到下排列的审稿总览。技术检查通过不代表美术验收通过。
