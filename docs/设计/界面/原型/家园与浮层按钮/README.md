左右移动沿用已认可的 44×44 圆钮；底部按钮固定显示“钓鱼、打窝、离席、回家”，保持原来的 88×36 纸质按钮样式。离席使用座椅与向外箭头，回家使用门与向外箭头。与家园共用原手账纸面，箭头、座椅、打窝图标统一为暖棕笔迹，投料强调使用深橘棕色，键盘焦点沿用淡紫色。沿用原指令、禁用规则与业务流程；钓鱼按钮的收杆操作和时长上限说明放入悬停提示。
