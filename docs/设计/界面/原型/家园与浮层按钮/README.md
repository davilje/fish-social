# 家园与 Overlay 交互按钮设计

日期：2026-10-31。本目录是可点击设计提案，未修改 Unity 与 WPF 运行逻辑。

修改范围仅为五个家园入口（钓竿、鱼缸、猫窝、猫碗、出门），以及已确认的 Overlay 左右移动、离开和打窝控件。家园预览直接嵌入现有手账主界面，移除提案中简化的顶部栏和底部导航示意；玩家卡片、钓鱼世界、货币、通知、设置和七个底部导航的样式与回调均使用原界面。只隐藏原“我的钓具”和“鱼缸 · 展示柜”文字入口，由相应图标替代。打开手账时隐藏图标，关闭后恢复。

预览入口：仓库根 `现行预览.html#home-controls` 与 `#overlay-controls`。手账正式页面汇总中也新增“家园与 Overlay 交互按钮设计”入口。

## 家园

使用当前 `home-room/room-base.png`，图形采用可直接复用的 SVG 线描，保持 1.65 px 笔触与圆头。按用户反馈，五个家园按钮收为 48×48 px 的图标小标签，默认不显示文字；奶油纸色底搭配鼠尾草绿图标，房门保留陶土橙。悬停或键盘聚焦显示用途提示，所有标签具有随状态更新的无障碍名称。

| 目标 | 悬停提示 | 图标 | 演示反馈 |
| --- | --- | --- | --- |
| 鱼竿 | 查看钓竿 | 钓竿与鱼钩 | 打开装备入口说明 |
| 鱼缸 | 查看鱼缸 | 鱼缸与鱼 | 打开展示柜入口说明 |
| 猫窝 | 去睡觉 | 月亮与 Z | 休息后改为轻轻唤醒 |
| 猫碗 | 开饭啦 | 碗与粮粒 | 吃饭中暂时禁用，结束恢复 |
| 房门 | 出门钓鱼 | 房门与向外箭头 | 切换钓鱼场景示意 |

家具标签按 1672×941 设计坐标展示，靠近对应家具边缘。短尾指向家具，悬停时底色加暖并显示家具柔光。睡眠用绿色小圆点、进食用暖黄色小圆点提示，提示文字同步更新。状态对照中的五个家园按钮也改为纯图标。正式接入时标签跟随家具移动；拖动和打开手账时暂隐。现有家具拖动未在此设计页重做。Overlay 方案保持用户已认可版本。

## Overlay

左右移动采用 44×44 DIP 轻量圆钮，置于两侧中线；悬停显示方向文字，视野到边界禁用。按钮状态页使用相同的圆形控件。

离开鱼塘采用 112×40 DIP 图标加文字，热区扩至 44 DIP 高。预览包含取消、确认回家两条路径；正式接入时应复用已有离塘与收竿状态规则。

打窝使用窝料袋、粮粒与水纹组合图标，与鱼钩鱼讯区分。角色旁展示 38 DIP 标记、44 DIP 热区，数量放在角标；悬停或点击展开窝料数量与剩余时间。打窝按钮表达操作，角色标记表达当前效果。

| 状态 | 外观 | 操作 |
| --- | --- | --- |
| 未打窝 | 灰色轮廓、0 | 可投放 |
| 正在打窝 | 陶土色、缺口环、点号 | 暂停重复投放 |
| 生效中 | 绿色、数量角标 | 可继续叠加 |
| 已达上限 | 绿色、50 | 禁止继续投放 |
| 已到期 | 灰色、短横线、到期文字 | 可重新投放 |

12/50、12:48 等为演示值，不定义叠加收益规则。投料缺口环只代表投料过程，数量角标代表层数。减少动效时关闭循环和位移动效。反馈不依赖颜色，详情保留状态文字。

## 2026-10-31 项目接入

已接入 Unity：`CozyHomeRoom.Actions.cs` 和 `CozyHomeActionTag.cs` 维护五个 48px 图标入口、悬停/聚焦提示与睡眠/进食圆点，`DesktopShell.prefab` 已同步；装备、展示柜、世界地图沿用现有路由。原顶部栏、底部导航及其他按钮保持原样。

猫咪直接拖动使用主界面全尺寸边界，按当前体型限制四边；自由状态置于顶部栏和导航上方以保持可抓取。自动散步、睡觉和进食保持原有动作与家具遮挡。打开功能页面、切后台或暂停会取消拖动。总预览页中同步了拖动范围，并在家园按钮页附 Unity 实际截图。

Overlay 原生控件使用独立 `CozyInteractionButton` 样式和 `CozyInteractionGlyph` 矢量图形，仅作用于左右横移、离塘和打窝。角色旁的窝料标记读取 IPC 实际层数、有效期、咬钩次数与加成，支持悬停、点击或键盘查看详情；保留原指令和边界禁用规则。预览页的 12/50 仍是演示值。

验证：Unity 家园及动画测试、保存场景截图、WPF 跨平台编译、打窝时间线回归、总预览页拖放与路由检查。Windows 窗口的实际显示仍需在 Windows 环境检查。
