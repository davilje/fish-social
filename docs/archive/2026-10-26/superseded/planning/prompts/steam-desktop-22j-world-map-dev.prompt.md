## 布局和资源

1. 沿用 1370 逻辑宽手账面板。左栏 x24/y112/w210/h496；地图 x254/y160/w710/h440，内视口 690×420；右栏 x984/y112/w362/h496，上部详情 296、间隔 12、下部固定操作 188。具体内边距和约束按 spec。
2. 左栏顶部搜索固定、中部分类／勾选滚动、底部清除／帮助固定；右栏上部照片／标签／描述滚动，下部档位／费用／进入固定，不能重叠或把按钮推出面板。
3. 正文 16/24、辅助 14/20、标题 22、按钮 18；主按钮图标＋文字整体居中，长塘名可两行。仅照片 −1.5° 轻倾斜，费用与操作保持水平。
4. 复用当前认可底图；重绘候选明确资源版本，不自动视作认可成品。底图约 2100×1400，地形柔和、水岸清楚，不烧录动态文字、价格、人数。
5. 按真实 pondId 配置归一化坐标、标签方向、区域和照片，与底图 hash 一起版本化。数量来自配置，不硬编码 20；缺位置进入列表并提示待更新，不堆到 (0,0)。
6. 浮标 30×38、命中 44×48，屏幕尺寸保持稳定；标签最多两行／132px，按选中>当前>焦点>可进入>其他避让。密集点稳定聚合，最大缩放仍重叠用选择列表。

## 交互与真实数据

1. 分类单选，与“仅看可进入”“免费”做 AND；中文名称／配置别名搜索 150ms 防抖。空态可清除，已选塘被过滤就清空选择、保留视角，隐藏塘不能继续提交。
2. 标记用图形／文字和颜色区分可进入、选中、当前、未解锁、暂闭、满员、未知。新手塘排除、巨物暂闭，遵循服务端门禁。
3. 名称、类别、解锁、档位、费用来自真实配置和权威响应；鱼种／人数／照片缺失有明确占位。禁止沿用 Web 按索引造类别费用、通用鱼种或虚构 0/20 人数。
4. 免费满足条件单次 join；收费在同一右栏先展示费用确认，再明确“确认进入”。未知本次扣款时只显示每 2 小时标准，不伪造报价。切塘、换档、费用／账号变化使确认失效。
5. 提交锁定重复操作；当前塘“返回当前鱼塘”不重复 join。超时先查会话再决定是否重试，避免重复扣费。核验已有幂等链路，仅确实缺失时补 requestId／服务端能力，不自行扣客户端余额。
6. 请求带版本，A→B 选择不让 A 回包覆盖 B；关闭／换账号丢弃旧 UI 回调。迟到成功更新会话，不强拉已关闭页面。目标快照和本人角色就绪才打开 Overlay，保持无闪屏流程。
7. cover 初始视图、缩放 100%–250%、指针为缩放中心；6px 拖动阈值防误点，滚轮按地图／左右栏分区。标记与命中共用投影，支持键盘，输入框及中文 IME 不误触地图或进塘。

## 动效与实施顺序

1. 先整理真实数据、点位、资源清单，更新 cozy-journal 可交互地图；journal-workspace 复用同一实现。提供初始、锁定、暂闭、收费确认、提交、失败、空筛选、数据缺失和超时核对的可达演示状态。
2. 地图／左栏在公共 pageContentReveal 边界出现，右栏在公共 aside 边界出现，不等网络返回才启动动画；不能给整页与子层重复淡入。
3. 选点 160ms 1→1.08→1、右栏内容淡化 120ms、切档沿用 320ms、聚合／复位 180ms、滚轮追随 120ms。拖动取消插值，减少动效最多 100ms 淡变；异步只更新内容，不重建整页。
4. 用同一配置／对照表接 Unity；列表和地图共享门禁、费用及选择状态。UI 声按 I，一次导航一个 cue，不另建播放器。
5. 新增地图／标记实际 GPU 纹理≤32MiB（含 mipmap），必要变化时才布局，不每帧全量重排。20 塘平移／缩放主线程新增 p95≤1ms 是待测目标。

## 专项验证

- 交付两个 Web 入口、Unity 变更、底图／点位／照片／描述清单、状态矩阵、逐帧对照和性能结果。
- 验证 1280×720、1600×900、1920×1080、2560×1440 以及 100%/150%/200% DPI；长名称、密集点、三栏滚动、按钮居中和命中一致。
- 验证两档费用、免费、未解锁、引导未完成、暂闭、满员、余额不足、网络失败、双击、超时重试、旧回包、关闭和换账号。
- Web／Unity 开页、右栏时机、选点、切档、关闭逐帧对照，无双刷新／整页重播／进塘背景闪回。运行对应项目检查并记录 Windows 实测，对照 J spec 逐项验收。
