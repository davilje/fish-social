## 素材说明

操作声改为真实纸张、铅笔和印章录音；短点击使用纸张动作瞬态，不把它描述成实际指腹触纸录音。抛竿为实录杆子挥动，收线为实录钓线轮。水声使用不同录音中的独立事件：小水体扰动、木棍拍水、容器水下划动、倾倒和湖面落水。它们是物理拟音，非实录鱼动作，且未对水声变调。三类 × 四档 × 两变体，再加浮漂与撒饵各两条，28 条均有独立 hash 和不重叠的源事件。

音乐使用 VCSL 最轻力度 Kawai 三角钢琴采样并做柔化；不是实际毛毡钢琴录音。B 候选使用 VSCO 2 CE 大提琴替代低音钢琴线条。曲目为本项目原创稀疏编配。全部新第三方输入为 CC0，发布无需联网。三条旧授权猫声保持波形内容，仅为混音余量降峰值，其中第一条本来就是人声模仿猫叫，来源说明保留这一事实。

## 正式接入

- Unity 独占播放：音乐 1、UI 1、钓鱼 2、猫叫 1；事件级身份检查与有界播放器替代无限 `PlayOneShot`。默认音乐 35%、音效 70%，独立偏好和后台咬钩开关。
- WPF 在完整动画帧提交后上报 marker；携带 session、actor、pond、spot、ownerEpoch、generation、action/event、source-frame／occurrence。源帧窗口和变换后接触几何均通过才允许接触音；未提交、冷解码、旧 owner、取消和快照不提前响。
- 稳定 ID 审计：基线已有结算 `catchId`，但咬钩、ACK、settled 透传不完整。本次把同一 catchId 提前到权威咬钩并一路复用，失败 resultId 复用同一尝试身份；没有增加平行随机 ID 系统。不改变概率、收益、钓鱼时间或埋点。
- 音乐 duck 为瞬时乘数，重叠取最低倍率／最晚结束；不会改写保存音量。静音消费事件，恢复不会补播。自动猫叫依赖真实确认声结束，并可被新咬钩／取消／离塘丢弃。
- 旧 D/E/F 运动、UI 版式和用户交互保留；22I 不恢复 H 撤销的收线／收获／脱钩视觉特效。

## 仍需实机／人工验收

- Windows 原生 WPF + Unity 至少 30 个事件录屏／回录，逐项填写 frame-present 与声卡 onset 时间；目标 ≤80 ms，>120 ms 必须诊断。当前宿主 macOS，尚未执行，不能填“达标”。
- 0／150／400 ms 冷解码场景已有可移植策略验证，但真实 Windows 解码、IPC 与声卡端到端延迟仍需上述录制。
- 耳机和普通扬声器分别实听纸张质感、钢琴柔和度、小水花辨识度、大小档位和循环连续性；当前为已接入候选，未宣称用户认可音色。
- 当前源动画的 hooked／effort 鱼层按已有求解器保持水下，不含真实 fish.surface／fish.slap 破面 marker；这些声音已备齐与接线，但在无合格水面接触时正确静默。Unity 兜底 hero 没有可验证水面锚点，同样不伪造接触声。后续动画提供真实接触后再联合验收，不能用定时器补假水花。

## Windows 录制表模板

保存 CSV 列：`session,actor,ownerEpoch,actionId,eventId,marker,occurrence,coldDecodeMs,framePresentedMs,audioOnsetMs,deltaMs,muted,visible,verdict`。覆盖自己正常钓鱼、打窝取消、重复包、两个相邻真实 catchId、8 人同塘、隐藏新咬钩、静音中 duck 恢复。必须从同一录制时钟提取画面实际呈现和声音起点；不能用日志发送时间替代。

## 最终工程状态

STEAM-DESKTOP-22I 标为**已实现、待实机／听感验收**，设计／完成日期均为 2026-10-24。执行 `npm run planning:master-xlsx` 生成根目录和 docs 副本的计划表／看板；本任务只编辑 22I 行，不把 H/J 顺带关闭。

正式配置普通水声 duck 持续各 cue 的实际变体时长，运行时进一步以当前 clip 长度封顶，最多 0.7 秒；咬钩固定 0.7 秒。四声部加音乐的真峰值估计采用不 duck 的更坏情况。所有窗口隐藏且没有实际短音／duck 过渡或仍有效咬钩窗口时恢复既有 5FPS；没有使全部等待阶段常驻 60FPS。

WPF 当前可响标记：cast.release、float.contact、bite.onset、真实 groundbait.contact、retrieve.start、result.presented。fish.surface／fish.slap 的现有鱼层保持水下，escape.contact 的空杆素材没有可见鱼，均静默；这些条件不是测试遗漏，不增加假接触或被 H 移除的视觉效果。

后台调度边界：完全隐藏的等待阶段仍保留既有 5FPS；新网络事件进入主线程可能等待约 200ms，随后进入短时音频工作窗口。此值是现有调度间隔推导，不是实测声卡延迟，也不声明全隐藏提示满足 ≤80ms。音量和开关保存使用既有本机 PlayerPrefs，本次未新增云端音量同步。
