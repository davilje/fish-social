# 六款猫咪形象稿 · 2026-10-24

本轮准备耄耋、美国短毛猫、布偶猫、方师傅、狗子、大开门。每个角色一张 1536×1024 PNG，含正面头像和三分之四坐姿。使用内置 image_gen 独立绘制，原始输出完整复制到 sheets/，保留透明通道；没有程序改色或 SVG 代替绘制。

这是外观设计稿，不是完整可运行皮肤。当前没有修改角色注册表、已有猫咪素材、鱼竿层、动作 manifest 或 Unity 预制体。形象确定后仍需逐动作绘制、脚锚与握点配准、四层遮挡制作以及花纹连续性验收，不应直接将本图集当作钓鱼动画。

## 查看和文件

- `index.html`：六只角色对照，支持奶油/白/深色/网格底、原尺寸查看和 PNG 下载。
- `sheets/`：六张生成形象稿。
- `references/`：外观核对照片，只供设计对照，不作为游戏发行素材。
- `characters.js`：角色名、外观要点、来源链接。
- `prompts.json`：完整生成提示词和参考图输入记录。里面的 `/tmp/` 路径是本次工具输入的历史位置，对应照片已持久保存到 `references/`。
- `generation-records.json`：内置工具原始输出位置和本目录交付位置。
- `validation.json`：PNG 尺寸、alpha、文件哈希及浏览器检查。
