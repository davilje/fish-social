# 水库·薄荷：独立绘制植被样板

本样板验证完整植被资产的制作方式：两组近树和两组中景灌木使用内置 image_gen 以原图为风格、配色和构图参考独立绘制，不从整图裁切枝叶。绘制结果保存在 generated/，透明资产按等比缩放和根部定位放入 layers/，完整提示词及生成源路径在 prompts.json。

背景使用本轮已经补绘的天空、透明云景、完整水坝与坡地。前景岸边和水面沿用原图，下部保留原图像素，上部以短透明过渡接入地面。背景补绘来源记录在 background-prompts.json。素材保持同一粉彩绘本方向，但新增植物形状和部分背景已经重绘，不再声称与原图逐像素一致。

共 8 张全画布图层（2172 × 724）：天空、静态云层、远林水坝与坡地、两组中景灌木、两组近树、岸边与水面。可逐层关闭、单独查看、和原图左右对照。

风动试验以完整植被为单位，固定底部 32%（含根部），上部逐渐增加轻微横向弯动。树群最大位移约 4 个原图像素，灌木约 2.8 个像素；云和地面静止。背景连续覆盖植被后的区域，没有使用固定原图树叶叠一份动叶来遮洞。本试验用于评价资产结构，尚未集成到 Unity 或 Windows Overlay。

输出：composite.png 为静止组合，original.png 为对照原图，layers.json 为摆放信息。浏览器验证结果见 browser-validation.json。

旧方案状态：此前千岛湖灌木固定后层的来源和景深顺序已修正并同步项目；当前项目仍使用既有分层与风动方案。Unity 预制体是静态图层和引用，Windows Overlay 执行树叶风动，云景保持静态，整幅水面背景静止；水花为独立钓鱼交互特效。
