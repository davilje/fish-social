# 40个鱼塘场景更新 · 2026-11-04

世界地图的旧坐标表只有20个鱼塘，未覆盖新增鱼塘，运行时因此整体回退到8×5规则网格。当前坐标表已补齐40个正式鱼塘，沿原画内湖泊、河道、海湾分布。整合预览的地图、鱼塘列表、详情照片和Unity读取同一份坐标及场景对应关系；地图按1672×941原画比例显示。

新增20个鱼塘此前没有保存的Overlay布局，默认椭圆钓位会落入背景高度。本次已生成20份预制体并导出对应JSON，每塘20个钓位使用各场景groundY对齐座椅落地线；继承原有猫咪与木凳接触关系，并写入对应等候区和水面线。默认缺失布局的钓位生成也改为同一条水平岸线。

40个正式鱼塘和教学塘共41份明确场景绑定，覆盖此前全部30张粉彩系列图及千岛湖专用版。场景数量小于鱼塘数量，因此部分同类水域复用场景，但不再依赖主题随机回退。照片41张；原始PNG颜色与纹理、前层植被风动配置保持原样。云和天空仍固定在完整原图中；恢复的独立天空与云景是预览备选层，不参与正式动效。

已同步到 desktop-overlay/OverlayResources 和 fish-social-unity/FishSocialOverlay/OverlayResources。已有Windows安装包未重新构建，需要重新打包Unity客户端与Overlay后使用新的地图与资源。

验证：Unity针对性EditMode测试8项全部通过，覆盖完整绑定、全部30套场景、41张照片、820个钓位的座椅落地线、导出水面线、运行资源副本及风动文件。浏览器检查总预览的40个地图标记、41个场景选项、北湾照片和钓位检查开关，无脚本错误。原有20个正式鱼塘及教学塘的保存钓位坐标未更改。
