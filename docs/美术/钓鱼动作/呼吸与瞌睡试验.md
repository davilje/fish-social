# 呼吸与瞌睡预览试验 · 2026-10-30

状态：2026-10-30 用户确认后，默认“明显”档已应用到 Unity 与 Overlay。统一入口为根目录 `现行预览.html#rest`。服务器入睡规则与角色 PNG 不变，其他强度档仅供 Web 比较。

选择“等待”后，左栏是原版呼吸和睡姿，右栏是试验版。默认清醒呼吸从 ±0.6% 提高到 ±2.2%，睡着呼吸从 ±0.9% 提高到 ±2.8%；均围绕固定脚底周期变化，无累积放大。提供三档呼吸、三档点头幅度。

瞌睡循环为 6.4 秒，8 段姿势过渡，边界位于 0、900、1900、2700、3300、3900、4400、5200、6400ms。动作先慢慢低头，在最低点停留，再抬头、轻回落、恢复；闭眼使用现有独立头部素材。这些是代码生成的姿势过渡，不是新绘制的角色序列帧。

为避免直接转动头层露出头颈切口，四个角色图层使用同一连续形变，向脚底渐退；鱼竿保持刚性并跟随握点，鱼线起点跟随竿尖，末端仍固定于浮标。头部最大前倾约 8°，支持调为 0.65× / 1× / 1.25×。呼吸仍有整体现有层的微幅纵向伸缩，最终幅度以预览观感选择。

查看方法：点击“模拟 30 分钟后睡着”，保持播放；或拖动进度条检查完整 6.4 秒。暂停后“上一帧/下一帧”按 100ms 步进；点击角色或“触碰唤醒”恢复。

正式实现：`FishingRestGeometry.cs` 是 Unity / Overlay 共享的点头曲线与形变坐标。Unity 使用 UGUI 顶点网格，Overlay 使用冻结的分片贴图绘制，采用 48 档几何采样及最多 128 个缓存条目，避免每帧生成 PNG 或无界缓存。鱼竿保持刚性，头颈共享形变；离开等待时恢复源素材和姿势。

验证：`scripts/verify-rest-study.cjs` 检查 11 角色 × 9 时点、脚底固定、周期无尺寸漂移、最大幅度形变不翻折、唤醒和进度条；另通过原有 616 次动作渲染回归。Unity 动画与呼吸专项 187/187 通过，Overlay 7/7 跨平台动作检查通过，包含 Unity/Overlay 参数一致、握点和鱼线连接。Overlay WPF 编译成功，Windows 实际渲染和多人同屏性能待用户验收。
