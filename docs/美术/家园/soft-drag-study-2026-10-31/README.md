# V9 躯干分段弯曲（2026-11-01）

入口：`现行预览.html#home-soft-drag`，橘猫默认「软组织分段弯曲」。V8 的整体惯性旋转让大摆幅掩盖了局部形变不足，用户反馈为“全身僵硬绕提起点晃”。下面 V8 及更早章节只保留历史，不代表当前采用方案或已通过用户验收。

- 删除整猫最佳拟合旋转、整体旋转基底与对应残差蒙皮。胸、腰、臀沿现有软组织节点分别产生位移；限制相邻段折角，防止颈部折叠。
- 新增 `segment-skin.js`：沿参考脊柱分配固定权重，按距抓取点的路径距离限制各段位移，再限制相邻材料点的位移差。提头使用局部刚性 MLS；中部和四爪使用连续位移场，避免弯曲原画的近邻分支混淆。仍是受约束的二维网格，不含自碰撞或三维体积。
- 头脸保持局部刚性。爪、尾的重叠权重连续混合，取消“只取最大权重”的接缝；独立摆角使用连续周期响应，避免经过 ±π 时跳变。四爪可抓取，保留三种起姿与回落。
- 对物理节点相对抓取点的位置做约 63ms 的跟随滤波，保留分段滞后；最后仍有防翻面与描边伸缩保护，但不再增加整猫旋转来补偿减幅。
- 深色区域几何主伸缩检查为 0.65–1.45，允许真实弯曲，比 V8 更宽。它不是“描边屏幕宽度恒定”的保证；快速拖动仍可能触发减幅，手感及线条需要实际预览判断。

验证：六种抓取实际渲染网格的胸腰/腰臀相对角变化约 12–24°，最佳整体刚性拟合后的平均残差峰值约 3.1–5.4px；这两个指标用来排除只做整体摆动。测试轨迹中无可见翻面，脸部中心采样宽度保持，最大抓取误差低于 0.1px；轮廓相对位移最大约 7.4px/帧，差分变化最大约 3.8px。54 组实际鼠标抓取回归通过。

# V8 恢复柔韧摆动并保护描边（2026-11-01）

统一入口：`现行预览.html#home-soft-drag`，橘猫默认“二维软组织（柔韧）”。V7 的数值稳定性检查没有覆盖摆幅下限及描边厚度；用户实际反馈表明，固定高阻尼、保留上一帧的保护会抑制运动，局部面积修正也会挤粗描边。这些处理已替换，以下 V7/V6 章节仅为历史记录。

- **运动与形变分开。** 从物理组织网格提取连续整体姿态，保留绕抓取点的惯性摆动；局部变形保护只作用于非刚性残差，不再把整只猫锁在旧网格上。头脸及爪掌使用同一套刚性变换，不依靠逐顶点时间混合。
- **移动与停手分开。** 阻尼随抓取点速度平滑变化：默认柔软度下，拖动约 4.5/s，停手约 9/s。保留跟随滞后，降低停手后的持续反弹。最大整体姿态偏转约 ±35.5°，不是无限旋转或拉长。
- **描边保护。** 删除局部三角形面积投影；在原 PNG 的深色线条附近约束网格局部主伸缩比例为 0.85–1.15，其他可见区域为 0.70–1.40，避免细长/挤扁面片放大单侧黑线。这个指标是几何缩放范围，不是对最终栅格线宽绝对恒定的保证。
- **蒙皮与性能。** 抓取点锚定的有界残差减少头肩连接处的 MLS 外推误差；按姿态缓存解剖权重和变换。角色素材与毛色坐标未改，未写入 Unity / Overlay。

验证：`scripts/verify-home-soft-flex.cjs` 覆盖六种抓取的真实渲染网格，要求足够摆幅、非刚性残差、移动期间非冻结、描边缩放范围、无反转、头脸尺寸、抓取精度、帧间连续性与停手收敛。本次测试摆幅约 55–75°（完整左右行程），描边区域缩放处于上述范围，未发现翻面。`scripts/verify-home-soft-stability.cjs` 现转调该完整回归；原仅限制速度上限的检查不能证明手感正常。

54 组实际鼠标抓取回归通过。截图与报告在 `output/home-soft-drag-flex-v8/`，包含头部、中部、前爪晃动的多个时点；本机 450 帧 CPU 双物理步与绘制提交平均约 4.1ms、P95 5.8ms，不包含 GPU 完成。最终手感与描边观感仍以实际预览验收为准。

# 橘猫二维软组织试验 V6（2026-11-01）

## 实现与范围

- 参考 sobosuba 的 `game.js` 果冻揉捏中的边长、弱抗弯、面积保持与阻尼思路。没有移植 `slime.js` 的断裂、邻居重组、融合或密度场渲染。

- 先对有折叠风险的渲染三角形做局部面积投影，保护脸部、爪尖与抓取区域；仍无法修复时保留整体减幅兜底。极端快速拖拽时该兜底仍会减弱效果，因此这不是无限拉伸的流体。
- 保留三种起姿及全部六点抓取、松手回落与姿态过渡。没有补绘新原画；没有完整自碰撞、三维体积或逐足地面软接触求解。仅网页验证，未接入 Unity / Overlay。
- 调参区提供新旧求解器、柔软度、自动演示、锁定躯干及骨架/组织网格显示。头部可见网格中的尺寸保持，不等同于肩髋混合区域所有纹理像素绝对不变形。

# 猫咪软体拖拽 · 柔性节点链 V5

统一入口：`现行预览.html#home-soft-drag`。当前默认加载 `drag-v4.js`，仅网页试验。

## 本轮可操作内容

- 橘猫、三花猫、英短蓝猫；坐姿、低身趴伏、仰躺三种起始姿势。
- 头部、身体中部、前爪①②、后爪①②，共六个独立抓取区域。三种起始姿势四只爪尖都可见，直接点击爪尖命中；蓝点是前爪，棕点是后爪。
- 按下锁定部位及接触偏移，拖过其他部位不换爪。背景透明像素不可抓；尾巴不是额外抓取部位。
- 前爪用肩部悬垂原画，后爪用骨盆带起和头朝下原画，中部用头尾两端下垂的拱形原画；左右没有镜像复用。
- 各姿势按头宽 148 场景像素标定（V3 约 190），缩小约 22%；不是按每帧整体包围盒自动缩放。
- 固定 120Hz 更新，8 个脊柱节点组成柔性质量链，每步 14 次约束迭代；重力、距离约束、较弱的抗弯约束与阻尼共同产生身体弯曲、滞后、伸展和停手后的回摆。四肢连接保持骨长，头脸与爪掌采用局部刚性保护；上传网格前检查可见面片反转。
- 按抬起高度选择准备/悬垂关键姿态，短淡变在 0.1 秒内完成，停在中间不会永久叠加两张半透明图。松手保留速度、重力回落后短缓冲恢复所选休息姿态。
- 默认柔软度 100%；可选演示部位、自动演示、柔软度调节、抓取点、柔性骨架与网格及复位。“对比：锁定躯干”可对照只做整体摆动的版本。取消指针、切换猫或姿势、窗口失焦会解除抓取。

## 素材与实现

`grab-v4/` 保存三品种原图集、透明切图、切图坐标 JSON、`poses.js`（抓取坐标和头宽）与 `prompts.txt`。现有 V3 的头部悬垂图按相同尺度复用。三花的 `calico-paws-4.png` 为独立修正的高清倒悬帧，覆盖图集同编号单元；重切图集时须保留 JSON 中的 override 标记和该最终 PNG。

`drag-v4.js` 负责实际透明像素命中、固定抓取点、姿态状态机与 WebGL 连续蒙皮；`rope-rig.js` 负责 Verlet 积分和 PBD 位置约束。抓头、身体中部、四爪分别固定对应节点，肩部/骨盆连接将受力传到躯干。

渲染通过有界连续位移场映射节点运动，并用头部轮廓和爪掌局部刚性权重保持原画完整；发生可见面片折叠风险时降低形变增益。因此渲染不是原始物理节点的一比一投影。当前是 PBD 柔性链交互试验，不含自碰撞、完整体积求解及肘膝多关节 IK；尚未覆盖全部八种休息姿态，也没有写入 Unity / Overlay。

`paws-0` 是未接入的探索稿，前爪①使用单独的 `paws-3`，不能把错误方向的探索稿当作它的过渡。未使用的图保留在原画材料中，运行时只按 `poses.js` 加载。

## 验证

`scripts/verify-home-soft-drag.cjs` 从总页进入，使用真实鼠标覆盖 3 品种 × 3 起始姿势 × 6 部位共 54 组，检查命中、抓取锁定、接触点精度、网格反转、松手落地、透明背景、取消、复位和演示。截图与结果在 `output/home-soft-drag-grab-v4/`。

`scripts/verify-home-soft-rope.cjs` 进一步检查六种抓取下的连续移动、停手余摆、渲染头宽、物理骨长和可见面片。当前记录的非刚性形变跨度约 12–52 场景像素、停手后继续位移约 4–36 像素，可见反转为 0；结果与截图在 `output/home-soft-drag-rope-v5/`。骨长检查针对物理约束，不能等同于全部纹理像素绝对刚性。

原画图形与浏览器截图已检查；最终动作观感由用户评审，几何检查通过不等于视觉验收。
