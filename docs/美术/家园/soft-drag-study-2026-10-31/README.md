# 猫咪软体拖拽 · 独立部件惯性 V2

总入口：`现行预览.html#home-soft-drag`。本轮只更新网页试验，尚未接入 Unity / Overlay。

橘猫、三花猫、英短蓝猫各七个部件：头、无肢躯干、远/近前肢、远/近后肢、尾巴。支持直接抓取任意可见部件，自动演示、惯性档位、分层关节显示、重置与取消拖拽。

## 本轮变化

- 旧版整张坐姿网格会把四肢一起拉长。V2 只有躯干采用 8×24 连续纹理网格，头和四肢、尾巴均使用刚性四边形，仅平移和旋转；运行中宽高保持常量。
- 四肢分别保存角度与角速度，使用各自的摆长、阻尼和移动关节的加速度产生惯性；悬空后趋向重力方向，快速甩动与停手后各自继续余摆。头部独立小幅摆动，尾巴阻尼更低。
- 躯干独立长度弹簧、横向滞后弹簧，惯性比 V1 强；长度有 78–210 的边界，静止长度 95。横向曲线不翻折。没有把躯干缩放传给子部件。
- 抓取绑定部件局部 UV，保持抓取点跟手；120Hz 固定步长。释放带有限惯性与重力，脚/身体接地后收腿恢复，尾巴单独处理碰地，不作为支撑把整只猫架起来。
- 绘制顺序：尾巴 → 远后肢 → 近后肢 → 躯干 → 远前肢 → 近前肢 → 头。关节部分相互覆盖。

## 视觉修正

- 缩短前肢，恢复坐姿的紧凑比例；前肢肩部使用局部透明过渡，避免完整圆形根部轮廓像贴片一样露在胸前。
- 坐姿与悬空使用不同的肩/髋位置，并连续过渡。提起后后腿连接到躯干底端，避免被伸长的肚子完全遮住；四肢自身尺寸不变。
- 校正三花头部和蓝猫躯干的图集裁切范围，排除相邻部件的描边/胡须；记录同步到 manifest。
- 接地改用脚掌底部采样点，而非旋转图片的透明矩形边角；尾巴独立碰地，阴影随身体位置移动。
- 关节惯性由拖动加速度和躯干摆动加速度驱动，避免抓取点校正又被算成下一步加速度的反馈；停止后逐渐回到下垂姿态。

## 素材

通过内置 imagegen，参照现有三只猫的姿势原画补绘完整部件及隐藏区域。

- `layers-v2/*-atlas.png`：生成的原始七部件图集，1254×1254 RGBA。
- `layers-v2/{orange,calico,blue}/*.png`：21 张独立透明部件，网页直接加载这些 PNG。
- `layers-v2/manifest.json`：每个部件的文件名、在原始图集中的裁切区域。
- `layers-v2/prompts.txt`：完整生成提示词。参考图来自 `../rest-poses-2026-10-31/*-poses.png`。
- `physics-v2.js`：尺寸、归一化旋转支点、关节位置、摆动参数及绘制顺序。
- `drag-v2.js`：独立贴图渲染、透明像素命中、鼠标/触摸、可视化。

V1 的 `physics.js` / `drag.js` 保留作原型历史，本页不再加载。

## 验证与限制

`scripts/verify-home-soft-drag.cjs` 验证三种惯性、头/躯干/前肢/后肢抓取、快速甩动、独立余摆、悬空稳定后朝下、边界及落地。逐步检查头、四肢、尾巴的宽高不变，以及躯干三角形正面积。通过总页检查三角色真实鼠标拖动、取消、重置与演示。截图和报告在 `output/home-soft-drag-study-2026-10-31/`。

当前每条腿作为一整个刚性部件绕肩/髋摆动，尚无独立肘/膝关节；躯干为二维弹簧形变，不是三维软体。图集与组装比例为手感预览的新绘方案，仍需视觉验收后再应用正式游戏。
