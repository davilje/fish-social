    水声常在，风叶时起时落。

    水声与风叶音量分别保存，并跟随上方总音效音量。自动环境中先有风、再有叶，渐渐安静后过一会儿再起。

    水声连续循环；风声与叶声只响一阵，结束后会安静 20–38 秒。隐藏或静音时略过当前风叶，恢复后等下一阵；不会补播旧声音。
