## 参数与成长

- [ ] 品质基准上限依次20厘米、35厘米、50厘米、80厘米、3米、15米、40米；个体固定±15%，独立于幼鱼规格。
- [ ] 自然T80依次1／2／3／5／7／10／14天；初期快后期慢，14天后继续渐近，不设14天生长终点。
- [ ] S为幼鱼基准，C为上限，k=ln((C-S)/(0.2C))/T；幼鱼从S起，成长规格从实际入塘长度E起，不能入塘后缩水。
- [ ] 不添加本次未定的鱼种倍率、随机速度；同品质差异来自固定规格、上限、入塘时刻与实际摄食。
- [ ] 体长保存0.001米；不足1米显示厘米一位小数，1～不足10米显示米两位小数，10米及以上显示米一位小数；单位用量化后的实际区间判断。
- [ ] 成长、定价、重量、尺寸归一化、回鱼、图鉴与客户端共用新口径；FISH-ATTR-01旧0.05米粗步进不再执行。

## 初始铺鱼与补鱼

- [ ] 正式塘初始100条，原品质权重与合法鱼种池不变，新手塘独立处理。
- [ ] 开服先生成S、C，在S至14天自然可达长度间抽取长度，再倒推历史入塘日期，范围前14～0天；入塘长度为S。
- [ ] 初始批次标记pre_opening_seed；不编造开服前摄食、玩家或脱钩经历，重启不重复播种。
- [ ] 已明确确认50%幼鱼、40%成长鱼、10%较成熟鱼混合补入，对应0～0.2T／0.2～0.8T／0.8～1.5T成长阶段；幼鱼以3.4～4.6厘米为基准，实际入塘长度按阶段生成。这是规格生成参数，不是真实鱼龄，在塘时长从实际投放时刻开始。
- [ ] 日常补入记录实际入塘长度和真实投放时刻；本塘生存时间从0开始。
- [ ] 每小时库存≤40补到80，41不补；每日Asia/Shanghai凌晨04:00补100；重合只执行日结，事务与批次幂等。
- [ ] 史诗及以上沿原分布计算容量100下目标；实际整数达到浮点目标即停止自动补入，等效向上取整；高级塘参考9／4／2／1，其余逐塘原表计算。
- [ ] 限制覆盖小时、日结、离线和兜底，每新增一条立即更新库存；合法低品质可补足，不绕过限制。
- [ ] 无人塘按既有休眠协议唤醒补算，不重放虚构捕获；塘内迁徙每小时一次。
- [ ] 40塘、每塘100条、每塘20位是容量规划；鱼塘目录、地图、解锁与鱼种需同步扩充，物理多机另立计划。
