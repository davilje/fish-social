# 手账资料与收获：交互布局预览

2026-10-22 网页设计预览；2026-10-23 按确认方案迁入正式 Unity 页面，详见 [Unity 实施记录](../../journal/2026-10-23-cozy-journal-workspace-unity.md)。

入口：`http://127.0.0.1:8769/docs/design/ui/prototype/journal-workspace/index.html`。

在仓库根目录运行 `python3 -m http.server 8769 --bind 127.0.0.1` 后访问。通过顶部四个按钮切换，也支持 `#profile`、`#edit`、`#compose`、`#settlement` 直接打开。

基于原版 cozy-journal 的手账外框、字体、美术、导航和动效，新增独立扩展文件；原版 HTML/CSS/JS 保持不变；Unity 实现另见实施记录。所有操作仅在当前标签页内生效，统计、体重、时间及金币均为设计示例。

- **个人资料**：身份名片、累计鱼获/水域/时长、升级进度和最近收获；右侧静态珍藏详情。主内容仅保留一个编辑入口，收藏功能通过既有左栏访问。
- **编辑资料**：左侧名字与简介，右侧大面积切换九个头像和八个展示位；鱼获整卡点击，弹出可搜索的大图选择器，支持取消、清空、确认；取消和保存固定在左侧资料卡内底部，与输入框对齐；切换头像/展示鱼获时保持位置不变。昵称最多 12 字，简介最多 120 字。
- **分享鱼获**：左侧鱼获大图和候选缩略图，右侧 160 字附言及公开/仅好友切换；空文案提示，发布后进入本地「我的动态」。
- **离塘结算**：本次咬钩、脱钩、时长和成功钓获统计；可滚动记录展示图片、鱼名、日期时间、体长和体重；支持新纪录筛选、时间/体长/体重排序、单条分享与返回；侧栏展示回鱼收入、费用和净收入。

已通过浏览器实际操作检查：编辑保存/取消、头像选择、八展示位更换、鱼获搜索空结果、发布校验/可见范围/动态回显、结算筛选/排序/分享、Escape 关闭、1280×800 窗口缩放。页面无脚本错误，相关图片均加载成功。截图见 `screenshots/`。

Unity 使用真实账号、背包及新增离塘台账统计；没有权威来源的网页演示累计时长／水域数量以现有统计替代。保留全部 10 个头像及可选附言，不允许分享已回塘鱼获；体重沿用既有公式。本网页仍为独立演示数据。
