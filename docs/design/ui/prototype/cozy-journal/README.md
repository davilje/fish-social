# 猫咪钓鱼手账交互原型

在原版纸张、贴纸、拍立得与浮标导航的视觉基础上补齐页面。

## 预览

从仓库根目录启动静态服务：

```sh
python3 -m http.server 8769 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8769/docs/design/ui/prototype/cozy-journal/index.html`。

## 已补齐

- 排行榜：四类榜单、玩家详情与本地关注。
- 个人信息：资料编辑、展示柜、图鉴、相册与成就。
- 钓友动态：动态筛选、点赞、评论与发布表单。
- 选塘列表：搜索、筛选、锁定状态、详情与入塘预览。
- 主界面顶栏「钓鱼世界」入口，关闭手账后也可打开地图。
- 地图与列表共用鱼塘详情布局，照片、信息、档位选择和进入按钮各占独立区域。

`pages.js` 与 `pages.css` 扩展原版页面；`app.js` 保留原有页面、导航和动效逻辑。工具栏支持减小动效与演示速度控制。

这里使用本地示例数据。资料、展示柜、相册和动态操作保存在当前浏览器的 localStorage 中，不会发送到服务器；入塘展示为交互预览，尚未接入 Unity 游戏流程。

## 室内背景评审

当前 v4 房间已接入正式 Unity 桌面工程。入口、资源位置、交互及验证见 [首页室内小屋接入 Unity](../../home/2026-10-23-home-room-unity.md)。本目录仍是浏览器评审原型，数据行为与上述 localStorage 说明相同。

首页使用 `assets/room-runtime/room-base.jpg` 空房间底图，叠放 15 张独立透明 PNG，共 17 个物件实例。切图包括鱼竿、猫窝、猫爬架、玩具篮、老鼠玩具、植物、鱼缸、地毯、猫抓柱、钓具收纳架、鱼缸底架、食水碗、钓鱼包、壁架与书、装饰画。三支鱼竿复用同一切图。移除了原来的窗光斑、地板光影、物件外部投影与角色脚底阴影，保留物体内部的柔和明暗以表达体积。底图只保留墙地、窗户窗帘与门。

`assets/room-v4/manifest.json` 保留母版尺寸与布局；`assets/room-runtime/manifest.json` 记录按最大展示约 2x 导出的运行尺寸及相同布局，`room-preview.js` 读取运行清单组装场景。与 Unity 一起由 `scripts/art/export-home-room-runtime.py` 导出。切图保留独立透明通道，可以逐件替换、移动、隐藏。地毯以清单指定宽高适配地面透视。原界面字体、面板、按钮、导航布局直接复用。旧整图候选和原始大图保留。

切图浏览与下载页：`assets/room-v4/index.html`，可切换棋盘格、深色、米白背景检查透明边缘。完整提示词与生成路径保存在同目录 `generation-records.json`；图像由内置 image_gen 编辑/提取，导出脚本仅裁去透明空白并生成检查预览。

页外工具栏提供“室内小屋／原背景”“物件：显示／隐藏”及“合上手账看房间”。隐藏物件可检查空房间底图，同时隐藏家具功能入口。地址加 `?roomView=home` 可直接查看室内首页。原背景仍保留为 `assets/home-sakura.jpg`。

室内只显示一个活动角色，复用原 `#corner-cat`，移动到中央地毯；站立、坐下直接使用已有角色 PNG。点击中央地板移动，拖动猫咪调整位置，点击猫咪点头回应；聚焦猫咪后可用方向键移动、Home 回中央、R 坐下。无操作时低频短距离移动，30 秒后坐下休息；打开手账或切到后台暂停，关闭手账保留位置，减少动效时立即移动且不自动漫游。活动脚底限制在 x=580–1070、y=690–775，避开底部导航。

“我的钓具”和“鱼缸 · 展示柜”分别打开原装备页、个人信息展示柜。物件已按独立切图组装，但尚未绑定正式账号陈列数据。鱼缸内部鱼、水草、水体作为一个完整组件导出，暂未拆成缸内动画层。走动使用原站姿的轻微起伏演示位移，未制作新的逐帧步行动画；坐下使用真实坐姿，不以旋转站姿代替睡觉。

补充交互：直接点击三支鱼竿也会打开装备页；点击猫窝，猫咪移过去并用已有睡姿在窝里休息。猫窝、猫碗和猫爬架支持限定区域拖放，或聚焦后用方向键摆放，本浏览器保存位置。搬动猫窝时睡着的猫一起移动，拖动不触发点击；打开页面或窗口失焦会取消未完成的拖动。打滚、倒粮及进食序列帧尚缺，按本次约定先列入[动画资源需求](../../home/2026-10-23-home-room-animation-requests.md)。

## 验证

已检查 10 个页面、27 个分类标签、主要表单与交互、本地保存和快速切页；在 1672 × 1033 和 1280 × 800 窗口检查地图与选塘列表的右栏边界，确认详情、档位和进入按钮无重叠。
