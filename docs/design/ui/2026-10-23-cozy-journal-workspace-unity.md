# 资料与收获工作区：Unity 实现记录

日期：2026-10-23。依据用户确认的 `prototype/journal-workspace/index.html`，在已认可的正式 DesktopShellUi / PanelRouter 上重写四个页面；不启用 JournalV2。

## 页面与业务

- **个人资料**：身份名片、三项真实统计、升级进度及最近收录、右侧珍藏详情。移除正文重复的展示柜／相册按钮，保留单一编辑入口。
- **编辑资料**：左侧昵称／简介与实时名片，取消和保存固定在左卡底部；右侧三列大头像和四列八展示位。整卡点击打开可搜索选择器，暂选、确认、取消与清空分开处理。保存中禁止重复提交和离开；错误保留草稿。保存成功回到个人资料。
- **发布鱼获**：1120×752 双栏，左侧鱼获照片、尺寸／体重／时间／水域、可滚动库存缩略图；右侧作者、160 字附言和公开／好友选项。底部取消／发布固定。可见选择态在重新应用主题后保留；预选鱼获已售出时不会擅自换成其他鱼。
- **离塘结算**：1120×720，四项统计，滚动鱼获记录，右侧收支及经验，底部返回手账。每条记录有实际鱼种图片、记录时间、尺寸、体重；支持入包／回塘筛选及时间／尺寸／体重排序。筛选排序使用展开菜单。入包记录可打开发布弹窗并预选库存 ID，发布成功跳到我的动态；回塘记录禁用分享。

原有页签、按钮与卡片动效继续使用原生 uGUI 动效组件。弹窗淡入上移及减少动效选项兼容；结算支持遮罩和 Escape 关闭，分享弹窗在前时不会同时关闭底层结算。

## 真实字段与网页演示的区别

网页数据仅是设计示例，项目不保存这些演示数值：

- 资料页以图鉴累计钓获、已收录鱼种、已解锁成就替代没有完整权威来源的累计时长和探索水域数。昵称、头像、简介、等级、经验与珍藏来自真实接口；其他玩家未公开的累计数量明确标注。
- 保留项目全部 **10 个可用头像**；额外一行可滚动，不限制为网页演示九个。
- 发布 API 的附言仍为选填；空文案沿用鱼获描述，保持既有业务约定。
- 结算没有伪造“新纪录”字段，筛选以真实入包／回塘状态为准。回塘鱼已不在背包，不提供再次发布入口。
- 体重使用既有 `calcFishWeightKg` / `DesktopGameData.CalcWeightKg` 公式。资料页明确标注估算体重，不新增重量算法。

## 服务端统计

`pondSessionLedger` 新增 `biteCount`、`escapeCount`、`fishingDurationMs`。真正进入咬钩与脱钩阶段时累计；钓鱼时长汇总已计入的有效钓鱼分段，排除闲置和重复结算，沿用现有每日额度规则。离塘 DTO 增加 `weightKg`、入包记录的 `inventoryItemId`，旧字段兼容保留。

修改服务端源码后需重新启动服务并重新进入鱼塘，才能得到整次出行的新增统计；旧进程或更新前已开始的出行不能补算历史事件。本轮未新增或修改埋点事件。

## 可重复生成与检查

Unity 菜单 `Fish Social / Cozy Redesign / Apply Web Workspace Pages` 写入正式 ProfileHub、ProfileEdit、JournalComposeModal、PondSettlement 预制体，包含原有 Variant 保存处理和结构守卫。默认结算生成器也使用新布局，避免重新生成后回退。

`CozyRedesignPreview.RenderWorkspace()` 使用生产 presenter 和示例 DTO 渲染六个状态；全量预览含 24 个状态。运行以下脚本更新本地预览：

```sh
node scripts/art/build-cozy-journal-production-preview.cjs
node scripts/art/build-cozy-workspace-preview.cjs
```
