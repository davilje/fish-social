# 手账网页预览打开动效修复

日期：2026-10-23。范围：`cozy-journal`、`journal-workspace` 两个网页预览。

## 历史定位

- 共用底栏的“刷新两次”观感，在 Git 最早收录的 `806a765d`（2026-10-21 15:16:47，`10/21 部分ui更新`）已存在。`d57a7dd0` 没有修改这段打开顺序；不能归因于后来的 Unity 对齐更新，也没有更早的已提交预览可供回退。
- 浏览器逐帧复现：点击只替换一次 `.content`；纸页升起时卡片已经可见，约 200ms 后 `entrance()` 把同一张卡片透明度设回 0，再播放贴入。不存在两次文档刷新。
- 工作区另有真实重复渲染：`6a19aff2`（2026-10-22 23:48:53，`界面优化预览效果更新`）新增 `workspace.js` 时，在启动渲染后延迟 100ms 再打开同页；编辑入口还会先渲染资料，再刷新为编辑页。

## 修复

- 纸页升起期间暂时遮住内容，装好内容入场动画后再揭开。保留 200ms / OutCubic / 16px 纸页上移、80ms 活页环回弹、40ms 卡片错峰和原有曲线。
- 已打开页面间继续使用原来的左退右入翻页；底栏重复点击不重新渲染。
- 工作区在首次渲染前选好 profile/edit/compose/settlement 状态，删除延迟重开；编辑页准备好草稿后直接进入，不再途经资料页。
- 启动同时等待字体与 DOMContentLoaded，避免字体命中缓存时先执行 boot、后加载工作区覆盖脚本的竞态。
