## 1. 一句话概念

整个客户端是小猫随身带的一本钓鱼手账。页面是纸，卡片是贴纸，选中是胶带，获得是盖章，导航上漂着一只浮漂。每一次操作，界面都像纸和水一样回应玩家。

## 2. 设计原则

1. **一张纸，一个强调色。** 页面底色统一为暖纸色，每个页签只有一个点缀色。其余全是墨色与纸色。
2. **动效只回应原因。** 只在玩家操作、获得东西、出现新内容时动。待机几乎静止。
3. **一屏最多一个循环动画。** 浮漂、浮标、小猫呼吸三者同屏时，只保留离视线最近的一个在循环，其余降为偶发。
4. **永远可读。** 动效不遮挡文字，文字不倾斜超过 2°，正在阅读的详情栏不做位移动画。
5. **可以关掉。** 设置里提供「减少动效」，开启后只保留淡入淡出。

## 3. 视觉语言

### 3.1 色板

沿用 `CatTheme` 现有的墨色与纸色，补齐点缀色。

| 名称 | 色值 | 用途 |
|------|------|------|
| Paper 纸 | `#FFF7E9` | 页面底色（即 `CatTheme.Cream`） |
| Paper Shade 纸影 | `#F3E6CF` | 栏位底、卡片阴影色 |
| Ink 墨 | `#75472E` | 正文、描边（即 `CatTheme.Ink`） |
| Coral 橘 | `#FC923C` | 主按钮、选中标签（即 `CatTheme.Coral`） |
| Lake 湖蓝 | `#5DADE2` | 水波、地图、信息提示 |
| Leaf 叶绿 | `#6BB86B` | 成功、可进入 |
| Gold 金 | `#F2BF47` | 金币、稀有、奖励 |
| Blossom 樱粉 | `#F7B6C8` | 胶带、NEW 角标 |
| Bobber Red 浮漂红 | `#E2533F` | 导航浮漂、印章 |

每个页签的点缀色：商店 Gold，背包 Coral，装备 Lake，成就 Gold，排行榜 Blossom，个人 Coral，钓友动态 Leaf，探索世界 Lake，设置 Ink 60%。

### 3.2 形状与材质

- **页面**：厚纸手账页，四角 20px 圆角，左侧 3 个金属活页环（装饰，不参与布局），纸面有 4% 不透明度的点阵。
- **索引标签**：左栏页签是从纸边伸出来的索引贴，未选中露出 190px，选中时多伸出 12px 并填充点缀色。
- **贴纸卡**：卡片带 6px 白色模切边与柔和投影，每张卡有 −1.5°～1.5° 的固定随机倾角（按 id 哈希，刷新不变）。
- **胶带**：选中卡片的左上角贴一条半透明胶带，三种图案（彩条、圆点、小鱼）。
- **拍立得**：右栏详情的主图用拍立得相框，图钉或胶带固定。
- **木栈道导航**：底部导航是木栈道板，激活页签上方漂着浮漂。

### 3.3 字体与文字

- 标题用圆体（现有字体中最圆润的一款），正文保持现有字体，字号不变。
- 数字（金币、经验、尺寸）用等宽数字，以便滚动计数时不跳动。
- 不使用英文装饰标题，参考图里的 “Scrapbook Journal” 仅为示意。

## 4. 动效语言

### 4.1 时长与曲线令牌

全局只允许以下组合，写成常量，不允许在页面里随手写数字。

| 令牌 | 时长 | DOTween 曲线 | 用途 |
|------|------|--------------|------|
| `Tap` | 60ms | `Ease.OutQuad` | 按下压扁 |
| `Snap` | 220ms | `Ease.OutBack`（overshoot 1.6） | 松开回弹、贴纸落下 |
| `Slide` | 200ms | `Ease.OutCubic` | 翻页、侧栏刷新 |
| `Hop` | 420ms | 自定义抛物线 + `Ease.OutQuad` | 浮漂跳页签 |
| `Float` | 2400ms 循环 | `Ease.InOutSine` Yoyo | 浮漂、浮标 |
| `Celebrate` | 900ms | 分段 Sequence | 收获、领奖、升级 |
| `Stagger` | 每项间隔 40ms，最多 8 项 | — | 卡片依次入场 |

### 4.2 五个动作

见 `cozy-journal-02-motion-storyboard.jpg`。

**弹（Press）**：所有按钮。按下 `Tap` 缩放到 (1.06, 0.92)，松开 `Snap` 回到 (0.98, 1.04) 再到 1。不可用按钮按下时水平抖动 ±4px 两次（`DOShakeAnchorPos` 180ms），不缩放。

**漂（Float）**：导航浮漂与地图浮标。纵向 ±3px，旋转 ±4°，相位按对象 id 错开，周期 2.4 秒。

**贴（Sticker）**：卡片入场与选中。从 1.12 倍、额外 +6° 倾角、透明度 0 落下，`Snap` 结束于自身固定倾角。选中时胶带从 0 宽度向右“拉出” 160ms，同时卡片抬起 4px，投影加深。

**翻（Flip）**：切换页签。旧页 `CanvasGroup.alpha` 1→0，向左 24px，120ms；新页从右侧 24px 滑入，`Slide`。左栏保持静止，中栏卡片以 `Stagger` 依次贴入，右栏最后 80ms 淡入。

**溅（Splash）**：奖励时刻。水花粒子 + 金币弹出 + 数字滚动，见第 6 节。

### 4.3 声音（建议）

每个动作配一个极短音效，音量 −18dB 左右，可在设置中关闭：按下“啵”、浮漂落水“咚”、贴纸“嚓”、翻页“沙”、盖章“砰”、金币“叮叮”。若暂无音频资源，先留接口不发声。

## 5. 各页面编排

### 5.1 外壳：顶栏与底部导航

- **浮漂导航**：激活页签上方 18px 处一个 36×52 浮漂，`Float` 循环。切换时：浮漂下蹲（scaleY 0.85，60ms）→ 沿抛物线跳到新页签（`Hop`，最高点高出 46px，带 1 个点状拖尾）→ 落下拉伸（scaleY 1.12）→ 回正，同时在落点生成一圈水波（scale 0.4→1.4，alpha 0.8→0，360ms），新页签图标上弹 6px。
- **顶栏数值**：金币、珍珠变化时数字滚动（`DOCounter`，400ms），增加时图标弹一下并冒出 “+N” 小字，向上漂 20px 后淡出。
- **铃铛**：有新通知时左右摆动 3 次（±12°），之后每 20 秒再摆一次，查看后停止。

### 5.2 页面通用框架

保持现有 1370×650 三栏（左 24,112,210,496 / 中 254,164,710,432 / 右 984,112,362,496），只换材质并加动效。

- 打开页面：纸页从下方 16px、alpha 0 升起（`Slide`），活页环最后“咔”地扣上（scaleY 0.9→1，80ms）。
- 关闭页面（右上角 ×）：页面向下 12px 淡出 140ms。

### 5.3 商店（参考 `cozy-journal-01`）

- 商品卡是贴纸，悬停抬起 4px，倾角减半（看起来被“拿起来”）。
- 选中：胶带拉出，右栏拍立得主图从 0.9 倍 `Snap` 弹入，描述文字直接替换不做动画。
- 购买成功：右栏商品图缩小，沿弧线飞向底部「背包」页签，背包图标接住后弹一下；金币数字向下滚动。
- 购买失败（金币不足）：购买按钮抖动，金币胶囊闪一次红色描边。

### 5.4 背包与装备（参考 `cozy-journal-06`）

- 新获得的物品卡左上角有樱粉色「新」角标，首次查看后角标“撕下”（旋转 20° 并淡出）。
- 稀有物品卡角每 6 秒闪一道光（斜向高光扫过，500ms），同屏最多 2 张同时闪。
- 装备成功：物品卡上盖一个小“已装备”印章（从 1.6 倍砸下，`Ease.OutBack`，伴随 2px 屏幕内页面轻震，仅限该页面容器）。
- 出售：卡片碎成 3 片纸屑淡出，金币飞向顶栏。

### 5.5 探索世界（参考 `cozy-journal-03`）

- 地图像照片贴在手账里，四角胶带。
- 鱼塘标记是浮标，各自 `Float`，颜色沿用现有分类色（进阶 `#F2BF47`、老手 `#9E6BDB`、野外 `#61B86B`、水库 `#479EC7`、禁区 `#DB6152`、巨物 `#B8C7DB`、未解锁 `#61666B`）。未解锁浮标不漂，半透明，带小锁。
- 悬停浮标：放大到 1.15 倍，名字标签从下方弹出。
- 选中浮标：外扩两圈水波（间隔 200ms），一个猫爪印从上方落下“盖”在浮标旁；地图视口平滑移动到该点（`DOAnchorPos` 350ms `Ease.OutCubic`），不再瞬移。
- 右栏换成拍立得：鱼塘图从右侧滑入并轻微旋转到 −2°。
- 进入鱼塘：按钮按下后，地图上的浮标“咚”地沉入水中，水波扩散，随后切到 Overlay。

### 5.6 选择鱼塘

- 列表卡片滚动进入视口时才 `Stagger` 贴入（只做一次，回滚不重复）。
- 选中卡片贴胶带，右侧详情同 5.5。
- 列表滚动到底时，最后一张卡下方有个小鱼摆尾的“到底了”，不使用回弹拉伸。

### 5.7 设置

- 开关做成猫爪拨钮：打开时猫爪从左伸出把圆钮推到右边（220ms），底色从纸影过渡到点缀色。
- 窗口尺寸预设选中后，按钮上盖一个小勾章；切换窗口模式时页面不做动画，避免与窗口重绘叠加。
- 保存提示用小鱼提示（5.9）。

### 5.8 个人中心与成就

- 成就解锁：奖章从卡片里翻转 360°（`DORotate` Y 轴，600ms）亮起，背后放射线淡入淡出。
- 等级经验条：增长时条内有一串小气泡向右滚动；升级时经验条满格闪光，等级胶囊放大回弹，顶栏头像框转一圈金边。
- 展示柜的鱼缓慢摆尾（2 帧图片切换或 ±3° 旋转），是该页唯一循环。

### 5.9 提示、空状态、加载

- **提示通知**：一条小鱼从右侧游入，嘴里叼着圆角便签，`Slide` 进场，停 2.5 秒，再游出。错误提示由小猫歪头举着，便签描边改为浮漂红。
- **空状态**：小猫蜷在空鱼篓里睡觉，呼吸起伏（scaleY ±2%，3 秒周期），头顶 Zzz 依次淡入。
- **加载**：浮漂下沉再浮起（3 帧循环），替换所有转圈图标。超过 3 秒时下方出现一行“鱼还没上钩，再等等…”。

### 5.10 角落小猫

- 主界面右下角趴着一只小猫，皮肤取玩家当前猫咪。尺寸约 140×120，不挡底部导航与右栏按钮。
- 待机：每 6～10 秒随机眨眼或甩尾巴一次。
- 反应：鼠标悬停主按钮时抬头看向按钮；购买成功时点头；钓到大鱼时跳起来；30 秒无操作后趴下睡觉。
- 图源：优先复用已有的分层钓鱼猫，选取 idle 帧裁切；不足时请原画补 4 个姿势（趴、抬头、跳、睡）。
- 必须预先加载，不在点击当帧解码图片（参考近期修复的预热卡顿）。

## 6. 收获演出（参考 `cozy-journal-04`）

钓到鱼时，Unity 主界面（不是 Overlay）在下一次打开主界面或在通知区域播放一次，总长约 1.6 秒，可点击跳过。

| 时间 | 画面 |
|------|------|
| 0–180ms | 浮漂下沉，水波两圈 |
| 180–360ms | 水花炸开，鱼从水面跃出 |
| 360–600ms | 鱼在空中翻转，金币向四周弹出 |
| 600–1000ms | 鱼落到手账页上变成贴纸，轻微回弹 |
| 1000–1240ms | 「新」印章盖在页角，角落小猫跳起 |
| 1240–1600ms | 尺寸与金币数字滚动，金币飞入顶栏 |

只有首次钓到某种鱼才盖「新」章；普通收获只播放到 1000ms，并跳过印章。

## 7. 性能与可访问性

- **减少动效**：关闭漂、贴、翻与收获演出，只保留 120ms 淡入淡出；默认跟随系统设置（若取不到则默认关闭此项）。
- **只改变换**：动效只改 `anchoredPosition`、`localScale`、`localRotation`、`CanvasGroup.alpha`、`Graphic.color`，不改 `sizeDelta`，不触发 LayoutGroup。
- **画布拆分**：浮漂、水波、提示、收获演出放在单独的 `MotionCanvas`（Sort Order 高于页面），避免动起来时整页网格重建。
- **装饰不吃点击**：胶带、印章、水波、小猫的 `raycastTarget = false`；小猫只在自身区域响应悬停。
- **后台暂停**：窗口最小化到托盘时 `DOTween.PauseAll()`，恢复时 `PlayAll()`。
- **预算**：任一时刻活动 Tween 不超过 64 个；页面切换帧主线程额外开销 < 2ms；不在动画过程中加载贴图。
- **时间源**：所有 Tween `SetUpdate(true)`，不受 `Time.timeScale` 影响。

## 8. 技术方案

### 8.1 引入 DOTween

- 使用 DOTween（免费版）。从 Asset Store 导入到 `Assets/Plugins/Demigiant/`，运行 *DOTween Utility Panel → Setup*，勾选 UI、Sprite 模块，取消 Physics、Audio、TextMeshPro 以外不需要的模块。
- 设置：`Recycle Tweens` 开、`Safe Mode` 开、`Default Update Type` 选 Normal 且 `Independent Update` 开、`Default Auto Kill` 开，容量 `SetTweensCapacity(200, 50)`。
- 需确认 DOTween 的许可证允许随 Steam 商业版发行（免费版允许）。
- 业务代码不直接散用 DOTween，统一经 `CozyMotion` 门面调用，方便以后替换或做「减少动效」开关。

### 8.2 组件

全部挂在 prefab 上，由 `CozyRedesignAuthoring` 写入参数，不在运行时临时 AddComponent。

| 组件 | 作用 |
|------|------|
| `CozyMotion`（静态门面） | 读取令牌，处理「减少动效」，封装常用 Sequence |
| `CozyPress` | 按钮的弹与不可用抖动，实现 `IPointerDown/Up` |
| `CozyFloat` | 漂；按 id 错开相位；屏外或页面隐藏时暂停 |
| `CozySticker` | 卡片入场、悬停抬起、选中胶带 |
| `CozyStagger` | 容器子项依次入场，只对视口内的项执行 |
| `CozyPageFlip` | 页面打开、关闭、切换 |
| `CozyBobberNav` | 底部导航浮漂与跳跃 |
| `CozyCounter` | 数字滚动与 “+N” 漂字 |
| `CozyToast` | 小鱼提示队列 |
| `CozyStamp` | 盖章 |
| `CozyCelebration` | 收获演出 Sequence |
| `CozyCornerCat` | 角落小猫状态机 |

`DesktopPrefabCatalog` 需登记新增的 prefab（`MotionCanvas`、`CozyToast`、`CozyCelebration`、`CozyCornerCat`、`BobberNav`）。

| 一 | 引入 DOTween 与 `CozyMotion`；按钮弹；浮漂导航；翻页；顶栏数字滚动；「减少动效」开关 | 每次点击都有手感，切页有方向感 |

## 10. 验收要点

- 每个按钮按下都有回弹；不可用按钮抖动不缩放。
- 切页签时浮漂跳到新位置，落点出现水波；连续快速点击不会叠出多个浮漂。
- 页面切换 200ms 内完成，卡片依次贴入，详情栏不晃动。
- 地图选中浮标有水波和爪印，镜头平滑移动。
- 同屏循环动画不超过 1 个持续运行。
- 开启「减少动效」后只剩淡入淡出。
- Debug 包 `Player.log` 中，页面切换、收获演出期间 `frame_stall` 为 0。
- 最小化到托盘后 CPU 占用回到无动效时水平。
