# 新版工作区动效同步到 Unity

日期：2026-10-23。状态：已实现，Windows/Steam 实机验收仍待完成。

基准为 `prototype/journal-workspace/` 的工作区交互，以及它共用的 `cozy-journal/app.js`、`pages.js`。正式入口继续使用 DesktopShellUi / PanelRouter。

## 覆盖范围

| 交互 | 网页基准 | Unity 对应实现 |
|---|---|---|
| 从首页打开页面 | 纸页 200ms、上移 16px、OutCubic；内容在纸页升起后揭开 | CozyMotion / CozyJournalFlipPose。遮住整块内容，包括普通文字、工作区卡片和索引；异步追加的内容也保持遮住。只启动一次内容入场 |
| 切换页面、关闭页面 | 旧内容 120ms 左退 24px，新内容 200ms 从右进入；关闭 140ms 下沉 12px | 共用路由保留原参数；取消与快速切页恢复可见性和点击状态 |
| 活页环、索引、卡片 | 环扣 80ms、索引 200ms 错峰 30ms、前八张卡 260ms 错峰 40ms | 保留共享实现，在纸页升起后统一开始；鱼塘仍按首次进入视口播放 |
| 左侧页签 | 固定纸张；旧内容 100ms 淡出，选中页签向左伸出 16px | 保留 CozyIndexMotion 和各页签控制器，纳入回归 |
| 排行榜、动态、图鉴与收藏详情选择 | 照片原地从 0.9 倍／0.3 透明度回到正常，220ms OutBack | 移除这些页面误套用的 24px 横移和 260ms 时长；商店、背包、世界地图仍按其网页的 260ms 横移动效 |
| 异步加载排行榜和动态 | 新卡片出现，已显示的标题和侧栏不重新消失 | ContentReady 更新初始数量，避免数据到达后重新启动整页入口动画 |
| 工作区按钮 | 悬停上移 2px、按下下移 2px；160ms CSS ease | CozyWorkspaceInteraction；取消通用按钮的压扁回弹叠加，固定点击几何 |
| 选择头像 | 仅头像图片旋转 −5°、放大 1.1 倍，200ms CSS ease | 图片网格变形；选择头像只更新选中态，不销毁并重建整组头像 |
| 展示位、鱼获选择 | 保留选中边框与填色，选择不触发整卡压扁或重播入口 | 工作区 Choice 反馈，分享缩略图与编辑选择器共用 |
| 分享、离塘结算、鱼获选择器 | 纸张 200ms 上移 16px并淡入，遮罩先出现且固定 | CozyWorkspaceDialogMotion；遮罩独立于纸张透明度，解决第 0 帧被透明父级一起裁掉的问题；关闭时恢复姿态 |
| 减少动效 | 保留不超过 120ms 淡入淡出，移除位移／缩放／环扣回弹和错峰 | 页面、弹窗、索引与卡片入口保留短淡入，按钮和头像不做空间变换 |

修改通过正式共享组件和 presenter 接入。本轮补存 12 个正式页面预制体的动效区域引用，运行时工厂和路由使用同一份区域映射；继续使用 DesktopShellUi / PanelRouter。

## 开页与右栏时序补修（2026-10-23）

实际原因是动效没有绑定到画面：商店、装备、背包、排行榜、动态、设置、个人中心预制体内的 `heading`、`aside` 和 `asideParts` 引用为空，缺少对应 CanvasGroup。之前的整页遮挡测试不能发现这类缺口。编辑资料的运行时绑定仍指向旧布局，把现已移动到左侧的 `JournalPreview` 及展示鱼获当成延迟侧栏。

- 新的 `CozyJournalMotionBindings` 共用明确区域映射，预制体烘焙和运行时都接入；修复后重新加载保存资产，验证实际区域透明度，不只验证组件是否存在。
- 资料内点击编辑、取消或保存返回，当前方案先用 100ms 淡出旧内容，再启动新内容入口（本轮补全，详见下节）；不误用跨页 120ms 退出／200ms 横移，也不重播索引和环扣。外部入口及其他页面继续使用原路由翻页。
- 编辑资料两栏当前按 240ms 轻抬淡入、间隔 40ms 依次揭开，标题与副标题淡入（本轮补全）；移除 presenter 额外启动入口动效的调用。资料页“我的钓鱼时光”和编辑按钮归同一标题时序。
- 网页初次开页只有整个 aside 的淡入，没有“侧栏完全不透明后照片再弹一次”。初始选择引发的照片动效在内容入口前归位，重新启用对象不会重播上次选择；主动选择照片仍保留其动画，且与父级淡入并行。
- 异步资料启用页签时接续当前开页时间，不把右栏直接展示为最终状态，也不重播整页。
- 选塘、世界地图和独立图鉴补上原先缺失的 aside 入口绑定。

Chrome 中暂停真实 Web Animations 并采样，再通过真实 PanelRouter 检查相同时刻；另实测编辑与取消按钮不产生纸页或内容横移动画。普通模式下，从首页点击打开开始计时：

| 页面 / 示例卡片数 | 纸页升起 | 右栏淡入 | 300ms 右栏透明度 |
|---|---|---|---|
| 个人资料、世界地图 / 0 | 0–200ms | 280–440ms | 0.125 |
| 动态 / 4 | 0–200ms | 360–520ms | 0 |
| 商店、排行榜、选塘 / ≥8 | 0–200ms | 440–600ms | 0 |
| 编辑资料 / 0 | 0–200ms | 右侧选择卡片 240–480ms，240ms OutCubic；左卡从 200ms 开始 | 0.577342 |

所有页面标题在揭开后 160ms 线性淡入；纸页 100ms 时透明度约 0.872202、向下偏移约 2.04477px，与浏览器采样一致。卡片数按实际可见页内容计算，上表是网页示例数据，不硬编码业务数据量。

新增 19 项回归覆盖保存资产引用、正式路由、编辑 presenter 和异步区域接续；专项 130/130，全套 521 通过、4 项同前失败。42 张帧图已重新导出，其中资料和编辑改用正式路由及保存的 DesktopShell 槽位，并新增“点击编辑资料”和“取消返回资料”两种实际入口。浏览器原始采样见 [开页时间线](../../art/cozy-journal/production/workspace-motion/web-opening-timing.json)，可用 `node scripts/art/qa-cozy-workspace-opening.cjs` 重跑（需 Playwright 和本地 8769 服务）。

验证范围是本轮的整页入口、标题及侧栏时序和相关选择反馈；分帧及数值检查不能证明所有页面、网络延迟和平台帧率下的全部动效已逐像素一致。Windows/Steam 实机验收仍待完成。


## 资料正文与编辑进退动效补全（2026-10-23）

此前网页工作区的 `.ws-profile` / `.ws-edit` 并不属于通用 `.sticker` 卡片，未接入正文入口；`jRefresh` 还会即时替换资料／编辑内容。这是网页设计与 Unity 同步的共同缺口。本轮先补交互预览，再把同一参数接入正式 Unity 页面。

| 动效 | 当前 Web 与 Unity 共用参数 |
|---|---|
| 个人资料中间区域 | 名片、统计、成长卡依次淡入，上移 12px，单组 240ms OutCubic，间隔 40ms |
| 经验条 | 正文揭开后等待 200ms，再用 500ms OutCubic 从零增长到实际经验比例；保留切片圆端 |
| 点击编辑、取消或保存返回 | 旧内容 100ms 线性淡出，新正文再按上述规则出现；纸页、环扣、索引固定 |
| 编辑左右卡片 | 左卡 0–240ms，右卡 40–280ms；背景、字段、取消／保存及选择区共用各自卡片时钟 |
| 局部交互与异步数据 | 更换头像、切换展示鱼获不重播整页；后来生成的头像／文字接续当前正文时钟 |
| 减少动效与中断 | 取消位移和错峰，保留 120ms 淡入；暂停／中断恢复可见性和点击能力 |

`CozyWorkspaceBodyMotion` 通过网格效果同步背景和文字，不改变布局位置及点击区域；保存的个人资料、编辑及共用资料结构的成就预制体均已绑定。正式路由的 `RefreshContent` 控制 100ms 退出段，正文在退出结束后才开始入场。

验证：新增 7 项正文、进度条、异步与中断回归，最终专项 **137/137**；全套 **528 通过、4 项此前已记录的失败**。Chrome 检查 7 个开页、编辑与取消两条时间线，以及连续点击、表单校验、草稿保留、保存返回和减少动效。42 张实际帧图已更新，切换入口先填充并稳定真实旧页面，再执行同页刷新。所有结果见上述验证记录；Windows/Steam 实机仍待验收。
