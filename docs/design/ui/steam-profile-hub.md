# Steam 个人中心（Profile Hub）— UI 草案

> 对应 **FEAT-ALBUM-01**。实现前可再由 UI 设计师细化视觉；本文件锁定**信息架构**，禁止缩回「资料弹窗 + 图鉴弹窗」双主入口。

## 目标

单一主窗面板承载：资料 · 展示柜 · 图鉴 · 相册墙 · 成就。

## 布局（Wireframe）

```text
┌─ 个人中心 ──────────────────────────────────── [×] ─┐
│ ┌──────┐ ┌────────────────────────────────────────┐ │
│ │ 资料 │ │                                        │ │
│ │ 展示柜│ │         内容区（随侧栏切换）              │ │
│ │ 图鉴 │ │                                        │ │
│ │ 相册 │ │                                        │ │
│ │ 成就 │ │                                        │ │
│ └──────┘ └────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────┘
```

| 侧栏 | 内容区要点 |
|------|------------|
| 资料 | 头像、昵称、简介、等级/熟练度摘要、隐私；编辑按钮（仅本人） |
| 展示柜 | 既有 8 格 showcase，拖拽装备背包鱼 |
| 图鉴 | 物种网格 + 详情（迁自 Gallery） |
| 相册 | 上：精选墙（最多 12）；下：候选列表（钉选/取消） |
| 成就 | 已解锁高亮；未解锁灰态（隐藏成就不剧透条件） |

## 他人只读

隐藏「编辑 / 钉选 / 装备展示柜」；可见：资料摘要、展示柜、精选相册、已解锁徽章。

## 入口

- 主窗：合并原「资料」「图鉴」为「个人中心」。
- Overlay 右键「查看资料」→ 打开只读 Hub。

## 非目标

- 首屏堆叠统计条、多卡片仪表盘风；保持一栏导航 + 一内容区。
- 全量钓鱼日志时间线。
