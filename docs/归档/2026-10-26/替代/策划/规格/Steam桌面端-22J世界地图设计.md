## 1. 目标与现状

地图首先让玩家知道「哪里能钓、有什么特点、进入要付什么」，再提供探索感。保留手账外框、底边栏世界入口、左侧纸签、浮标标记和右侧鱼塘照片；局部照片／胶带可轻倾斜，正文、价格和操作按钮保持水平。

当前 `DesktopWorldMapPanel` 已有拖动、缩放、选中、档位和进入；`WorldMapPondCatalog` 合并 `DesktopGameData.Ponds` 与 `WorldMapPonds.json`。当前本地坐标仍为 20 点规则排列，旧 Web 数据会用索引循环生成类别与费用，这是演示值，不能用作正式地图数据或把“格子排列”当成最终地理布局。

本轮设计解决：左栏图例／说明挤占、标签与字体位置不一致、详情与档位区相互重叠、缺乏搜索筛选、缩放后标记拥挤、进塘费用不够明确。未新增鱼塘、概率、票价、解锁等级、巨物开放或新手入口。

## 2. 固定职责与布局尺寸

沿用当前 1370 逻辑宽的手账面板；坐标相对面板左上，全部按当前项目窗口统一缩放，不按系统 DPI 二次放大。基准沿用 `.rail/.mid-h/.aside`；若外框版本调整，三栏约束整体迁移，禁止每页自设 CanvasScaler。

| 区域 | x / y / w / h（逻辑 px） | 内容与滚动约束 |
|---|---|---|
| 左筛选栏 | 24 / 112 / 210 / 496 | 18px 内边距；顶部搜索固定；中部分类／选项独立滚动；底部清除／帮助固定 |
| 中间标题 | 254 / 114 / 710 / 40 | 世界地图＋筛选结果数；不在地图底图再烧录标题 |
| 地图框 | 254 / 160 / 710 / 440 | 内边距 10px；视口 690×420，地图、标记、标签一并裁剪 |
| 右详情栏 | 984 / 112 / 362 / 496 | 上部详情 296px，间隔 12px，下部操作 188px；背景整体固定 |
| 页面提示 | 254 / 610 / 1092 / 26 | 只放单行结果／操作提示；重要错误在右栏按钮上方，不能只靠此行 |

左栏：搜索高 40，之后 12px；筛选可滚动区 y=70..392；底部 y=408..478 放清除按钮与两行操作提示。分类为「全部／野外／水库／进阶／老手／禁区／巨物」七行，每行最小 32px；「仅看可进入」「免费」是独立 checkbox。中部超高就滚动，不把帮助便签 absolute 叠到最后一行上。

右栏上区：内边距 16px，标题／状态行 32px；照片视觉高 128px，局部旋转 −1.5°，容器另留旋转安全边；其余鱼塘介绍、标签、鱼种在统一 FactsScroll 内。长塘名允许两行，不能缩到不可读或压按钮；上区内容超出只滚动上区。

右栏下区：左右内边距 16px，有档位时 40px、间隔 8px、费用摘要 48px（两到三行）、间隔 8px、主按钮 48px；底部安全余量。无双档时去掉切换控件，留下费用信息与按钮，不显示无效档位。错误可替换费用摘要区并提供行内重试；不扩大 footer 推走按钮。

正文 16px／行高 24，辅助 14px／20，标题 22px，主按钮 18px。主按钮图标 20px、间隔 8px，**图标＋文本作为整体居中**；不得把文字仍按带空图标的旧偏移定位。键盘焦点可见；基础命中区至少 32px，高缩放 Windows 鼠标与命中区一致。

## 3. 地图美术、分区和坐标

- 底图为柔和地形：平原淡草绿、森林深一档、山地米灰、河湖湖蓝、近海淡青；河流连通、水岸清楚、区域留出浮标空位。地形形状服务游戏区域。玩家可见的分区名称和鱼塘介绍改由 [猫咪世界观与场景描述](../世界观/猫咪世界观与场景描述.md)（WORLD-CAT-01）提供，本项不改写地理文案，也不宣称真实中国地理比例。
- 六类玩法区域以淡色边界／短标题区别，不铺六块高饱和矩形遮住原画。类别以 `pondCategory` 为准；水域类型是独立信息，不把“水库类玩法”与“水库地貌”混作同一字段。
- 使用当前已认可地图作为首个底图基线。另有地图重绘任务时，只在明确交付资源路径／版本后接入；不把候选图自动视作已认可成品。
- 在正式地形上重新标 0–1 归一化点位，按真实 pondId 维护；不得每次载入随机散点或沿用 Web 的索引造类别。每点落在对应水域或岸边，标签可以偏移但浮标尖端锚点不移动。
- 点位交付 `pondId,x,y,labelDirection,regionLabelId`，底图版本/hash 和坐标表一起版本化；现有格式不支持的附加字段先走迁移兼容。未提供点位的鱼塘进入侧栏列表供查看，但地图显示“位置待更新”，不全部堆在 (0,0)。
- 地图文字、锁图标、费用、人数不烧进底图；均为动态 UI。预计底图 2100×1400（现有 1050×700 逻辑尺寸的 2 倍），sRGB，无不必要 alpha；不能全分辨率导出成 8K。移动端布局不在此票。

## 4. 浮标与标签

| 状态 | 外观 | 点击后 |
|---|---|---|
| 可进入 | 六类颜色浮标＋类别形状小符号＋塘名 | 选中并展示详情，不直接进塘 |
| 已选中 | 暖橙外圈＋勾选角标，名称背景加深 | 再次点击不重播整页入场、不提交 |
| 当前所在 | 小猫爪角标＋“当前鱼塘” | 主按钮“返回当前鱼塘”，不重复 join／扣费 |
| 等级／引导未达 | 降饱和，明确锁图标 | 可查看信息，按钮展示具体条件 |
| 暂未开放 | 灰色浮标＋“暂未开放” | 可看介绍，不显示可支付进入 |
| 满员（有真实数据时） | 保留类别色，加“已满”角标 | 显示原因和刷新；不能仅看颜色 |
| 状态未知 | 普通轮廓＋待核对文案 | 允许查看，入口等条件核对后启用 |

浮标图形 30×38px，命中框 44×48px，屏幕大小不随地图比例无限放大；标记坐标和底图使用同一相机投影，图形 UI 层作反向缩放。标签最大宽 132px、最多两行，距浮标 6px。

标签优先级：选中 > 当前 > hover/键盘焦点 > 可进入 > 其他。按预设四方向尝试避让，8px 安全间距；仍冲突先隐藏低优先标签，保留浮标和焦点提示。不每帧全量重排，只在缩放、平移停止／筛选／选择变化时更新。

缩小后命中框重叠：以固定格网稳定聚合为“鱼塘 ×N”，点后向聚合区域放大；最大缩放仍重叠时弹出视口内小列表，只用于选择，不直接进塘。聚合不会把隐藏／不匹配筛选的鱼塘算入数量。使用既有 20 塘做基准，另用密集测试数据验证冲突，后者不可混入正式列表。

## 5. 搜索、筛选与数据边界

- 搜索按鱼塘中文名称／配置提供的别名匹配，输入 150ms 防抖；一次 Enter 立即执行。首版不承诺拼音搜索。按 Esc 先清当前编辑，再关闭面板，IME 组合输入时 Enter 不提交进塘。
- 分类单选，与“仅看可进入”“免费”做 AND。免费按已配置可用档位判断，显示该塘实际免费档；不得用原演示固定数值。
- 空结果文案：“没有符合条件的鱼塘”，给“清除筛选”；不自动切回全部使玩家以为筛选没生效。
- 已选塘被筛掉：取消选择，右栏提示“当前筛选下未选择鱼塘”，保留地图视角；不要偷偷进到不可见的旧塘。
- 同次打开保留缩放／平移和筛选；从鱼塘列表显式“在地图查看”跳来时优先选中指定 pondId，提示并清除会隐藏它的筛选。切换账号重置；不以刷新进度为由重播整页。

| 展示数据 | 权威源／缺失处理 |
|---|---|
| 名称、类别、开放、最低等级、费用、双档支持 | DesktopGameData.Ponds／现有配置；服务端最终门禁，不从示例 PONDS 推导 |
| 归一化位置、地貌、标签方向 | 版本化坐标表；与底图一起校验；地貌字段未有则省略，不拿 theme 文案冒充 |
| 用户等级、引导完成、今日扣费次数 | FishingProgressDto；加载中显示“核对条件中”，失败可重试，不能按 Lv.1 或免费兜底 |
| 可遇鱼种 | 该塘真实鱼种配置／API；最多 3 图标＋“更多”；缺失显示“鱼种信息待更新”，不所有塘都写鲫鱼鲤鱼草鱼 |
| 占用／容量 | 有覆盖所有塘的实时数据才显示；只有当前塘快照时其他塘显示“人数待更新”，不可显示虚构 0/20 |
| 照片、描述 | 按 pondId 资源表；缺图用中性水域占位＋塘名，不错用别塘照片 |
| 金币余额、档位当前价格与收费进度 | 当前账户／权威进度；已有字段不足时只显示已知标准，不把每2小时价格说成本次必扣额 |

只缓存静态图和坐标；等级／费用条件每次进入页面重新核对，异步回包带请求版本。快速 A→B 选塘时 A 的回包不能覆盖 B。地图关闭取消请求或丢弃迟到结果。

## 6. 详情、档位和进入路径

信息顺序：塘名＋状态 → 照片 → 类别／水域／解锁标签 → 一到两句介绍 → 鱼种 → 档位 → 费用 → 主操作。单个标签最多 2 行内排完，溢出收纳为“更多”，不把长描述塞进 chip。

双档名使用与实际经济规则一致的「出售档／回鱼档」，下方各一句说明。选档仅更新该塘费用，不换照片、不重播整个侧栏。切换到不支持双档的塘恢复 sell_only。正式文案以现有规则为准，不用“自动回鱼免费”等未经配置证实的承诺。

免费且满足条件：点击“进入鱼塘”一次发起 join。收费：首次点击“查看费用并进入”在**同一右栏操作区**展开确认态，显示塘名、所选档、每 2 小时标准、今日扣费次数／上限和服务端实际结算说明；按钮变为“确认进入”＋文字“返回修改”。明确一次点击用于确认信息、下一次用于提交，不做没有状态变化的隐蔽双击。

若权威入口报价明确提供“本次将扣 N”，显示该值；否则写“收费标准 N 金币／2小时，实际扣费以入塘校验为准”，不能把标准直接称为本次扣款。若产品必须承诺本次金额，先补服务端报价与有效期／请求 ID，再启用精确承诺。

确认态切塘／换档／费用变更／账号变更立即失效；重新展示新摘要后再确认。余额信息只做辅助，不能代替服务器判定。不得在客户端自行扣余额再等待 join。

提交态锁定选塘／档位，按钮“正在进入…”且只发一次。可关闭页面但不等于取消服务端事务：迟到成功更新会话，在下次打开显示当前塘；不能因旧回调强行再拉起已经被用户关闭的面板。进入新塘并且目标快照／本人角色就绪后才打开 Overlay，沿用现有无闪屏切换；收费或加入失败留在地图，展示明确原因和重试，不播放成功声。

连接超时先标记“正在核对加入结果”，重新查询当前会话；确认未加入才允许重发。实现时复用已有幂等能力，缺失则由后端补 requestId；禁止盲目 Retry 重复扣费。若原在鱼塘中，切塘成功前不把原会话当作已清空。

## 7. 平移、缩放和输入

地图逻辑尺寸沿用 1050×700，视口 690×420。初始 cover = max(viewportW/1050,viewportH/700)；缩放控件显示相对 cover 的 100%–250%，底图不足视口时居中，超过时 clamp，不能露空白。

鼠标滚轮只在地图视口内生效，以指针位置为 pivot；右栏滚轮只滚右栏内容，左栏只滚筛选。统一公式：world=(cursor-translation)/scale；newTranslation=cursor-world×newScale。Unity RectTransform 和 Web CSS 只在边界转换一次 y 轴方向。

拖动阈值 6 个逻辑像素；超过阈值不触发 marker click。不使用点击后延迟猜测拖动。滚轮每档比例 ×1.12／÷1.12，120ms ease-out，连续输入从当前值追随；拖动直接跟手不加回弹。复位回 cover 和全图中心；点击定位鱼塘时仅平移足够距离，不把目标藏到右侧栏后。

键盘：Tab 可到筛选、地图标记、缩放控件和入口；Enter/Space 选择标记而非直接收费，方向键在地图获得焦点时平移，+/−缩放，Home 复位。输入框获得焦点时不截获这些字符。

## 8. 动效与 Web/Unity 对齐

外框打开／关闭完全复用新版工作区的同一时间轴，使用 pageContentReveal 边界后启动内容，不能给整页和子节点各自再执行一次淡入。左纸签缩进沿用现有曲线与取消机制，不重新猜一组毫秒数。

| 操作 | 本页新增动效规范 |
|---|---|
| 首次内容展示 | 地图与左栏随公共 reveal 出现；右栏在同一公共 aside 边界出现，不受网络回包延后 |
| 选塘 | 标记 160ms 缩放 1→1.08→1；右栏内容 120ms 交叉淡化；只照片 −1.5°，不整个侧栏扭转 |
| 选中浮标 | 轻抬 2px 后落定，不持续跳跃；当前塘静态爪印 |
| 筛选 | 匹配集合 120ms 淡变；地图视角不自动飞走；数量同步更新 |
| 切档 | 沿用现有 320ms 滑块；费用文本即时更新，按钮不漂移 |
| 聚合放大／复位 | 180ms ease-out；拖动会立刻取消插值 |
| 减少动效 | 所有缩放／移动装饰取消，最多 100ms 淡变；真实地图平移与缩放仍可操作 |

新参数在 Web/Unity 共用配置或对照表中记录。动态加载只更新图片／文本，不能重新创建整页造成“双刷新”。UI 声音遵从 I：选择 toggle、地图打开 open、真正提交 click、失败 error，一次操作只发一个导航 cue。
