项目简介

休闲社交挂机钓鱼游戏雏形，包含世界地图、实时鱼塘、背包鱼获、好友与动态、私聊与经济系统。技术栈为 Expo (React Native Web) + Node.js + Socket.io。

核心玩法 v1

世界地图4 个鱼塘区域，点击进入
二维鱼塘圆圈头像挂机钓鱼，实时同步
鱼塘聊天每塘独立频道，紫品以上全塘公告
限制每塘 20 人，每日钓鱼 8 小时

社交系统 v2

好友申请 / 同意，查看好友动态
动态墙公开分享钓到的鱼
关注仅看好友动态
私聊好友一对一聊天
经济卖鱼得金币（暂无用途）

一键启动

在项目根目录执行：

cd C:\Users\Administrator\Projects\fish-social
npm run dev

将同时启动服务端 :3001 与 Web 预览 :8082

打开 Web 游戏 检查 API 健康

主要 API

REST

  • POST /api/players/register
  • GET /api/posts/wall
  • POST /api/friends/request
  • POST /api/inventory/sell
  • POST /api/dm

Socket

  • register_player
  • join_pond / fish_bite
  • dm_message
  • friend_request

双窗口测试社交

  1. 打开两个浏览器标签（或一个普通 + 一个隐身窗口）
  2. 分别进入游戏，点击右上角「社交」
  3. 在「好友」里搜索对方昵称并发送申请
  4. 对方同意后，可查看动态、私聊、卖鱼分享
